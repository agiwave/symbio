# 交付流程手册

## 启动检查清单

1. 技术栈与服务形态已明确（纯 API / 全栈单体 / 微服务）。
2. 数据库选型与迁移工具确认（PostgreSQL / SQLite / MySQL）。
3. 接口方式确认（REST / GraphQL / tRPC / gRPC）。
4. 实时能力按需决策（轮询 / SSE / WebSocket），必须含心跳与断线重连。
5. 认证策略确认（JWT / Session / OAuth），访问令牌短时效。

## 上线前红线

- 配置全部来自环境变量，启动时集中校验、快速失败；`.env.example` 只含占位值。
- 客户端只看到规范化错误结构，绝不返回堆栈或内部细节。
- CORS 使用显式来源，生产禁用通配符。
- 日志不记录密码、令牌与隐私数据。
- 健康检查端点（/health、/ready）与优雅停机必须可用。

## 验证顺序

编译检查 → 启动冒烟 → 集成检查 → 实时检查（如适用）。任何一步失败都不得进入下一步。
