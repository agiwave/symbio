# 目标自生成能力包（conation）

一条事实、一条视图、两半折叠：会话空闲到点时表达一条「欲」，表达过什么、各自升没升格
（升格 = 由它长出一个任务）由本包折成可读的意图流。名册 #31「目标自生成」的能力包。

## 它交什么

| 面 | 交出物 | 谁用 |
|---|---|---|
| 事实 | `conation.expressed`，格位 `conation × opened`，字段 `goal` | 写闸按声明校验名字与格位；`seal` 按归宿行判它有没有人看护 |
| 视图 | `conation.intents` → `{ intents, declared, expressed, escalated, adoption_rate }` | 任何按名字读的插件（报表登记，D-221 / D-387） |
| 多片合并 | `ViewDecl::agg`：N 份单片读数 → `{ expressed, escalated, adoption_rate }` | 实例级聚合列的读方（D-281） |

**没有工具、没有路由、没有配置、没有新端口。**

## 为什么有实例、却没有行为

四条扩展面（事实 / 视图 / 归宿行 / 多片合并）都走 `symbio-plugin-api` 的**链接期**收集，
不需要实例参与。实例仍然要有，理由只有一个：**装配清单按插件目录挂载**——停用插件 ⇒ 实例
不构造 ⇒ 这个能力包从插件树里消失。`ConationPlugin` 就是那个挂载点本身（与
`symbio-plugin-task` 同一形状、同一理由）。

给它一个 `route` 臂只会多一条永远 `NotFound` 的地址，给它一个 `traverse` 臂只会多一个
永远空的工具面——两样都是「注册了但没人能到达」的形状（`E-012` 判过同一个病）。所以
`route` 恒 `NotFound`、`traverse` 恒空数组，两者都不是占位符而是**答案**。

## 两条口径

- **升格靠溯源认**：一条欲「已升格」当且仅当存在一条 `task.opened` 的 `produced_by` 指向
  它。不靠 goal 字符串相等——字符串相等会把**别的**来源开的同目标任务也算成这条欲的产物。
  这条 `produced_by` 是**信封**字段，所以它不进 `reads`（`reads` 列的是载荷字段）。
- **as-of**：形参 `now` 就是锚，`ts > now` 的欲与升格一概不见。

## 为什么折叠要交两半（D-281）

读方要的是两个基数上的同一个口径：**这一片**的采纳率（单会话列）与 **N 片**的采纳率
（实例级聚合）。`eval` 交前者、`agg` 交后者，两半都由本包交、同经冻结声明表被调用，
所以「率 = 已升格 / 已表达」这条算式只有一个 owner。少了 `agg`，跨会话合并就只能在读方
再折一遍——那是同一件事的第二份口径。

`declared` 那一格同理：「哪些目标算已声明」由 owner 判（= 升格过的那几条），读方只做
**查表**。让读方自己扫 `intents` 找 `task_id.is_some()`，等于把定义搬到读方。

## 卸载之后

- 视图格消失，`session/stats` 的主动性列退化成空形状（并出声一次）；
- 实例级主动性轴交 `null`（不是三个零——零是「没有主动发起过」，`null` 是「读不出来」）；
- 会话的自主触发**不再升格**长目标（它读不到 `declared`，宁可这一次不开，也不每 tick
  重开一条），但触发与「欲」照常入格。

三条都是**能力消失**的正确形态，没有留下静默的边。

## 测试的边界

本包的用例钉**数字**（升格靠溯源、as-of、分母含未升格、合并可加、`declared` 只含升格过
的那几条）。读方（会话）的用例只钉**契约**：按名字读、原样透传、缺席怎么退化。

会话的测试二进制**不链接**本包（`E-009`），所以它读到的必然是缺席——那正是要测的形状之
一。给读方交一份「算法一样」的替身会让「卸载之后系统还完整」这句话失去判据：替身不是
owner，它只是把红改绿。端到端的组合证明在 `e2e/cases/t36-autonomous-initiator.mjs`
（真跑两个 tick，就绪集里始终只有一条心跳任务；`fleet.axes.conation` 由本包的 `agg` 汇总）。
