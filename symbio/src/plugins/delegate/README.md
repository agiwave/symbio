# delegate 插件

**可选的委派者**：主会话与后台 worker 会话之间的三项只读事实——**判定该不该开 worker**、
**主会话有哪些能力**、**worker 跑到哪一步了**。

## 它解决什么

目标形态（[`docs/plan/06` §10](../../../../docs/plan/06-落地桥接方案.md)）：主会话只与用户
对话，深度思考与多轮工具在 **worker 会话**里做。主会话因此**不持有工具**，它需要外部
事实才能工作——本插件就是这三件事的唯一真源：

| 问题 | 出口 | 形态 |
|---|---|---|
| 这轮该不该开 worker？ | `delegate/decide` | 纯函数（前缀 / 关键词 / 长度，全部可配） |
| 没有工具时怎么知道有哪些能力？ | [`digest`](digest.rs)（当前由单元测试与后续注入消费） | 纯函数：能力清单 → 按分类的短目录 |
| 用户问"进展如何"怎么答？ | `delegate/progress` | 纯函数 + 磁盘公开布局（worker 会话快照） |

## 三条设计边界

| 边界 | 为什么 |
|---|---|
| **可选**：停用 / 未装配 = 系统照常运行（J2） | 它给的是**事实**，不是地基；不在系统默认装配清单里 |
| **只读**：不启动 worker、不写任何域 | 写入仍走各域原有路径（杜绝"第二份真相"） |
| **零插件依赖**：只读磁盘公开布局，不 import 任何兄弟插件 | 插件独立原则 |

## 两条路由

| 路径 | 输入 | 输出 |
|---|---|---|
| `delegate/decide` | `payload = { "text": "用户消息" }` | `{ dispatch: "chat" \| "work", reason }` |
| `delegate/progress` | `payload = { "parent": "主会话 id" }`（可选） | `{ parent, count, workers, rendered }` |

> 判定**必须回理由**：`reason` 是"为什么这轮没动手"的唯一出口，也是漏判可申诉的前提
> （主会话据此对用户说"需要我动手做吗"）。
> `parent` 给了就只报该主会话名下的 worker（注入自用），不给 = 全局（诊断面用）——
> **串台比没有更糟**，所以归属判据是磁盘上的 `metadata.parent_session_id`，不是目录位置。

## 配置（`<本插件目录>/PLUGIN.yml`）

| 键 | 出厂值 | 作用 |
|---|---|---|
| `enabled` | `true` | `false` ⇒ 两条路由都 `NotFound`（**平凡值**） |
| `force_prefix` | `/work `（**带尾空格**） | 显式指令前缀；尾空格是**词边界护栏**（`/worker` 不命中），别 trim 掉 |
| `keywords` | `[]`（空集） | 命中即开；出厂空 = 宁可漏判（用户一句话可补）也不要误判 |
| `min_chars` | `0`（不启用） | 主题长度 ≥ 阈值即开，按**字符**计 |
| `digest_max` | `40` | 能力目录条数上限，超限截断并在末尾标 `…（共 N 项）` |

## 平凡值（J2）

| 项 | 平凡值 | 平凡值下 |
|---|---|---|
| 插件 | `enabled: false` | 两条路由 `NotFound`；**会话与其余路由照常** |
| 判定 | 未命中任何判据 | `dispatch = "chat"`（主会话直接答），且**带理由** |
| worker 快照 | 没有 worker | 空表 + `rendered: ""`（不注入空标题） |
| 能力目录 | 无能力 | 空串（不注入空标题） |

## 为什么叫 `delegate` 而不叫 `worker`

`worker/` 在本仓已是**路由前缀别名**（`worker/session/chat/send` ≡ `session/chat/send`）。
同名插件会造成「同名异物」——排查时按名字找代码会找错东西。
