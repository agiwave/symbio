## 规范

`#[allow(dead_code)]` 的承认必须同时满足三条，否则死码审计等于自废：

1. **承认必须指名消费方**：理由里写 `消费方=<谁在用>`，且名字非空。消费方不在 Rust 侧
   （前端镜像 / 协议文档 / 审计脚本）是这类标记存在的**唯一**理由——rustc 看不见那些
   调用点，故完成判据不是「接入」，而是**理由写明消费方名**；
2. **棘轮只许降**：基线 `R002_BASELINE` 只降不升；每次下调在代码里写明理由；
3. **新死码不入账**：新出现的 `dead_code` 要么接上、要么删掉，不许再加 `allow`。

## 判据

`scripts/dead-code-audit.mjs` 的 R-002 段（`R002_BASELINE = 8` + `消费方=` 非空核对）；
回归 `scripts/dead-code-audit.test.mjs`。
