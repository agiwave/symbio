## 规范

设计文档按**作用范围**分区：

- **`DE-0xx`**：系统级设计——跨模块的机制与契约，住在 `docs/003-design/`；
- **`DE-1xx`**：组件级设计——某个模块或前端 / CLI 的内部设计，**就地**放在该组件目录（模块 `README.md` 与其 `docs/`）。

分区不是分类轴：两区都是 `design` kind，字段与状态机完全相同。分区只让「这条设计管多大范围」
在编号上可读，并保证两段各自独立、不撞号。新写一篇设计按范围落区；跨区引用只写编号，地址由 `gen-doc-refs` 重算。

## 判据

`scripts/registry-audit.mjs` 的 RG-022（前缀与 kind 对账）与 RG-003（id ↔ 文件名）。
