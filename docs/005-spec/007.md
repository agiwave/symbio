## 规范

**每一条架构改动都要论证「必需」；论证不出的改动直接删掉。** 「必需」指：不做这一步，
哪条判据兑现不了、哪个已登记缺陷关不掉。论证写在设计文档的正文里，不另开清单。

放宽既有形状（棘轮）**必须挂一条可打开的决策**：

- 形状只许收窄：`symbio_core` 生产侧的三格（`pub trait` 数 / `fn` 成员总数 / 带默认体的成员数）冻结成只许降的棘轮；
- 要放宽，就在设计文档里留一节 `### D-NNN` 说明为什么必需，并在基线旁写
 `core-shape-allow <格>: D-NNN <理由>`；那个锚点在设计文档里**必须真的存在**。

## 判据

`scripts/core-shape-audit.mjs`：**CS-001**（三格棘轮只许降）、**CS-002**（放宽必须挂一条可打开的设计决策）；
数字是否比上一版更松由 `scripts/gate.d/35-baseline.mjs` 比对基准版本判。
