## 规范

新字段一律 `#[serde(default)]`（或等价的默认值声明）；**新语义只对「新产生的数据」成立**，
不为旧数据写迁移分支、不做双读兼容层。

理由：兼容层是**永久成本**，而本仓未发布、旧数据只存在于开发者的本机目录——
一段只服务一周前数据的分支会活到下一个读它的人误以为它还有用。

## 判据

人工评审（改动的自查项）：出现「读旧字段 / 判断数据版本 / 双写」即需在评审里解释；
契约形状的机械判据见 `scripts/schema-audit.mjs`。
