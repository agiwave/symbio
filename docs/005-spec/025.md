## 规范

**声称「编译期强制」必须附一段已知编译不过的代码**。它拦住的反模式：「强制」没有反向用例时，无法区分「真的强制」与「恰好没写错」。

## 判据

`docs/003-design/verify/` 下 `#[cfg(feature = "should_not_compile")]` 模块 + `rustc --cfg` 期望非 0 退出。
