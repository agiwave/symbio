## 决策

**背景**：[T-168-模型档位闸门对内部请求无效](../009-task/168-模型档位闸门对内部请求无效.md "T-168-模型档位闸门对内部请求无效") 立项时核出：档位闸门只有
一个挂点 `LlmAdapter::generate(&FullModel, …)`，而 `ModelProvider::execute_turn` 对所有插件开放。
生产代码里共有四处直调（`grep '\.execute_turn('` 滤掉测试文件），其中一处是闸门自己的方法体，
另外三处是「内部请求」：`classify/decide.rs`（快速档判决）、`compose/wording.rs`（答话措辞）、
`session/context/pipeline.rs::run_compression_llm`（压缩摘要）。

**裁决一：「内部请求」成一类，这一类显式不受档位闸门约束。**

定义的形状（四条同时成立）：

1. `tools` 传空切片——**不需要工具**，不是「忘了给」；
2. 出口不产生对话轮次帧——`ExecEventSink::silent()`，或经压缩节点过滤（摘要增量改道、
   骨架帧被吞）；两者都不给用户留下「正在思考…」的空 Turn 骨架；
3. system prompt 由调用方就地构造且**不随用户输入变形**；
4. 中止走调用方给的共享信号，没有独立的编排层。

**裁决二：三条各归其位，但不同时。**

- `compose/wording.rs` 与 `run_compression_llm` **判为内部请求**：它们做的是生成，
  而令牌族里唯一能签给生成的就是 `FullModel`——它们今天的权限**已经是** `FullModel`，
  绕一圈经 `ProviderLlmAdapter` 拿回来的还是它。对这两处，闸门没有可给的约束。
- `classify/decide.rs` **标记为待裁决**：它该拿的是 `ClassifyOnly`（允许分类、不许生成），
  而 `LlmAdapter` **没有**收这个令牌的方法。给它加方法 = 给 core 加公开面（CS-002），
  须先裁语义 ⇒ 归 [T-162](../009-task/162-ClassifyOnly快速档路径裁决.md "T-162-ClassifyOnly快速档路径裁决")。
  若 T-162 裁 (i) 纯规则分类器，这次模型调用**本身就该消失**；裁 (ii) 才走
  「补 `ClassifyOnly` 入口」那条（那一次须另立 ADR，本条不预定）。

**裁决三：为什么「不受约束」不是漏洞——闸门管的三件事，内部请求分别由别的机制满足。**

| 闸门管的事 | 内部请求怎么满足的 |
|---|---|
| 用哪个模型 | `capability_model_resolve`（classify / compose）与编排器的生效 provider（压缩），**随用户选的那一个**——不存在第二条模型来源 |
| 不许长输出 | 输出空间由解析约束：判决四选一（`parse_verdict`）、措辞一段、摘要一段。给它们长输出也没有第二个消费方 |
| 不带工具 | 形参 `&[]`，**编译器保证**；不是运行时检查 |

**裁决四：把这条边界钉成可执行的，而不是靠「大家都知道」。**
`scripts/internal-model-audit.mjs`（IM-001…IM-004，进门禁）枚举直调点，每处一条非空理由；
IM-004 判**形状**：登记为内部请求的点 `tools` 必须是 `&[]`，闸门本体（`IM-001/gate`）才可透传。
于是本条裁决的失效形态（某处长出工具调用、或声明悄悄扩大）会在门禁变红，而不是烂在文档里。

## 否决的替代方案

- **三处全部改走 `ProviderLlmAdapter::for_turn`**：对 compose 与压缩是**空转**（裁决二），
  对 classify 要求 core 变宽。被否——它不是不好，是**提前**：为一件还没定形的事付两份代价。
- **押后不裁，守卫建成即止**：缺口从「没人看见」变成「看见了还没裁」确实比原来好，
  但「闸门管什么」这条边界没有书面答案，下一个读者仍要从令牌族反推。被否。

## 后果

- 档位闸门的覆盖范围**第一次有书面定义**：主对话链路（经 `LlmAdapter`）+ 反射档（`RuleOnly`）
  + 内部请求（显式在外）。新增一种模型调用时，先回答「它是哪一类」。
- 本记录不阻碍 T-162 的 (ii) 分支：真到那天，「今天为什么没有 `ClassifyOnly` 入口」
  就是本条 ADR；届时另立一条专门记入口的形状与 core 面代价。
- 若某处内部请求长出工具调用 / 可见帧，IM-004 当场变红，而不是等一次架构复盘。
