## 规范

限定名 `13 §0 纪律 2`（编号沿用 13 篇的命名空间）。

**机制优先**：每条问题必须落成**一个守卫 / 一份真源 / 一个类型约束**；
只做人工修正不算闭环——人工修一次，同类问题下一轮再来（本仓同类削格已发生两次）。

它与 [SP-013](SP-013.md)（出口可核对）是同一件事的两半：本条要求问题落守卫，
SP-013 要求**出口不许依赖一个尚不存在的守卫**。

## 判据

无独立机制判据：由各条问题的 `exit` 是否指认一条已存在的守卫 / 脚本锚来兑现
（判据形态是 SP-013，本条约束的是**问题本身**有没有落成机制）。
