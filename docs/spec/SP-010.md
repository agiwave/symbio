## 规范

限定名 `13 §0 纪律 1`（编号沿用 13 篇的命名空间）。

**只写目标态**：注释与文档**只描述现在是什么**。以 `TODO` / `FIXME` 起头的注释、
或只写「批 N」却不给任务编号出处的注释，都是过程叙述 ⇒ 红。
追溯走 `git log -S<符号>` / `git log --grep=<词>`；要保留「为什么否决 A 选 B」的结论，
写进 [docs/adr/](../adr/ADR-000-架构决策汇总.md "ADR-000-架构决策汇总") 的一条 ADR——**那才是它的 owner**。

它防的是：注释叙述过程 ⇒ 代码改了注释不改，且读者分不清哪句还成立。

`scripts/grep-audit.mjs` 的 S-012（注释以 `TODO` / `FIXME` 起头、或以无出处的批次口径叙述实施排期 ⇒ 红）。
