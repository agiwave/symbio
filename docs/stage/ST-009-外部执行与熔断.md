# ST-009 · 外部执行与熔断

前置：S08 ｜ **新增机制键 0** ｜ 参数变化 4 ｜ 阶段三

## 1. 场景：要什么能力

智能体能对外部世界产生**不可逆后果**（写文件、发消息、下单、调生产接口），
并且有硬闸门：超预算 / 高风险 / 未授权时**熔断**，而不是"先做了再说"。

相对 S08 高了什么：S08 之前的所有副作用都是"系统内部的"；本阶第一次对外产生真实后果。
**T5→T6 的分界就在这里**：从"能做事"到"做的事有代价"。

## 2. 为什么它能落在 v2 上（J1）

| 看起来新的东西 | 实际是 |
|---|---|
| 外部动作 | 一个 Actor 的一次 `progressed`，写 `artifact/asserted` |
| 熔断 | 一个 `Decider`，`budget_ms = 80`，写 `control/opened` |
| 风险分级 | `grants` 表里的能力名（闭集 7 名；外部轨 = `produce.artifact`）——**数据** |
| 预算控制 | `projection = budget` + I3 |

**关键**：内外双轨（Internal / External）在 v2 里**不是两套动作空间**，而是 grants 表里的能力名 + 高风险组合的构造期拒绝。
> 认知体系提出的"内外双轨动作空间（CoALA）"就落在这一阶——它不需要新机制，
> 只需要"内向推演"与"外部破坏性执行"在授权上分开。
按 J1，能用授权表表达的就不占机制位。**新增机制键 = 0**。

## 4. 平凡值与回退（J2）

| 参数 | 完整值 | **平凡值** | 平凡值下 |
|---|---|---|---|
| `actor.capability` | `produce.artifact`（外部） | **`reply.append`** | 仍完整运行——只用文字描述要做什么，不真做 |
| `actor.budget_ms` | `80` | `60000` | 仍完整运行——闸门慢，但闸门仍在 |

**`reply.append` 是本阶唯一安全的退路口**：把"会对外产生后果"降级为"只说不做"，
系统仍是一个完整的对话系统（S01 状态），只是丧失执行力。

## 5. 静默失效与强制（J3）

| 约束 | 违反时信号 | 强制方式 |
|---|---|---|
| 未授权的外部执行 | **无**——只是多了一条事件 | 写侧 `grants_of` 编译期强制 |
| 熔断必须在 80ms 内产出 | **无**——静默超时 | I3：超时必须产出 fallback 事件 |
| 高风险组合不得同主体持有 | **无** | 构造期拒绝——`governance` 建表即校验（`governance/mod.rs`） |

## 6. 验收断言

1. 未持有 `produce.artifact` 的主体尝试外部写入 → 被拒绝，**且不产生事件**。
2. 预算耗尽 → 必须产出熔断事件，不允许静默继续。
3. grants 表中出现高风险组合 → **构造期拒绝**（建表即报错）。
4. **反向用例**：把预算放宽 → 断言 2 的判定必须改变（证明预算在生效而非常量）。

## 8. 这一阶做不了什么

- **"该不该做这个外部动作"的价值判断不在架构层**——架构只保证"有闸门、有授权、有熔断"
- 不可逆动作的**补偿/回滚**未定义：v2 的撤销语义只覆盖日志内部（`memory.forgotten` 是投影排除），
  对外部世界已发生的事，**架构不提供 undo**
- 成本首测已落地（[slo-calibration](../ref/RE-004-slo-calibration.md "RE-004-slo-calibration")）；`budget` 投影读的是实测 `cost_ms`，剩余的是**真实流量**下的 P99
