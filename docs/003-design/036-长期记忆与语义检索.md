# 长期记忆与语义检索

记忆是追加事实上的投影。检索必须确定、可见域受控、支持 as-of 读取，并在能力不足时
显式降级，不能静默返回“没有相关记忆”。

## 1. 写入与遗忘

记忆写入分为：

- `memory.encoded`：来源、可见性、内容与编码时的检索词；
- `memory.consolidated`：由多源内容形成的巩固结果及其来源集合；
- `memory.forgotten`：记录被排除的来源集合。

物理记录只追加。遗忘是投影排除，不删除源记录，也不改写巩固事实；被排除来源仍可从
审计视图读取。

活集为“全部已编码 ∪ 全部已巩固 − 被遗忘来源及其派生产物”。巩固结果的来源必须可追踪，
否则不能精确排除，只能整项排除并留下理由。

## 2. 可见性与 as-of

每条记忆携带认知主体与来源会话可见性。跨会话读取默认 `thread_private`；只有显式声明
更宽可见性的记忆才能进入其它会话。读者还必须属于允许的认知主体。

当前扫描边界是 peer sessions，不递归包含所有后代会话。分支、截断与来源节点信息不足时，
按已知可见域保守过滤，并报告无法证明的记忆范围，不声称完整隔离。

as-of 读取只使用读取时点已经提交的编码、巩固与遗忘事实。后续写入不得改变历史读取
结果；同时间戳按事实序列确定先后。

## 3. 检索排序

当前检索使用词面重叠，不使用向量重排：

1. 词项交集数量降序；
2. 记忆时间戳降序；
3. 事实序列降序。

空查询按时间降序返回可见记忆。重复词、停用词与大小写归一不得改变事实身份。结果包含
分数来源、记忆身份、来源与可见性，便于解释为什么命中。

同义、换述和跨语言不保证召回，这是当前机制的诚实边界。扩展语义索引必须保持 as-of、
可见性与确定性，不得把排序副产物写回事实载荷。

## 4. 向量与巩固

向量、embedding 与派生索引不写入 `memory.encoded` 等事实 payload。需要索引时由独立
投影或缓存承担，并能从事实重建；索引缺失必须走可解释的词面降级。

巩固是记忆能力声明的一笔条件债。执行体在派发后读取计划期快照，自行选择可巩固来源、
提交 `memory.consolidated` 并关账。活集不足时不派发；环不提供通用“记忆聚合”行，也不
保存调用点。

## 5. 快路径与成本

没有显式召回请求的轮次仍编码成功的记忆写入。检索候选扫描、上下文注入与巩固各自
有声明预算；预算耗尽产生降级标记，不伪造空结果。高频写入不得强迫每轮运行嵌入模型。

## 6. 能力阶梯赋值

```capability-assign
event.entity = memory
event.verb = asserted
actor.pattern = translator
projection = recall
```

## 7. 平凡值与回退

| 参数 | 平凡值 |
|---|---|
| `projection` | **snapshot** |
| `event.entity` | `memory` |
| `actor.pattern` | `translator` |

无专门检索投影时使用可见记忆快照，但仍应用 as-of 与可见性过滤。`recall` 是能力阶梯
坐标，不声明一个新的向量事实面。
