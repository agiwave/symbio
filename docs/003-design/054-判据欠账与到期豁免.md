# 判据欠账与到期豁免

> 欠账与契约资产的分表、绝对欠账线、迁移台阶和期限算法归
> [DE-026-能力拆分与影响类](026-能力拆分与影响类.md "DE-026-能力拆分与影响类") §5。
> 本页只规定例外动作的边界，不复制读数、日期、提交或逐笔台账。

## 通用规则

- 豁免必须具名到判据、责任范围、理由、代价、失效日或复核触发条件；不得用无限期口头约定延后。
- 豁免只改变到期时间，不改变判据、分子分母、统计范围或补件与迁移的配对算法。
- 修正口径必须证明没有任何存量欠账因修正而消失；不得为消账改路径、换符号或放宽统计入口。
- 冻结账保持零余量、只许降、禁新增。复核只确认仍然适用，不把冻结项转成可增长预算。
- 棘轮基线不留余量。低于基线是合规，高于基线即红；缺口必须有真实迁移或具名期限豁免。
- 缺失 SLO 的出口按欠账处理，不得以“尚未配置”为由退出计数。
- 台阶当天无法真实完成时，保留红灯或使用具名豁免；禁止凑数迁移、假搬迁和只改文档读数。

## 执行与审计

- `EX-007` 管累计欠账，`EX-008` 管契约资产；两者不得互相抵销。
- 提交签名、受保护树和迁移纪律归 [DE-026-能力拆分与影响类](026-能力拆分与影响类.md "DE-026-能力拆分与影响类")。
