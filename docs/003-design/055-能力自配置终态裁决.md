# 能力自配置终态裁决

> 扩展面见 [DE-025-能力包与扩展面](025-能力包与扩展面.md "DE-025-能力包与扩展面")；
> 决策只读快照的判据见 [DE-047-义务环判据与归属推导](047-义务环判据与归属推导.md "DE-047-义务环判据与归属推导")。
> 本页规定配置真源与交付时机，不记录迁移过程或作废清单。

## 配置真源与快照

- 一项能力配置的真源在该能力包自己的 `PLUGIN.yml`。配置定义、默认值、读写与校验由同一 owner 持有。
- 能力在既有 `traverse` 收集中，用 `capability_announce_config_snapshot` 声明本轮要贡献的键和值。
  贡献只传值，不向宿主或其它能力暴露配置类型。
- 宿主用 `capability_config_snapshot` 按注册序合并贡献，不解释键名、不补默认值、不按能力名分支。
  同名键按表语义由后注册者覆盖。
- 开轮装配把合并结果写入一条 `session.config` 事实。决策面只读这条快照，不读活配置。
- 键缺席时，由读方使用自己的出厂值。卸载能力导致键缺席是合法降级，不得留下永久旧值。
- 运行中修改配置从下一次开轮快照起生效；同一轮内不得因活配置变化产生第二个读数。
- 会话自身拥有的行为字段由会话直接投影；能力拥有的字段由该能力贡献。宿主不维护能力字段的平铺副本。

## 声明式去重

- 作用域改名的工具由声明方同时声明 `(前缀名, 本名)`，宿主经 `SCOPE_TWIN` 读取。
- 宿主只做集合判定：前缀名与本名都在本轮候选集中，才去掉前缀副本。
- 本名缺席时保留前缀工具；声明缺席时不去重。不得按名字形状猜前缀，也不得让宿主认识工具语义。

## 边界

- 设置页只声明配置文档的地址与呈现，实际读写仍落在 owner 的配置文件。
- 能力之间不共享配置结构体，宿主不新增按世界命名的配置字段或专用通道。
- 决策面读不到快照时使用出厂值，不得为了取得当前值直读插件配置。
- 首响、进度等会话行为仍由会话配置与事实边界管理；措辞能力只消费请求，不反写会话配置。
