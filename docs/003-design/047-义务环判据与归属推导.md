# 义务环判据与归属推导

环只认债：一次端口调用一笔债，由声明欠出、由提供者还清。环只承担七项职务；不属于
这七项的内容不得以机制形式留在环内。事实词表与债务表归
[DE-050](050-义务环事实词表与债务表.md "DE-050-义务环事实词表与债务表")，端口合同归
[DE-048](048-端口机制裁决.md "DE-048-端口机制裁决")。

## 1. 不变量

**I-1 单位是债。** 一次端口调用对应一笔债，协议事实为 `request` / `sent` /
`response` / `failed` / `retry`，幂等键为 `(port, id, attempt)`。N 次调用是 N 笔债，
不存在批债单元。

**I-2 债由声明欠出。** 声明只引用事实行、视图与端口名，不引用端口实现，不靠解释端口
载荷生成债。领域事实先由能力写入，声明依据事实开出下一笔请求。

**I-3 环只有七项职务。** 选债、派发、等待、配对、记账、预算与租约、重放。环内每个
保留元素都必须能指认属于其中一项。

**I-4 环不碰世界语义。** 环不解析端口载荷，不读授权闸，不做批、并发策略、重试判据、
终答判定或轮次编排。

**I-5 提供者执行并还债。** 提供者按契约执行一笔债，并通过宿主写口提交事实草稿。
执行隔离、并发、guard、熔断、广播、超时与结果守卫均在提供者内部。

**I-6 端口接口通用且开放。**

1. 端口身份是数据：提供者申报一个或多个端口名，环按名字解析绑定。
2. 输入是端口名与行／值草稿，输出是事实草稿、通用错误与应答承载；不出现具名世界载荷。
3. 行形状与字段校验归端口所属能力，接口不承载世界契约。
4. 执行面一次只处理一笔债；接口不含批、并发度、熔断或授权闸读数。
5. 执行上下文只含取消、幂等、增量出口、事实草稿出口、只读事实面与宿主纯值。
6. 能力位只允许 `streaming` / `cancel` / `idempotent` 等通用词。
7. 注册即扩展：新增端口只增加能力声明与提供者绑定，不改环、注册面或接口。

## 2. 归属判定

对任一元素依次判断：

1. 属于七项职务之一：归环，并指明对应职务。
2. 能写成“读事实 → 欠 `request(port=…)`”：归声明。
3. 能写成“执行一笔债 → 提交还债事实”：归提供者。
4. 两者都写不出：删除，或降为纯值与声明数据。

落在环与提供者接口上的元素还须检查是否具名某个世界。具名则改为端口名、值草稿与
通用错误分类，或移入提供者内部。实现困难和既有代码位置不改变归属。

## 3. 门禁

| 判据 | 规范 |
|---|---|
| `LP-001` 类型边界 | 环生产代码不引用端口载荷类型，只使用端口名、事实行与债 |
| `LP-002` 依赖边界 | 环不依赖提供者或业务插件；机制门面不在禁止之列 |
| `LP-003` 世界语义词根 | 环生产代码不出现批、授权闸、模型、工具、轮次等世界词根与硬编码端口行名 |
| `LP-004` 接口世界词根 | 端口合同公开类型与方法名不具名任何世界 |
| `LP-005` 载荷类型通用 | 端口受理签名只使用通用输入、输出、上下文、能力位、错误与执行体类型 |

棘轮只许下降。端口名本身是数据，不受世界词根检查。

两个彼此独立的世界端口必须分别实现同一套 `PortProvider` / `PortExecutor`，跑通成功与
失败两条完整债链路；通用环侧派发路径另以桩执行体验证。不得用同一个提供者伪装成两个
独立端口。
