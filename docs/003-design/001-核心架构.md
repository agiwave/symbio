# 核心架构：事实、Actor 与控制环

Symbio 由 **Store 原语、Projection 签名约束、Actor 一等概念、三条不变量和参数数据**构成。
控制面是“一环 · 一表 · 一源”，Agent 是一棵插件树。

本文定义核心语义。插件分层见 [架构总览](002-架构总览.md "DE-002-架构总览")，机制形状见
[机制形状规格](051-机制形状规格.md "DE-051-机制形状规格")，工程验证见 [工程落地与验证](016-工程落地与验证.md "DE-016-工程落地与验证")，
能力坐标见 [能力注册表与能力坐标系](008-能力注册表与能力坐标系.md "DE-008-能力注册表与能力坐标系")。

## 1. 核心元素

<!-- list:core-elements owner -->

| 元素 | 性质 | 增长边界 |
|---|---|---|
| Store | 唯一原语，提供追加与范围读取 | 不随场景增加 |
| Projection | 受构造签名约束的纯派生类型，不是 trait | 不随场景增加 |
| Actor | 使用投影与 Store 的一等概念 | 模式封闭，实例可增 |
| 不变量 | I1 单通道、I2 无溯源不声明、I3 到点必答 | 不随场景增加 |
| 参数数据 | 事件格子、ActorSpec、授权、视图定义 | 允许增长 |
| 控制面 | 一个驱动环、一张声明行表、一个事实源 | 不随能力增加 |
| Agent | 由插件容器装配的树 | 结构封闭，实例可增 |

## 2. Store：唯一原语

```rust
pub trait Store: Send + Sync {
    type Event: EventEnvelope;
    fn append(&self, event: Self::Event) -> Result<Seq, AppendError>;
    fn range(&self, from: Seq) -> Vec<Self::Event>;
    fn head(&self) -> Seq;
}
```

Store 是权威事实源，必须满足：

| 语义 | 约束 |
|---|---|
| append-only | 不提供 `update` / `delete`，更正以新事件表达 |
| 单写者 | 同一事实流串行追加，线程内 FIFO |
| 单调序号 | `seq` 严格递增且无跳号 |
| 幂等 | 重复事件身份或幂等键返回重复，不重复产生副作用 |
| 原子性 | 单事件要么完整写入，要么不写入 |
| 可重放 | 能按 `seq` 读取完整前缀 |

存储介质、索引、分片和压缩是实现细节，不进入 trait。非权威投影或记忆索引不得被当作
事实源，也不承担权威 Store 的写侧不变量。

## 3. Projection：签名约束

Projection 不是 trait。trait 只能规定方法，不能禁止实现读取时钟、写入外部状态或调用模型。
构造签名必须把纯度变成可检查的边界：

```rust
pub struct Projection<V> { /* 私有字段 */ }

impl<V: 'static> Projection<V> {
    pub fn new<F>(f: F) -> Self
    where F: Fn(&Event, Timestamp) -> V + Send + Sync + 'static;

    pub fn apply(&self, events: &[Event], now: Timestamp, budget: Budget) -> View<V>;
}

pub struct View<V> {
    pub value: V,
    pub degraded: bool,
    pub used: Budget,
}
```

Projection 必须满足：

1. **确定性**：同一事件前缀与同一 `now` 产生逐字节相同结果。
2. **无副作用**：不调用模型、不写 Store、不读墙钟、不访问外部可变状态。
3. **预算统一**：闭包只计算视图值，截断、降级和用量由 `apply` 统一处理。
4. **显式降级**：超预算返回 `degraded: true`，不以异常中断对话。
5. **不可伪造**：外部不能绕过唯一构造入口注册任意实现。

构造签名拦住直接传入 Store、时钟和主体句柄；静态检查补拦闭包体内的隐式全局依赖。
视图是参数，不是第二份状态；没有生产消费方的视图不得长期保留。

## 4. Actor：一等概念

```rust
pub struct ActorSpec {
    pub principal: Principal,
    pub pattern: Pattern,
    pub capabilities: Vec<Capability>,
    pub budget_ms: u64,
    pub scope: Scope,
}
```

模型与上下文不是独立字段：模型由模式选择，上下文由投影参数提供。

| 模式 | 决策来源 | 约束 |
|---|---|---|
| Decider | 规则与代码 | 确定性，适用于权限、判定、仲裁 |
| Reasoner | 模型 | 用于规划、生成与语义判断 |
| Translator | 输入事实到另一种表示 | 不创造信息，输出可溯源 |

模式按能力选择：可写成规则时用 Decider；只重述已有事实时用 Translator；否则用 Reasoner。
Actor 没有独立持久状态，只读取投影并经 Store 写回新事实。

### 4.1 时延预算

`budget_ms` 是事前约束，不只是事后统计。预算层必须限制可获得的依赖，使超预算调用在结构上
不可发生；无法结构限制的部分必须有运行期守卫和到点回退。

| 层 | 语义 | 模型边界 |
|---|---|---|
| Reflex | 即时规则反应 | 不得调用模型 |
| Fast | 快速分类 | 只允许有限空间判定，不开放生成 |
| Deep | 完整规划与工具 | 允许模型和工具 |
| Autonomic | 常驻、事件驱动 | 允许模型，按触发和预算运行 |

判据是时延，不是调用形式。禁止静默超时：到点必须产生正常事实或回退事实。

### 4.2 欲的治理

欲必须成为可审计事实，但不能直接变成执行动作。欲先形成候选意图，经授权、预算和策略
闸门后才能成为已批准任务。平凡值是关闭：关闭后系统退化为纯响应式且仍完整运行。

治理必须保证：想要的事项留痕、执行前批准、随时可关停、批准可溯源。

## 5. 控制面：一环、一表、一源

### 5.1 不动点模型

```text
state   = project(event_log, now)
action  = decide(state, trigger)
event_log.append(action.facts)
drive   = 反复计算“现在欠什么”，直到没有可执行债
```

- **单环**：所有能力共用一个控制面循环，事件到达后重新算债并执行，直到不动点。
- **一表**：策略行与能力行共用声明形状、排序和裁决规则，按消费方分目录存放。
- **一源**：状态只是日志投影，副作用只经 Store 追加；不存在旁路状态修改入口。

并发来自多个独立事实流和执行体内部批次，不来自驱动环自行共享可变状态。

### 5.2 一笔债

一笔债由以下声明表达：

| 字段 | 含义 |
|---|---|
| `owes` | 什么事实使债成立 |
| `key` | 按什么身份绑定债务 |
| `until` | 哪些事实偿还债务 |
| `unless` | 哪些事实使债务不再成立 |
| `reads` | 执行前必须存在的实例或非空视图 |

```text
open       = owes 成立 ∧ until 未命中 ∧ unless 未命中
ready      = reads 的每一项都有实例
actionable = open ∧ ready
next       = 按 (prio, name, key) 取最小可执行债
```

执行者、可执行性和归宿都从声明与事实派生：

- `owes` 指向端口开启侧时由通用受理口执行，否则由行注册表提供执行体。
- `reads` 是阻塞的唯一来源；不把“没人执行”伪装成永久阻塞。
- `until` 完整覆盖 `owes` 的行不产生债，用于声明归宿。

装载期必须验证依赖无环、每行有出口、执行体写入封闭、每个控制面事实都有归宿；任一失败
拒绝启动。时间只能由触发事件的时间戳或显式 `now` 参数进入视图，债公式不读墙钟。

### 5.3 端口

端口名是载荷，不是事件名或新机制。端口协议只使用 `request / sent / response / failed / retry`
五种事实，按 `(port, id, attempt)` 绑定；新增端口增加声明和适配器，不增加驱动循环分支。

流式帧、审批、用户补充和中止等外部输入必须先落事实或进入显式直通出口，再由同一控制面
重新算债。

## 6. 三条不变量

| 不变量 | 约束 | 主要判据 |
|---|---|---|
| I1 单通道 | 事实只经 Store 追加，主体间不直连 | `seq` 单调、每轮收束唯一、无旁路写入 |
| I2 无溯源不声明 | 断言与产出事实必须有来源 | `produced_by` 非空、指向更早存在的事实 |
| I3 到点必答 | 禁止静默超时 | 到点存在正常或回退事实 |

I2 的引用必须指向同一条日志中真实存在且序号更小的事实，因此派生图天然无环。权限与
可见域必须在第一条事实写入前生效，不能事后补建。

## 7. 事件语法

事件按“实体 × 动词”登记。核心实体与动词是封闭语法，事件实例是开放集合。

| 实体 | `opened` | `progressed` | `held` | `closed` | `asserted` |
|---|---|---|---|---|---|
| task | 创建、规划、分解 | 开始、推进、检查点、就绪、指派 | 阻塞 | 完成、失败 | 验证、返工、重规划 |
| artifact | — | — | — | — | `artifact.added` |
| verdict | — | — | — | — | `classify.verdict` / `classify.escaped` |
| memory | 编码 | 巩固 | — | 遗忘 | 召回、校准 |
| commitment | 提出 | — | — | 释放、违约 | 断言 |
| conation | 表达、提议 | 评估 | — | 撤销 | 批准闸结论 |
| thread | — | 检查点 | — | — | — |
| control | `task.controlled` | — | — | — | — |
| scope | 用户消息、消息编辑 | 轮次状态变化 | — | 助手终答、追加、回退 | 授权允许、拒绝 |
| system | 触发 | 健康 | — | — | — |
| message | `message.added` | `session.consolidated` | — | `message.removed` | `message.edited` |
| domain | 由领域 owner 声明 | 同左 | 同左 | 同左 | 同左 |

`domain` 是唯一领域扩展位。新领域由 owner 的 `EventDecl` 声明，内核不解释其具体名字，
也不在核心表逐项列举。新增事件必须能归入已有实体与动词，并有生产写方和消费方；无人
写或无人读的占位格必须删除。

`conation` 只记录表达、评估、闸门和撤销，不提供“欲直接执行”事件。`message` 的变化是闭集：
新增、编辑、移除和整体巩固已经覆盖消息列表生命周期。

## 8. 身份、能力与模式

| 维度 | 回答 | 形态 |
|---|---|---|
| Principal | 谁 | 事件主体身份 |
| Capability | 有权做什么 | 封闭能力枚举 |
| Pattern | 如何做 | Decider / Reasoner / Translator |

身份可随实例增长；能力与模式不随场景增长。授权由读写两侧共同构成：

- 写侧回答某主体能写哪些能力和事件类型；
- 读侧回答某主体能看到哪些作用域。

只有一侧视为授权不完整。主体间消息必须进日志，可见性由 `VisScope` 与读取授权共同决定；
跨主体共享是显式授权，不是默认继承。

## 9. 参数面

| 参数键 | 取值域 | 用途 | 平凡值原则 |
|---|---|---|---|
| `store` | `memory` / `wal` / `sharded` | 权威事实存储策略 | 最小可回放实现 |
| `projection` | `snapshot` / `display` / `readyset` / `turnstate` / `checkpoint` / `eval` / `recall` / `consolidate` / `reputation` / `calibration` / `budget` / `replay` / `skill_compile` / `conation` | 选择视图 | 仅保留评测所需视图 |
| `projection.param` | `consolidate:max_gen=<n>` / `consolidate:min_fidelity=<f>` / `recall:tag=<label>` / `recall:density=<n>` / `recall:layer=<n>` / `recall:spread=on` / `recall:decay=<fn>` / `recall:min_generality=<0–4>` / `readyset:cap=<n>` | 视图过滤、容量、代数与保真度 | 不改变核心生命周期 |
| `actor.pattern` | `decider` / `reasoner` / `translator` | Actor 模式 | Decider |
| `actor.capability` | `judge.intent` / `reply` / `define.work` / `produce.artifact` / `assert.verification` / `assign.work` | 授权能力 | 空集 |
| `actor.budget_ms` | `*` | 时延预算 | 保守完整预算 |
| `event.entity` | `↳ §7 实体` | 事件实体 | 由语法表约束 |
| `event.verb` | `↳ §7 动词` | 事件动词 | 由语法表约束 |
| `scope` | `root` / `child:<id>` | 主体树作用域 | 根作用域 |
| `vis_scope` | `thread_private` / `shared` / `public` | 可见域 | 私密 |
| `principal` | `*` | 主体身份 | 显式主体，不匿名 |

取值域用 `/` 分隔；`<…>` 是通配段，`*` 表示开放取值，`↳ §N` 指向本节的封闭集合。
新增取值只改本表，并须有生产消费方；参数不得只有声明没有读取。

新能力首先表达为既有参数取值。参数必须有生产消费方；只写不读的值不是机制，而是词表。
空集、单元素和多元素必须走同一规则，不得增加场景特例。

## 10. 记忆与检索

记忆类型是过滤参数，不是多套存储。工作记忆、情景记忆、语义记忆、程序记忆和预测都从
同一事实源投影或检索。

- embedding 是普通事实，索引属于 Store 实现；
- 检索读视图并产出可溯源召回事实，受可见域约束；
- 巩固必须同时受代数上界和源事实保真度约束；
- 遗忘是投影排除，不物理删除日志；
- 技能编译复用 Actor 与预算机制，异常时可回退到推理；
- 检索质量必须由可复现指标证明，不能由“已存入”推导。

## 11. 确定性边界

| 级别 | 承诺 |
|---|---|
| L0 投影确定 | 同一事件前缀得到同一视图 |
| L1 记录可重放 | 模型输出落事实后，重放读回已记录结果 |
| L2 重执行一致 | 不承诺；模型采样与外部世界会改变结果 |

崩溃恢复、审计和状态对比依赖 L0/L1。更换模型重新生成属于离线评测，不称为重放。

## 12. Agent 组织

一个 Agent 一个目录；系统 Agent 与子 Agent 同构，由同一插件容器装配。目录承载能力，
manifest 只承载身份、兼容性和权限。系统与子 Agent 的能力取并集，并以命名空间隔离；
装配顺序不得成为语义。

一个作用域只能有一个文件所有者。稳定指令与动态记忆必须物理和语义分离。目录协议与
权限细节见 [Agent 目录规范](011-Agent目录规范.md "DE-011-Agent目录规范")，VDFS 挂载见
[VDFS 规范](009-VDFS规范.md "DE-009-VDFS规范")。

## 13. 架构边界

- 不增加第二个权威事实源，不为主体间性能开直连旁路。
- 不让具体能力进入内核分支，不用实现困难改变机制边界。
- 不承诺重执行一致，不声称能力清单已经穷举。
- 不用迁移过程、模块清单或历史判例定义当前架构。
