# 最小闭环（对话基线）

## 内容

前置：无 ｜ **新增机制键 6** ｜ 参数变化 6 ｜ 阶段一

## 1. 场景：要什么能力

用户说一句话，系统回一句。**这是全部高阶能力的地面**——后面 12 阶都不是替代它，而是往它上面加。

这一阶的难点不在"接个大模型"，而在**闭环的四个端点必须同时成立**：

| 端点 | 要求 | 缺了会怎样 |
|---|---|---|
| 收到 | 用户消息成为一条事件 | 后面所有溯源无从谈起 |
| 思考 | 有一次生成动作 | 只是 echo |
| 发出 | 发言只有一条 final | 用户对同一句话收到两次回复 |
| 兜底 | 生成失败也要有输出 | 对话静默中断——**这是最常被漏掉的** |

## 2. 为什么它能落在 v2 上（J1）

四个端点全部是已有参数取值，不需要任何新类型：

- 收到 = `event.entity = turn` × `event.verb = opened`
- 思考 = `actor.pattern = reasoner`
- 发出 = `event.verb = closed` + `actor.capability = reply`
- 兜底 = `chat.assistant.fallback` 事件（网格里已有的一格，**不是特殊通道**）

**关键设计**：兜底话术也是一条普通事件。所以它可被 I2 审计（谁产生的）、可被元认知统计（兜底率多少）。
如果兜底走的是例外分支，它就永远逃出审计——这正是"静默失效"的典型形态。

## 3. 增量清单（只加数据）

| 类型 | 内容 |
|---|---|
| 事件格子 | `turn/opened`（`user.message`）、`turn/closed`（`chat.assistant.final`、`chat.assistant.fallback`） |
| ActorSpec 行 | `{ principal: "agent:main", pattern: reasoner, capabilities: [Reply], budget_ms: 300, scope: root }` |
| grants 行 | `agent:main` ▸ `reply` 写 |
| 投影参数 | `projection = snapshot`（≤1.5k tokens） |

**本阶点亮的机制键**（阶梯总表的「新增机制键」由这张块算出；`scripts/gen-verify-facts.mjs` 从这里取输入）：

```capability-assign

event.verb = closed
actor.pattern = reasoner
actor.capability = reply
actor.budget_ms = 300
projection = snapshot
```

## 4. 平凡值与回退（J2）

| 参数 | 完整值 | **平凡值** | 平凡值下系统是否完整运行 |
|---|---|---|---|
| `actor.pattern` | `reasoner` | **`decider`** | 是——规则应答仍产生 final，对话不中断 |
| `actor.budget_ms` | `300` | `60000` | 是——只是慢 |
| `projection` | `snapshot` | `turnstate` | 是——只看当前 turn |

**这一阶的平凡值是整个阶梯的地基**：把 `pattern` 退回 `decider`，系统退化成"规则应答机器人"，
但它**仍然是一个能完成对话的系统**。后面每一阶都要能退回这一阶。

## 5. 静默失效与强制（J3）

| 约束 | 违反时有无错误信号 | 强制方式 |
|---|---|---|
| 每 turn ≤ 1 条 final | **无**——用户只是收到两条回复 | CI 断言（`invariants.rs` 的 `I1DoubleFinal`） |
| 兜底必须产生事件 | **无**——超时后什么都没发生 | I3 断言：无事件且无 fallback = 违例 |
| 回复必须有 `produced_by` | **无** | I2 断言（`invariants.rs` 的 `I2NoProvenance`） |

三条全是"违反时没有测试会失败"的类型，所以必须第零天就做成 CI 断言。

## 6. 验收断言

1. 一条 `user.message` → 恰好一条 `turn/closed` 事件（`assert_eq!(finals, 1)`）。
2. 强制生成失败 → 必须存在 `chat.assistant.fallback`，且它的 `produced_by` 非空。
3. 投影两次运行结果逐字节相同（确定性）。
4. **反向用例**：注入两条 final → 断言 1 必须失败。
