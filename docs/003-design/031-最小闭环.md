# 最小闭环

最小闭环覆盖一条用户消息从输入、决策、应答到收束的事实路径。规范目标是一个 scope
只有一份最终答复，所有降级都可审计，事实投影可确定重放。

## 1. 输入与身份

用户输入先落事实，再触发能力；轮次不是环的输入。输入身份、scope 与触发来源由宿主
盖章，能力不能自行扩大授权或改用他根身份。

一次输入可以启动多条事实支路，但用户可见终答只允许 `chat.assistant.final` 一条。后续
输入必须晚于 `session.settled`，否则视为仍待处理。

## 2. 生成、回退与投影

生成与回退都是普通事实写入，携带来源、能力、触发事实与预算归属。回退不伪装成模型
输出，也不取消原请求；原请求仍按租约、失败或取消事实收束。

每个节点、消息与工具状态都从同一事实集合投影。重放只改变读取范围，不改变排序、字段
或终答判定。终答落库后，收束贡献关账；新的用户事实可使 scope 重新开放。

预算由能力层、会话配置与事件声明推导，行内不重复保存另一套额度。预算耗尽产生可见的
回退或停止结果，不把部分输出静默当成功。

## 3. 能力阶梯赋值

以下赋值只服务能力阶梯生成，不替代运行事实名与语义。

```capability-assign
event.entity = scope
event.verb = closed
actor.pattern = reasoner
actor.capability = reply
actor.budget_ms = 300
projection = snapshot
```

## 4. 平凡值与回退

| 参数 | 完整值 | **平凡值** | 平凡值下 |
|---|---|---|---|
| `actor.pattern` | `reasoner` | **`decider`** | 仍完整运行——规则应答仍产生终答，对话不中断 |
| `actor.capability` | `reply` | `reply` | 仍完整运行——本阶只有一种能力，没有更窄的取值可退 |
| `actor.budget_ms` | `300` | `60000` | 仍完整运行——只是慢 |
| `projection` | `snapshot` | `turnstate` | 仍完整运行——只看当前 turn |

无策略声明时使用 `decider`，但最终输出仍受单一终答与来源规则约束。能力阶梯中的
`closed` 是能力坐标，不替代 `session.settled` 的关账语义。

## 5. 必须钉住的规范

- 每个 scope 至多一条有效终答，重复终答请求被幂等键吸收。
- 回退携带真实来源与理由，可回放、可查询。
- 预算、能力权限与授权结论均来自声明或事实，不靠推测补全。
- 投影不依赖写入顺序之外的隐式状态。
