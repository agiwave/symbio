# 058 沙箱机制

## 横切句柄

- 沙箱是工具调用前的横切策略，不进入义务环，也不产生承诺事实。会话只保留 `sandbox_id` 作为选择。
- 架构层定义开放事实 `SandboxFact`、单次裁决 `SandboxDecision` 与 `SandboxFace` 句柄，
  不定义具体工具、策略或配置。
- 宿主在 `SANDBOX` 共享槽中发布一个实现。`sandbox_publish` 幂等，第二次发布失败，不替换首份句柄。
- 注册表没有成功加载可用快照时拒绝执行；显式选中的档案缺失或损坏也拒绝。
  未显式选档且已有良好快照时，可以保持无沙箱放行。
- 重载使用版本化快照；新档案未完整校验前继续使用旧的可用快照，不发布半成品。

## 单次决策

`SandboxFace::decide` 在同一档案快照内一次返回许可、风险、拦截、审批参数、阈值、版本与原因。
执行链不得把多次跨快照读取拼成一次许可。

- `permits` 回答策略许可，`risk_of` 回答动态风险，`intercept` 回答参数改写，审批参数单独返回。
- 风险阈值是最大自动放行风险，判定为 `risk <= threshold`。无人值守只改变失败处理，不提高阈值。
- 工具提交可安全解析的命令、子命令、重定向、路径、URL 等事实；解析失败时失败关闭。
- 路径按段比较，先折叠 `..`。物理写检查全部现存祖先；物理读拒绝已发现的链接与重解析点。
- 上述检查不能消除检查与使用之间的时间窗，本机制不声称进程级或容器级隔离。

## 审批

- 模型参数中的 `approved` 不是授权。只有宿主验证用户答复、`call_id` 与审批产物后才能签发
  一次性 `ApprovalGrant`。
- grant 绑定调用、规范化工具名、参数摘要、会话、档案版本和有效期。执行闸门原子消费。
- 改参、重放、过期或档案版本变化均拒绝；取消与背压不得降低这一要求。
- 并发领取使用进程内进行中集合；产物收束状态阻止顺序重放。沙箱不把审批状态写进义务环。

## VDFS 与凭据

- VDFS 管理调用携带可信 `VdfsCaller`。只有 Manager 能写、删或执行沙箱档案，Model 不能改策略。
- MCP 凭据字段与 URL userinfo 在对外投影前删除；投影失败不得回退为原文上送。
- 出站每一跳重新校验，禁用自动重定向。校验 scheme、完整主机、DNS 解析结果、
  Agent 域名授权与沙箱规则；连接钉住已校验公网地址并禁用代理。
- 管理员显式配置的 `web_search` 上游初始 origin 是唯一例外；模型不能选择地址，重定向仍按公网规则拒绝。
- Windows cmd 无法安全枚举插入符转义时失败关闭。

## 实现入口

- 句柄、事实、共享槽与单次裁决：`crates/symbio-platform/src/sdk/sandbox/mod.rs`。
- 档案加载、版本与策略执行：`crates/symbio-plugin-sandbox/src/engine.rs`。
- 审批验证与执行闸门：`crates/symbio-plugin-tool/src/port.rs`。
- 出站校验与代理：`crates/symbio-runtime/src/worker/broker.rs`。
