# 机制形状规格

本文只规定机制形状，不规定业务规则。局部性判据是：新增能力只改自己的能力包，受保护
机制树的非生成物 diff 为零，并通过 `LP-001`…`LP-005`。

## 1. 债表是带条件的数据

一行债由身份、触发与排除条件组成：

- 身份为 `(scope, port, id)`；`attempt` 是键的推进维度，不进入稳定身份。
- `id` 从产生该债的事实派生，禁计数。
- `after` 表达前置债，`when` / `when_id` 表达事实存在，`unless` 表达排除。
- `when_no_open` 与 `after_port` 只读债状态，不读引擎自述。

每圈从同一事实快照重算候选。真正的时序必须由谓词表达，不能依赖声明顺序。环不需要
认识行名、端口语义或业务条件，也不保存上一圈选债结果。

完整谓词闭集与当前债务表归 [DE-050](050-义务环事实词表与债务表.md "DE-050-义务环事实词表与债务表")。

## 2. 驱动边界

`drive` 同步穷尽环自己能做的动作，不阻塞等待用户、审批、外部答复或超时。正常出口为：

| 出口 | 条件 | 调用方义务 |
|---|---|---|
| `NoDebt` | 账上没有未收束债 | 可确认空闲 |
| `Waiting(outstanding)` | 仍有在飞债，环还能由回执或租约推进 | 不得记空闲或据此收口 |
| `NeedsHuman(outstanding)` | 环已无动作，只等外部事实 | 可交还控制权 |

安全阀出口 `Exhausted` 与 `Stalled` 表示驱动未正常完成：前者步数预算用尽，后者同一圈
没有新增 `(kind, key)` 事实。两者必须对宿主可见，并落 `driver.stalled` 通知；通知不得
再次触发驱动。

步数预算为 128。无进展按单圈差集判断，不数“连续若干圈”。

## 3. 派发、时钟与迟归

- `sent` 先于执行体落库，租约从 `sent.at_ms` 起算；执行体在后台运行，不阻塞 `drive`。
- 同圈执行体共享计划期事实快照，不读活账本；否则兄弟完成顺序会改变请求正文。
- `now` 取全部事实时间轴的最晚 `ts`，不读墙钟。时间推进必须落一条更晚的事实。
- 迟归整笔丢弃：attempt 已推进、同键已有终局或租约已过，均不再接收该执行体草稿。
- 候选按 `(row, debt_id, port)` 全序，消除装配顺序造成的偶然派发顺序。
- 重试按 `retry.row` 回到实际执行行；缺行则可见失败，不按表序顶替。
- 每个部署根只绑定一个驱动实例；等待方使用自己的根，不读进程级他根状态。

## 4. 流式

流式增量是 `PortExecContext.sink` 的瞬时帧，不是持久事实。每笔债只有一条终态
`response` 或 `failed`；终稿承载最终文本、领域事实与节点归属。丢帧不改变账本正确性，
节点由事实与终稿重建。

## 5. 同圈多笔债

互不依赖的候选可以在同圈派发；每一笔仍是独立债，依赖债必须等前置谓词满足。环侧
可同时持有多个在飞键，等待集合包含全部在飞债。

机制支持多笔派发不等于实际配置了多少并发。配置容量由宿主装配决定并归一为至少一；
提供者内部并发是另一层策略。端口接口与债表不增加批单元或并发度参数。

## 6. 终止由登记写方判定

终止不是驱动出口。往 `TERMINATION_FAMILY` 登记的能力有权观察同一份只读事实投影，
在驱动前后计算自己的谓词并提交终止事实草稿。

终止谓词必须看到终答，并确认本次驱动已穷尽且无未还债；同一 scope 的同一终止事实只能
落一次。终答的停止理由由终答写方拥有，终止事实原样继承，不另造第二套理由。

环不理解终止谓词；登记写方计算后提交普通事实，声明行可按事实种类用 `unless` 排除。
`session.settled` 表示收束贡献关账，`session.terminated` 表示整轮终止，二者不得合并。

## 7. 端口准入与写口

只有不可控、有延迟且可能失败的外部交互才能声明端口。本地存储、转写、纯计算与簿记
以事实或步内函数参与。装配期必须确认每个端口绑定有执行体、每个债行端口有提供者、
租约与尝试上限有限。

所有领域事实、协议事实与终止事实都经宿主唯一物理写口；执行体只交草稿。缺提供者、
未知读取或唯一前件生产者缺席都必须 fail-closed，不得以空结果伪装成功。

## 8. 形状门禁

- `LP-001`…`LP-005` 守住环纯度与端口通用性。
- 局部性门禁禁止新增能力改动受保护机制树。
- 分支选择是事实层纯函数：只读分支与选择标记，不依赖节点形状，也不迫使插件反向
  依赖呈现层。
- 同圈快照、确定性时钟、全序派发、迟归丢弃和单根单实例均须由 Rust 测试直接钉住。
