# 端口终态加严裁决

> 通用协议见 [DE-048-端口机制裁决](048-端口机制裁决.md "DE-048-端口机制裁决")，
> 环与写口不变量见 [DE-053-环驱动与写口裁决](053-环驱动与写口裁决.md "DE-053-环驱动与写口裁决")。
> 本页只规定动态端口的装配、执行与投影规则。

## 身份、描述与执行

- 端口名是内部身份，wire name 是模型侧别名。身份不受协议字符集支配，别名只对当轮快照有效。
- 端口名不得包含环事件 id 的保留分隔符 `:`；非法名字在注册期失败关闭，不转义、不猜测。
- 描述与执行必须同源装配。只有描述没有执行体的孤儿行不进入暴露清单；只有绑定没有描述的行不对外暴露。
- `PortBindings` 是装配期容器，每次装配新建；会话从宿主预置面复制新容器后继续收集，不得复用上一轮实例。
- 所有写入口经 `bind`。同名再登记把该键永久标为冲突，后续登记不能救回；快照读取时任冲突使整份装配失败。
- 工具注册经 `register_tool` 同次写端口绑定与工具数据行，共用 `CapabilityMeta`，不得维护两份注册事实。
- 作用域前缀同时作用于工具描述与端口绑定。派发名、描述名与执行体必须能按同一身份对应。

## 工具暴露与 wire 投影

- 本轮候选集是显式暴露、作用域允许与有效端口绑定三者的交集，并按注册序投影。
- wire 字符集与别名换算只归 model 的 `tool_projection.rs`。会话只转交候选身份，不实现协议命名规则。
- 两个内部身份映到同一 wire name 时，碰撞整组退出，并在请求成形前把原因写入 `session.config`。
  不得用返回时“精确匹配优先”掩盖歧义。
- 四个协议下行与模型调用回解读同一份别名表；工具执行仍使用内部身份。
- 工具身份与 wire 别名分离后，模型参数不得成为授权依据，工具名也不得成为通用审批分流条件。

## 调用、授权与结果

- 每次调用独立立债，幂等身份为 `(port, id, attempt)`。一批工具调用逐笔配对，续跑等待本次集合收束。
- 动态风险与授权在副作用前判定。`GatedExecutor` 是唯一通用审批闸门，结论写入 `PortOutcome.authz`。
  工具提供意图事实、动态风险与审批摘要；sandbox 通过 `ApprovalPolicy` 决定是否放行、拒绝、
  拦截或需审批以及可用授权范围；平台只验证并原子消费可信凭据，再转换既有执行信封。
  策略缺席时失败关闭。授权优先级、档案阈值与绑定语义见 [DE-058-沙箱机制](058-沙箱机制.md)。
- 参数原样交给执行体。端口层不解析、不补 `{}`、不把拒收折成成功，也不代工具做业务校验。
- 执行体先产出 `PortOutcome.facts`，读侧再投影模型消息或节点。业务失败保留为事实，协议失败进入错误分类。
- 轮边界簿记经 `after_port(plugin_row)` 表达；`tool.requested.calls[]` 的键契约由生产代码旁的契约测试守，
  不塞进机制词表。
- 取消、重试与恢复不改变授权语义。一次性批准绑定原调用，改参、重放、过期或当前沙箱档案
  `(profile_id, revision)` 变化均不得放行；恢复仍用完整意图事实重新裁决。

## 约束与实现入口

- 插件 `route` 不是第二条工具执行面；跨插件请求与工具执行分别走各自公开协议。
- session 冻结账由 `SRA-*` / `E-009` 自己守住，不计入端口迁移欠账。
- 端口容器与通用契约：`crates/symbio-platform/src/sdk/capability/port.rs`。
- 工具同源注册：`crates/symbio-platform/src/sdk/collectors/tool_visitor.rs`。
- wire 投影：`crates/symbio-plugin-model/src/tool_projection.rs`。
- 候选集与快照：`crates/symbio-plugin-session/src/plugin/round.rs`。
- 强制闸门与凭据消费：`crates/symbio-platform/src/sdk/collectors/approval.rs`。
- 审批策略与永久授权：`crates/symbio-plugin-sandbox/src/policy.rs`、`src/grants.rs`。
- 批准恢复与持久化策略绑定：`crates/symbio-plugin-tool/src/port.rs`。
