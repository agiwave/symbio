# 工具调用与产物

工具输出是普通事实；工具调用是独立端口债。一次模型响应中的 N 次调用形成 N 笔债，
分别授权、执行、配对和收束，不能合并成一次性“全部成功”事件。

## 1. 调用身份与产物

每次调用使用 `(port, id, attempt)` 债身份，`id` 由请求事实与调用 wire id 派生。重试不
创建第二份领域产物；同一幂等键的重复投递被宿主吸收。

产物落为 `artifact.added`，至少包含真实来源、调用身份、内容引用与成功状态。能力先
完成显式授权，宿主才允许产物事实落库。拒绝不得产生放行事实或产物；失败产物可以落
事实，但不得标记为成功。

## 2. 授权、超时与部分失败

授权是提供者显式给出的通用结论；环不解释授权载荷。拒绝、失败与超时分别进入可区分的
终局。超时必须产生可见降级或回退事实，不能把工具结果从模型上下文中悄悄抹掉。

同一批次的一笔调用失败不自动取消其它在飞债。需要取消或熔断时，由所属能力提交事实，
后续请求按这些事实重新判定。

## 3. 回到模型上下文

工具往返按请求 id、调用 id 与 attempt 配对。每笔调用以一条终态应答进入模型上下文，
包含匹配 id、真实结果或错误、来源与截断标记；不能用另一笔调用的结果顶替。

恢复按用户答复的调用 id 反查所属请求，不能取“最新请求”。同一调用的重复答复被幂等
键吸收；无匹配请求的答复不得恢复。

## 4. 上下文预算与呈现

模型上下文对每个工具输出分别截断，保留工具身份、结果类型与错误摘要，而不是整批
排除所有产物。投影与上下文读取同一事实，但展示层不得反向执行授权或修改产物。

运行状态按事实重建；文本增量只走瞬时出口。能力阶梯中的 `display` 不声明一个可写显示
节点，也不替代模型上下文中的工具往返事实。

## 5. 能力阶梯赋值

```capability-assign
event.entity = artifact
event.verb = asserted
actor.capability = produce.artifact
projection = display
```

## 6. 平凡值与回退

| 参数 | 平凡值 |
|---|---|
| `actor.capability` | **reply** |
| `event.entity` | `artifact` |
| `projection` | `display` |

无专门产物声明时，能力仍必须遵循事实产物、显式授权、逐调用配对与可见失败；阶梯
`reply` 不授予写工具产物的权限。
