# 多智能体社会

> **一句话**：一群智能体长期共存、按角色分工，有声誉有契约，能准入能淘汰——形成结构，而不只是点对点协作。
> 支撑能力：[T-133-多智能体社会](../009-task/133-多智能体社会.md)

## 场景

大量主体长期共存，长出组织的样子：有分工（市场 / 仲裁 / 守门）、有契约网络、
有声誉排序、有准入门槛，失效的主体会被淘汰，且淘汰可审计、可申诉。
今天的痛：智能体一多就是一锅粥——谁该干什么、谁可信、谁该退场，全靠人盯。

## 用户判据（诚实账）

| # | 用户应该看到 | 判据现状 |
|---|---|---|
| 1 | 多个主体按角色分工（市场 / 仲裁 / 守门） | 缺口：无判据（挂 [T-011](../009-task/011.md)） |
| 2 | 声誉读得出来，淘汰是可审计、可撤销的变更 | 缺口：角色分工无判据；声誉读数已有（e2e：t28 / t30）（挂 [T-011](../009-task/011.md)） |

## 边界

本场景今天基本是纸面：架构装得下，还没有一行把它接起来；
社会结构的涌现质量完全不由系统保证；博弈、激励、合谋检测是机制设计问题，系统层连断言都写不出。
