# 多步任务与返工

> **一句话**：一件活能拆成多步按序推进；某一步被验出不合格时，打回返工，而不是将错就错。
> 支撑能力：[DE-033-多步任务与返工](../003-design/033-多步任务与返工.md)

## 场景

用户交一件要分几步完成的活，智能体拆出待办、按先后依赖推进，模型不用每轮重述计划。
某一步被独立验证判为不合格时，产生返工而不是将错就错——历史不被改写，
被取代的步骤自然退出视野。今天的痛：一步到位的智能体做不了长活，中间错了也只能错到底。

## 用户判据（诚实账）

| # | 用户应该看到 | 判据现状 |
|---|---|---|
| 1 | 长任务的待办清单跨轮保持，不用每轮重述计划 | e2e：t55（多轮工具的跨轮记忆）（已有） |
| 2 | 步骤之间的先后序不乱，且能看到当前就绪的那几步 | e2e：t31；生产读数：会话统计的就绪列（已有） |
| 3 | "这一步该派谁做、做完由谁验" | 缺口：无判据（未立项） |

## 边界

不含并行抢占（各步骤串行）；任务不跨会话存续，进程重启即丢；
验证判得准不准不由系统保证——它只保证"有这么一次独立判定"。
