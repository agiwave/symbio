# 定时任务与自动巡检

> **一句话**：定好规则，它按时自己跑，跑完告诉我结果，出事才吵我。
> 支撑能力：缺口——未挂阶梯任务（场景交叉验证见 [PL-014-单环一表收敛](../004-plan/014-单环一表收敛.md)）

## 场景

时间 / 事件触发的无人值守运行：每天巡检一次服务、每周汇总一次开支、
备份前提醒确认。特征是**没有人发起请求**——由外部触发源唤醒，
且静默期不打扰（正常完成不通知，异常才通知）。

## 用户判据（诚实账）

| # | 用户应该看到 | 判据现状 |
|---|---|---|
| 1 | 触发历史可查：何时跑了、跑了什么、结果如何 | 缺口：无判据（挂 [T-011](../009-task/011.md)） |
| 2 | 失败可重试，且失败一定被告知 | 缺口：无判据（挂 [T-011](../009-task/011.md)） |
| 3 | 静默规则：正常不打扰，异常才通知 | 缺口：无判据（挂 [T-011](../009-task/011.md)） |

## 边界

不含服务器级调度器的高可用（本地优先角色的自然边界）；触发与静默是
策略选择，系统只保证「触发发生、历史留痕、异常可见」；自主发起目标
（不靠时间表）是另一件事，见 SC-012。
