# 长会话与断点恢复

> **一句话**：周五合上电脑，周一接着干——历史压缩了能翻回去，重启了能从断点继续，不从头再来。
> 支撑能力：[DE-035-长会话与断点恢复](../003-design/035-长会话与断点恢复.md)

## 场景

用户跟一个会话连续工作数小时甚至数天：历史太长会被自动压缩，但被压掉的内容仍能翻回去看；
中途进程崩溃或重启，编辑过、截断过的消息和"做到哪一步"都还在。
今天的痛：重启即失忆、从头再来，长会话变成一条不能回看的黑盒。

## 用户判据（诚实账）

| # | 用户应该看到 | 判据现状 |
|---|---|---|
| 1 | 会话长了自动压缩，压掉的内容仍能翻回去 | e2e：t8 / t11 / t45 / t47（已有） |
| 2 | 压缩过程本身是流式的，不是一条黑屏 | e2e：t18（已有） |
| 3 | 编辑 / 截断过的消息，重启后仍是编辑后的样子 | e2e：t44（已有） |
| 4 | "断点在第几步"能被读出来 | 生产读数：会话统计的断点列；e2e：t28（已有） |

## 边界

恢复的是"做到哪一步"，不是"学到了什么"——语义记忆是另一个场景的事；
"能恢复"不等于"能重现同样的模型输出"。
