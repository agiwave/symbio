# 深度研究与报告

> **未承诺（D-157）**：本草案已移出承诺清单，不在路线图内；重开条件见该决策。

> **一句话**：给它一个研究问题，它多源检索、交叉比对，给我一份带引用的报告。
> 支撑能力：缺口——未挂阶梯任务（场景交叉验证见 [DE-014-单环一表](../003-design/014-单环一表.md "DE-014-单环一表")）

## 场景

知识工作者的调研活：选型对比、竞品分析、文献综述。特征是多轮「检索 → 阅读 →
综合」的长循环，中途用户常要插话调整方向，最终产出是一份本地报告文档，
不是一句回答。

## 用户判据（诚实账）

| # | 用户应该看到 | 判据现状 |
|---|---|---|
| 1 | 报告里的关键结论带可回跳的引用源 | 缺口：无判据（未立项） |
| 2 | 长循环中途可插话纠偏，不丢已有进度 | 缺口：无判据（未立项；插话机制见 SC-007） |
| 3 | 报告作为产物落盘，可导出、可复用 | 缺口：无判据（未立项） |

## 边界

不含全网爬虫的合规与限流策略；不含团队协同评审；检索源的质量与覆盖是
provider 层选择，场景只要求「引用可回跳」这一交付形态。
