# 浏览器自动化操作

> **未承诺（D-157）**：本草案已移出承诺清单，不在路线图内；重开条件见该决策。

> **一句话**：让它替我操作网页——查单、填表、抓数，每一步留证据。
> 支撑能力：缺口——未挂阶梯任务（场景交叉验证见 [DE-014-单环一表](../003-design/014-单环一表.md)）

## 场景

登录态下的重复网页操作：查快递、填报销单、抓取后台数据。特征是**浏览器会话
状态跨步骤存活**（登录态、已填表单），且部分操作有真实后果（提交、支付），
需要先审批后执行。

## 用户判据（诚实账）

| # | 用户应该看到 | 判据现状 |
|---|---|---|
| 1 | 每一步操作有截图 / 证据留存，可回看 | 缺口：无判据（未立项） |
| 2 | 敏感操作（提交 / 支付 / 删除）先审批再执行 | 缺口：无判据（未立项；审批语义见 SC-009） |
| 3 | 中断后能续操作，登录态不要求重登 | 缺口：无判据（未立项） |

## 边界

不含验证码对抗；不含分布式抓取；浏览器实例的宿主形态（内嵌 / 借用系统浏览器）
是 provider 层选择，场景只要求会话状态可存活、证据可留存。
