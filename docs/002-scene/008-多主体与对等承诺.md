# 多主体与对等承诺

> **一句话**：几个身份各干各的、互不串包；彼此能立约，履约情况读得出来。
> 支撑能力：[GO-128-多主体与对等承诺](../001-goal/128-多主体与对等承诺.md)

## 场景

子智能体、对等智能体同时存在，各有各的身份和可见范围；对等体之间能立约——
承诺交付什么、何时交付，违约可被观测，声誉可被读出来。
今天的痛：多个智能体一上来就互相串话，说不清"这条是谁说的"，承诺了什么没有账。

## 用户判据（诚实账）

| # | 用户应该看到 | 判据现状 |
|---|---|---|
| 1 | 两个主体各说各的，转写里不会串包 | e2e：t30 / t39（已有） |
| 2 | 对等主体能立约，履约情况读得出来 | e2e：t71；生产读数：会话统计的声誉列（已有） |
| 3 | 子智能体在自己的空间里自驱动，不依赖外部有调用方 | e2e：t15（已有） |
| 4 | "这条是谁说的"按可见范围逐条过滤 | 缺口：无判据（未立项） |

## 边界

只记录"立了约、是否违约"，不保证守约质量；声誉怎么打分是算法问题；
组织形态（层级 / 市场）是多智能体社会场景的事，本场景只有点对点协作。
