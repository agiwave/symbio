## 内容

条目库（任务 / 规范 / 决策的单文档 + 生成投影）原本住仓根 `registry/`，
与本仓其余文字分在两处。迁到 `docs/`，并把「哪些判据管条目」从
**目录位置隐式决定**改成**代码里显式声明**——隐式的那条边界是这次迁移真正要消掉的东西。

## 处理过程

- 迁移本身是机械的，判定不是：`doc-link-audit` 的散文体检（D-002 / 003 / 004 / 006 / 008）
  此前从未判过条目，只因为 `registry/` 不在它的 `docs` 扫描根里。搬进 `docs/` 的第一遍
  就跑出 8 处命中（`## 处理过程` 里的「初版 / 曾经」、闭环条目引用的旧路径），
  证明这条适用范围一直是**位置给的**，没人声明过。
- 处置按 [ADR-056](../adr/ADR-056.md) 决策 3：散文体检整体豁免 `docs/`，
  **D-001 链接可达与 D-007 锚点照判**。豁免写成一个具名常量（`BODY_EXEMPT_DIRS`）
  而不是散在各判据里的 if，边界只有一处可改。
- 链接改写用「解析旧目标 → 应用迁移 → 重算相对路径」的脚本，不做文本替换：
  文本替换会把 `../`（已正确）和 `tauri/src/registry`、`~/.cargo/registry`
  （同名异物）一起改掉。反引号里的路径文本另走一遍**边界判定**（前一个字符不是
  路径字符才算路径开头）。
- 当场抓到一条真失效：T-008 的 `exit:` 写了 `docs/adr/ADR-*.md`——
  `refsIn` 只认 `docs/` 开头的路径，条目进 `docs/` 后这条**开始被 RG-012 验存在性**，
  glob 写法不是文件。改成「各立一条 `ADR-*.md`（住 `docs/adr/`）」后零违规。
- `docs/archive/` 里的旧路径**不回改**（归档是当时形态）；第一遍误改了 21 篇，已回退。
