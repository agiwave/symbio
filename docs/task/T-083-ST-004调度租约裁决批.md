## 内容

ST-004 §3.1 核实：本阶是全梯「文档≠系统」成色最高的一阶——

- `task/held` 在生产，但写方是 **S07 抢占路借来的**（`inbox.rs:336 → control.rs:90`），
  无 TTL、无发放方，不是租约；
- 正文的 `task.blocked / task.ready / task.assigned` 三个事件名**不存在**
  （`event/mod.rs:290-301` 只有五格）；
- `readyset` 无容量参数（模块头把容量推给「调用方的调度器」——该调度器不存在），
  §4 平凡值 `cap=1` 无处可调；
- §6 断言 1/3/4 **无执行方**。

要么调度器/租约是真目标（补事件名 = 动 core 词汇表，走 ADR），要么本阶的真实增量就是
「单写者 FIFO + 借来的 held」（那正文的叙事部分该删）。混着写会让下一轮把叙事当事实——
这正是各阶 §3.1 建制要消灭的形态，裁决不许再往后拖。
