## 内容

[ADR-063](../adr/ADR-063.md) 的裁决落实：会话线程的呈现合回**一个显示区域**。现状（分栏开启时）
`ModelChatPanel` 把同一条转写渲染成「对话 / 工作」两列，违反「一个会话线程一个
显示区域」的用户原则；单列形态已存在且长期验证（分栏关闭时即是），退役开关即
回归已验证行为。

边界（纪律）：

- **数据层零改动**：转写、读出口、`conversation_view` 后端投影与对话面插件不动；
  t24 的形状锚与本用例必须全绿；
- 前端镜像 `schemas/conversation_line.ts` 的去留按 [ADR-019](../adr/ADR-019.md) 的镜像纪律处理：
  分栏两列撤走后若前端无投影消费方，镜像登记相应撤除，不留下无主的副本；
- 黑盒纪律：判据取用户可见出口（界面形态 / 设置页 / 组件可见性），
  不新增后端白盒断言。
