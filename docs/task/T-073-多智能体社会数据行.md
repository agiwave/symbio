## 内容

[ST-013](../stage/ST-013-多智能体社会.md "ST-013-多智能体社会") 的整阶定义是「全部是已有键的新取值，新增机制键 = 0」——本任务就是兑现这句话的
**数据层**：角色 ActorSpec 行、每角色一行 grants（读写成对）、`vis_scope = public` 的公共域
行、以及「声誉投影低于阈值 ⇒ 收回 `assign.work`」的淘汰回路。前置的图侧通路（对等 offer /
assert / 会话独立角色）由 [T-072](T-072-对等主体生产增量.md "T-072-对等主体生产增量") 清偿。

判据对应 [ST-013](../stage/ST-013-多智能体社会.md "ST-013-多智能体社会") §6 四条：断言 1/2（声誉确定性、不认自报）已由
`symbio/src/symbio_core/actors/mod.test.rs` 覆盖；断言 3（淘汰可审计可撤销）与断言 4
的反向用例是本任务新补的部分。
