## 内容

`scripts/registry-lib.mjs`：`parent` 进 COMMON_OPTIONAL；KINDS 加 `retiredStates`（退场档，
与 `requiresDepsDone` 生效档成对）；RG-024（形状 / 存在 / 同 kind / 自指 / 成环）与
RG-025（子生效⇒父生效、父退场⇒子退场）两条判据；`topoOrder` 纳入 parent 边（分组表父子相邻）；
新增 `treeSection`（分解树小节）与 `parentDepth`（board 缩进）。
`scripts/registry-board.mjs`：`--children=<编号>`（子树递归孙辈）与 `--parent=<编号>`（父链），
组内按深度缩进。

## 处理过程

- 判据档位表复用 KINDS 现有配置：生效档 = `requiresDepsDone`（task `doing`/`done`，
  文档类 / spec / adr `active`），退场档 = `retiredStates`（task `done`/`wont`，文档类 / spec
  `retired`，adr `superseded`/`withdrawn`）——不新开档位概念，与 RG-008 同一张表。
- 「一个违规只红一条」：parent 含 `/` 时单文件段报形状错，跨文件段跳过（否则同一条违规
  红两次，`expectOnly` 式的测试纪律就破了）。
- 树小节**条件渲染**：该 kind 无 parent 数据时不出现——新机制对存量汇总页零回归。
