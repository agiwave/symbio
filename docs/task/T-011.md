## 内容

坐标系在 ADR-059 之后有了**刻度**，但刻度仍然只有观察口径的文字描述，没有可测的数字。
"跨会话可恢复""置信度经校准"这些说法在任何系统上都成立——正因为如此，它们不构成证据。

要补的是每条轴的**外部效标**（一个与系统内部实现无关的量），按可测性排序：

| 轴 | 候选读数 | 出口 |
|---|---|---|
| 时域跨度 | 可完成任务时长中位数（METR 式：人需要多久，这系统需要多久） | 新增一列 |
| 自我模型精度 | 校准误差（ECE / Brier）+ 说到做到率 | `calibration` 列已有口径 |
| 自主程度 | 每百步的请求次数 / 无人干预完成率 | 新增一列 |
| 主动性 | 自发发起且被采纳的比例（被否决 / 被忽略的算分母） | 新增一列 |
| 抽象层级 | 跨域迁移成功率（同一规则换一种表述是否仍成立） | 离线评测 |

**纪律**：读数没出来之前，§3.1 不得改写成"可测量"的口吻——设定的数字必须标"设定值"
（与 `docs/ref/RE-004-slo-calibration.md` 同一条规矩）。一条轴若一个读数都给不出，
在表里写明"本轴目前只能人工判"，比编一个数诚实。
