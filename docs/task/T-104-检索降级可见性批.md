## 内容

[T-085](T-085-记忆召回判据面补齐批.md "T-085-记忆召回判据面补齐批") 批②的核实结论：`recall` 投影的 `degraded`
（预算耗尽 ⇒ 降级 + 部分结果，S06 §6 验收 2 的 I3 形状）在投影侧已有执行方
（`recall.test.rs::exhausted_budget_degrades_…`），但**读方把它丢弃了**——
`v2_memory::recall_view` 取 `View::value`，`degraded` 与 `used` 一并留在
`View` 外壳里；注入段（`prompt_section`）因此无从标注。用户看不到「这轮记忆
只显示了一部分」。

这与 I3 的措辞「不允许空且不标降级」只差**出口**：今天的形态不是「空且不标」，
是「有部分结果且不标」——静默的形态变了，静默本身还在。ST-006 §7 该行因此
仍记 ❌。
