## 内容

`verify/capability_frame.rs` 验的是**文档之间**的一致（名册 ↔ 矩阵 ↔ 声明），
不验**文档 == 系统**：名册里 54 行能力，没有一条能回答"它在代码里是哪几行"。
于是"坐标系已归位"与"这条能力真的存在"在日志里长得一模一样——
这正是复盘 E6（验的是计划自洽，不是计划 == 代码）在坐标系上的残留面。

做法（形态已定，实现排期）：名册加一列「锚点」，取值是 `文件` 或 `文件::符号`（反引号形态，
`—` 表示"尚未落地"）；判据复用 `doc-symbol-audit` 的语料与 `D-005` 的提取形态，
**不新建第二份符号解析**。硬要求三条：

1. 已标锚点的行必须指得到——`—` 只允许出现在真的没落地的行上；
2. 判据的反向用例是"把锚点指向一个不存在的符号 ⇒ 红"；
3. 计数（已锚定 / 未锚定）进日志，使"名册在长、锚定率不动"这件事**看得见**。
