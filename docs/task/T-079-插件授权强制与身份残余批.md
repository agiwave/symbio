## 内容

[ADR-032](../adr/ADR-032.md) 自记两处「本期只定义不强制 /
本期不删」的期次债（`plugin_api` / `plugin_grants` 授权校验；`PluginMeta` 身份字段），
T-004 曾把姊妹清单判给「原表自持、不另登 task」——按本轮裁定，散落复选框不是登记，
归任务接管。依赖排序上与本批同族的 [T-078](T-078-shutdown接线批.md "T-078-shutdown接线批") 先行（两者同属宿主收尾/准入面）。

## 处理过程

- 2026-10-13 登记（ADR 全量复核发现：期次债无任务承载）。
- 2026-10-15 闭批：两处显式裁决 + 一处定案回写，**纯裁决批（零代码改动）**——
  ① **`plugin_grants` 维持声明式，写成终态判定**。理由：强制的判据是
  「越权声明装配即红」，而「越权」的前提是宿主侧有一套权限目录与插件的
  「需要」侧声明（init 协议，D5 未定案）——今天仓库内**没有外部插件**、
  没有「需要」侧数据，强行上运行期守卫或 gate 判据都是**机制先于消费者**、
  且判据只能对着空集永远绿（假覆盖）。ADR-032 决策⑤改为终态判定，撤销条件
  写明：D2 落地且出现真实「授予 < 需要」裁决需求 ⇒ 届时在装配层加守卫。
  ② **删除批不提前立项，归属 = A1**（AR-011 §11「下一期」，D2 定案后开工）。
  「一直停用、从未构造过的插件没有身份」写明不消解理由：现状等价而非退化
  （ADR-032 已记）；A1 属外部插件实施波次，现在登记只是把设计期条目提前成
  无产出的占位任务——归属已挂进 ADR-032 与 AR-011 §11 两处，不是无主债。
  ③ AR-011 §10 D3 定案回写「仅声明校验」，判据链指向 ADR-032 决策⑤。
  `T-000` 汇总与索引由 registry-audit 重生成。
