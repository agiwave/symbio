# 目标总览

目标回答「要达成什么」与「达成了没有」。这一层只有**三个大目标**，是同一个项目的三个问：

| 目标 | 问的是 | 答不了就 |
|---|---|---|
| [GO-001-产品目标](001-产品目标.md) | 用户得到什么 | 做完了一堆机制，没人用得上 |
| [GO-002-技术目标](002-技术目标.md) | 架构必须长成什么样才装得下 | 每加一项能力就重构一次 |
| [GO-003-工程目标](003-工程目标.md) | 怎么保证做对了 | 声称全绿，实际没有证据 |

更细的东西一律不在这里：**用户判据**在 [场景](../002-scene/README.md "SC-000-场景汇总")，**机制与取舍**在
[设计](../003-design/README.md "DE-000-设计总览")，**条文**在 [规范](../005-spec/README.md "SP-000-规范汇总")，**动作与进度**在
[任务](../007-task/README.md "T-000-任务汇总")。三个目标各自只持「必须成立什么」与「违反时哪条判据变红」——
判据数字引编号，不抄数：抄一遍就多一处漂移点。
