### 四类竞争威胁

#### 1. 传统生信培训（威胁：低）

- **代表**：生信技能树 / 生信宝典 / 各类速成班
- **特点**：本质是教材搬运——学了不会用是公认痛点
- **Symbiont 差异**：商业模式不在同一维度，更可能是教育用户后帮 Symbiont 收割

#### 2. 通用 AI 助手（威胁：中）

- **代表**：ChatGPT / 豆包 / Kimi / Claude
- **特点**：用户会先用这个，觉得「够用了」
- **Symbiont 差异**：无专业知识库、不记成长轨迹、无法验证结果对不对

#### 3. 专业生信流程平台（威胁：中）

- **代表**：Galaxy / Nextflow / OmicStudio
- **特点**：已有用户基础，自动化流程做得好
- **Symbiont 差异**：是工具不是老师——用户能跑出结果，但不知道为什么

#### 4. 大厂专项布局（威胁：高）

- **代表**：字节豆包 / 阿里通义 / 腾讯 专做生命科学方向
- **特点**：资金、流量、数据三样都有，进入速度快
- **Symbiont 差异**：大厂做垂直深度专业产品历史上不擅长
- **窗口期**：18-24 个月

## 护城河

```
护城河 = 专家隐性知识（独家）
       × 用户行为数据（私有）
       × 个人成长记录（不可迁移）
```

### 1. 专家隐性知识的独家提取

教科书只有 20% 显性知识。另外 80% 在专家脑子里：

```
「这个样本质量看着差但其实可以用，因为……」
「这个报错是已知 Bug，不是你的问题」
「这个 pathway 在这个癌种里没意义，文献都是凑数的」
```

这些东西不在互联网上。Symbiont 通过对话、工作流录制、访谈提取结构化入库。

**大厂有钱，但没有建立这批专家信任关系的渠道和时间。**

### 2. 用户踩坑数据的私有积累

每个用户的报错、走错的弯路、纠正的分析——这些是真实分析场景里的行为数据，不是公开数据。

积累到一定量后：

```
「你的样本有这个特征，历史上 47 个类似情况，
  其中 38 个都在这一步踩了同一个坑。」
```

这种预判能力是用户数量的函数，不是资金的函数。钱买不来，时间才能买。

### 3. 用户个人成长记录（锁定效应）

王雷的分析路径、犯过的错、能力水位——这些数据只在 Symbiont 里。

当他做下一个项目，他不会去用别的工具，因为迁移成本极高——知识积累和成长记录都留在这里了。

**这是最深的护城河：用户自己的历史，把自己锁在里面。**

### 飞轮效应

```
用户越多 → 踩坑记录越丰富 → 专家纠错越精准 → 对新用户越有价值 → 用户越多
```

## 专家知识注入 SOP

让专家用 Symbiont 走一遍真实流程——隐性知识不靠访谈，靠行为捕捉。

### 四层注入机制

```
┌─────────────────────────────────────────────────────────────────┐
│  01 专家操作层                                                  │
│  让他做，不让他教                                               │
│  专家用 Symbiont 完整走一遍 RNA-seq 流程                        │
│  屏幕录制 + 语音，在真实分析环境里操作                           │
├─────────────────────────────────────────────────────────────────┤
│  02 系统记录层                                                  │
│  捕捉停顿、修改、跳过                                           │
│  停顿 = 判断节点（这里有经验才能做的决策）                       │
│  修改 = 隐性标准（AI 输出没达到专家的预期）                      │
│  跳过 = 默会习惯（他觉得理所当然但新手不知道）                   │
├─────────────────────────────────────────────────────────────────┤
│  03 追问层                                                      │
│  在关键节点追问「为什么」                                       │
│  系统在停顿/修改处自动弹出：                                    │
│  「你刚才改了这一步，能说说原因吗？」                           │
│  这一刻说出的答案，就是平时无法被访谈触发的隐性知识              │
├─────────────────────────────────────────────────────────────────┤
│  04 知识提炼层                                                  │
│  结构化 → 审核 → 入库                                           │
│  回答被自动结构化为「场景 + 判断依据 + 结论」                   │
│  专家二次审核确认后写入知识库                                   │
│  多个专家交叉验证，浮现默会知识的共同影子                       │
└─────────────────────────────────────────────────────────────────┘
```

**结果**：1 位专家走完全流程 ≈ 注入数百条结构化隐性知识条目，比录课效率高 10×，且可持续迭代。

## 扩展路径

### Phase 1：生物信息学（立标杆）2026

基于中国市场核心用户群（见上文市场规模部分），覆盖分析方向：

- 🧬 转录组（bulk RNA-seq）— 最大用户群
- 🔬 单细胞转录组（scRNA-seq）— 增速最快
- 🗺️ 空间转录组 — 新兴，工具不成熟
- ⚗️ 蛋白质组学 — 需要质谱解读经验
- 🧫 基因组学（WGS/WES）— 变异解读复杂
- 📊 表观组学（ChIP/ATAC-seq）

### Phase 2：生物科研全域 2027

| 领域 | 痛点 | 切入方式 |
|------|------|----------|
| 结构生物学/计算化学 | AlphaFold2 结果不会解读，GROMACS 参数设置像炼丹 | 结构质量评估 + 参数推荐引擎 + MD 结果自动分析 |
| 生物统计/R 语言 | 统计方法选错，R 报错看不懂 | 统计方法决策树 + 假设自动验证 + SCI 图表规范审核 |
| AI 在生物医学应用 | 会调 API 但不理解模型 | 数据集评估 + 模型选型推荐 + SHAP/Grad-CAM 自动集成 |

### Phase 3：医疗/临床 2028

**关键前提**：先有口碑再进医疗。用户付费能力最强，但进入壁垒最高——生命科学 + AI 能力 + 医疗合规，三者缺一不可。

| 领域 | 痛点 | 切入方式 |
|------|------|----------|
| 临床科研统计 | 统计方法选错，不会写 Methods | 统计决策树 + SCI Methods 自动生成 + 审稿意见回应 |
| 医学影像 AI 辅助 | 模型众多不知选哪个 | 工具备信度数据库 + 结果解读辅助 + 临床标注工具 |
| 新药研发/临床试验统计 | ICH/FDA 规范要求高 | SAP 生成辅助 + SAS+R 双轨代码 + 数据质量自动审查 |

## 跨领域扩展潜力

适合 Symbiont 进入的领域，需同时满足：
1. 隐性知识密度高
2. 真实环境才能学会
3. 用户规模足够大

### 示例：法律领域

```
陈思，法学研究生，刚进律所。
合伙人让她看一份股权转让合同。
她用 AI 扫了一遍，AI 说「无明显法律风险」。
她交上去了。

合伙人沉默三秒：
「第11条的回购触发条件，和公司章程有冲突，你对过吗？」
她不知道要对。没有人教过她。

Symbiont 版本：
「第11条责任限额表述，历史上 6 次被认定无效。
  建议对照公司章程第 15 条检查冲突条款。」
这句提醒 = 合伙人10年的案感。
```
