## 核心用户群体

Symbio 的核心用户是**学术型生信分析者**，主要分为三类：

### 类型 A：初级研究员（Primary）

```
┌────────────────────────────────────────────────────────┐

├────────────────────────────────────────────────────────┤

│  · 结果解读困难，不知道如何写结论                      │
```

## 用户使用场景

### 场景 1：RNA-seq 分析（小林）

```
1. 小林上传 FASTQ 数据文件
2. Symbio 主动询问："这是双端测序数据，是要做 RNA-seq 差异表达分析吗？"
3. 小林确认，Symbio 自动生成分析流程模板
4. 小林按步骤执行，每步都有 AI 主动提示
   - 质控时：需要我帮你检查数据质量吗？
   - 比对时：检测到你有 GRCh38 参考基因组，用这个吗？
   - 差异分析时：你的实验设计是 case vs control，需要我生成 DESeq2 代码吗？
5. Symbio 自动记录所有参数和结果
6. 分析完成后，Symbio 主动提议："需要我帮你生成分析报告吗？"
```

### 场景 2：流程复用（张工）

```
1. 张工上传新的 ChIP-seq 数据
2. Symbio 识别数据类型："这是 ChIP-seq 数据，和你上个月做的项目类似，需要我复用之前的流程吗？"
3. 张工确认，流程自动生成
4. 张工调整几个参数，执行分析
5. Symbio 学习张工的调整偏好："我注意到你把 FDR 阈值改成了 0.01，以后都按这个来吗？"
```

### 场景 3：项目审阅（王教授）

```
1. 王教授打开学生提交的项目文档
2. Symbio 主动提供："这是差异表达分析项目，我来帮你总结关键结果..."
3. Symbio 展示结果摘要：样本数、DEG 数量、主要富集通路
4. 王教授可以直接在文档中批注
5. Symbio 识别批注内容，帮助学生改进
```

## AI 时代，还需要学这些知识吗？

> AI 让「不懂的人」和「懂的人」之间的差距，不是缩小了，而是扩大了。

### 三种知识，三种命运

| 知识类型 | 举例 | AI 之后的命运 |
|----------|------|---------------|
| **操作性知识** | 命令怎么写、参数是什么 | 大幅贬值 — AI 直接生成 |
| **判断性知识** | 结果对不对、选哪个方法、为何异常 | 升值 — AI 给结果，你来判断 |
| **方向性知识** | 问题值不值得做、实验怎么设计 | 大幅升值 — AI 根本没有这个能力 |

### 王雷的例子

```
AI 给王雷和任何人返回的是同一份 KEGG 富集结果。

第 6 周的王雷发现了错误：
「Cell cycle 排第一不对，背景基因设置有问题。」

没有领域判断力，这一页结果就直接写进文章了。
```
