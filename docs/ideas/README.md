## 核心定位

**Symbiont 是生信分析的学习平台，让你在做中学。**

- 看教程：先学后用，容易忘
- 问 ChatGPT：得到答案，不知道对不对
- Symbiont：边做边学，做过就记住

核心能力：
- **执行代码** - 在真实环境中运行，即时反馈
- **记录过程** - 学习过程可追溯，回头能看懂
- **复用流程** - 能力沉淀，不用重新学
- **验证结果** - 知道对不对，有信心
- **互动学习** - AI 陪你做，有问题随时问

## 关键调整说明

### 1. 核心定位：互动学习

```
原定位：更懂你的 AI 伙伴
新定位：在做中学的互动学习平台

核心价值：
  不是教你知识，是陪你做出来
  每次分析都是学习，每个流程都是能力沉淀
```

### 2. MVP 聚焦：验证学习效果

```
验证重点：
  ✅ 用户是否在真实环境中完成分析
  ✅ 用户是否从"不会"变成"会"
  ✅ 流程复用率是否足够高

不验证：
  ❌ 长期记忆
  ❌ 风格学习
  ❌ 隐性需求感知
```

### 3. 商业模式：免费学习 + 机构采购

```
个人版：免费（获取用户、形成口碑）
团队版：¥299/月（核心收入）
企业版：定制（高价值客户）

原因：
  - 学术用户付费意愿低
  - 免费用户形成口碑，推动机构采购
```
