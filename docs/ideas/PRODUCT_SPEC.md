## 界面布局

### 宽屏模式（桌面端）

```
┌──────────────────────────────────────────────────────────────────┐
│                          顶部工具栏                               │
├────────┬─────────────────────┬────────────────────────────────────┤
│        │                     │                                    │
│  导航  │       目录区        │           编辑区 + 学习区          │
│  条    │                     │                                    │
│        │  ┌───────────────┐  │  ┌─────────────────────────────┐   │
│  ┌───┐ │  │ 工作区切换    │  │  │                             │   │
│  │ 🔧│ │  ├───────────────┤  │  │      Markdown 编辑器        │   │
│  ├───┤ │  │               │  │  │      （代码块可执行）        │   │
│  │ ⚙️│ │  │   文档树      │  │  │                             │   │
│  └───┘ │  │               │  │  ├─────────────────────────────┤   │
│        │  │               │  │  │  💬 AI 互动学习区           │   │
│        │  └───────────────┘  │  │     [输入框]  [历史悬浮]    │   │
│        │                     │  └─────────────────────────────┘   │
├────────┴─────────────────────┴────────────────────────────────────┤
│                          状态栏                                   │
└──────────────────────────────────────────────────────────────────┘
```

- **左侧导航条**：垂直居中显示
  - 工作区入口
  - 系统设置
- **中间目录区**：
  - 工作区模式：顶部切换工作区，下方显示文档树
  - 系统模式：偏好设置、主题等
- **右侧主区域**：
  - 上部：Markdown 编辑器（代码块可执行）
  - 下部：AI 互动学习区
  - 右侧悬浮：学习历史

## AI 互动学习区

### 交互模式

1. **被动响应** - 用户主动提问，AI 回答
2. **主动提示** - 用户操作时，AI 给出相关建议
3. **协作执行** - AI 帮用户执行分析步骤
4. **错误诊断** - 执行失败时，AI 帮助诊断问题

### 交互组件

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│              Markdown 编辑区                        │
│              （用户主工作区）                        │
│                                                     │
│                                ┌─────────────────┐  │
│                                │  学习历史       │  │ ← 右侧悬浮
│                                │  （点击展开）   │  │   默认收起
│                                │                 │  │
│                                │  [用户] ...     │  │
│                                │  [AI] ...       │  │
│                                └─────────────────┘  │
├─────────────────────────────────────────────────────┤
│  🤖 [___________输入框（底部通栏）____________] [发送] │ ← 全宽输入
└─────────────────────────────────────────────────────┘
```

**默认模式（底部通栏输入）：**

- 输入框占据编辑区整个宽度
- 学习历史在右侧，有宽度限制
- 保持简洁，不干扰主工作区

**内联输入模式（局部交互）：**

当用户选中内容或 AI 需要针对特定位置交互时，输入框会出现在文档内部：

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  ## 差异表达分析                                    │
│                                                     │
│  我们使用 DESeq2 进行差异分析，                     │
│  阈值设置为 | 选中区域 ████████████ |              │
│                    ↓                                │
│              ┌─────────────────────────┐            │
│              │ [输入框] [发送] [关闭]  │ ← 内联输入 │
│              └─────────────────────────┘            │
└─────────────────────────────────────────────────────┘
```

### 输入框模式切换

| 模式 | 触发条件 | 输入框位置 |
|------|----------|-----------|
| 默认模式 | 无特定交互 | 底部通栏 |
| 内联模式 | 选中文本、点击错误提示 | 文档内部，就近显示 |
| 多轮对话 | AI 追问 | 保持当前位置 |

### AI 互动示例

```
用户：[选中一段代码]
AI：你选中了这段比对代码。
    · 解释这段代码
    · 帮我优化参数
    · 为什么这样写

用户：[点击"解释这段代码"]
AI：这段代码使用 HISAT2 进行序列比对...
    · hisat2 是常用的 RNA-seq 比对工具
    · -x 指定参考基因组索引
    · -1 -2 指定双端测序文件
    · -S 指定输出文件
    需要我详细解释某个参数吗？
```

## 文档树结构

### Notion 风格

文档树不同于传统的目录树，核心特点：

- **每个节点都是文档** - 没有"文件夹"的概念
- **文档可嵌套** - 任何文档都可以包含子文档
- **扁平存储，逻辑树状** - 通过引用关系构建树

**生信分析项目示例：**

```
📄 RNA-seq 差异表达分析
├── 📄 实验设计
│   ├── 📄 研究背景
│   └── 📄 样本信息
├── 📄 数据预处理
│   ├── 📄 原始数据 QC
│   ├── 📄 序列比对
│   └── 📄 表达定量
├── 📄 差异分析
│   ├── 📄 标准化处理
│   ├── 📄 DEG 筛选
│   └── 📄 可视化
└── 📄 功能注释
    ├── 📄 GO 富集
    └── 📄 KEGG 通路
```

### 文档数据模型

```typescript
interface Document {
  id: string;              // 唯一标识
  title: string;           // 文档标题
  content: string;         // Markdown 内容
  parentId: string | null; // 父文档 ID
  children: string[];      // 子文档 ID 列表
  createdAt: number;
  updatedAt: number;
  executions: Execution[]; // 执行记录
}

interface Execution {
  id: string;
  timestamp: number;
  code: string;
  status: 'success' | 'failed';
  output?: string;
  error?: string;
}
```


## 结果验证机制

### 三层验证

```
┌─────────────────────────────────────────────────────────────────┐
│                      结果验证三层次                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第 1 层：执行验证                                              │
│  ─────────────────                                             │
│  • 检查命令返回码是否为 0                                       │
│  • 检查预期输出文件是否存在                                     │
│  • 检查输出文件大小是否合理                                     │
│                                                                 │
│  示例：                                                         │
│  ✅ HISAT2 比对完成，输出文件 sample.bam (2.3GB)               │
│  ❌ HISAT2 执行失败：索引文件不存在                             │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第 2 层：逻辑验证                                              │
│  ─────────────────                                             │
│  • 样本数是否匹配设计                                           │
│  • 基因数量是否在合理范围                                       │
│  • 比对率是否正常                                               │
│                                                                 │
│  示例：                                                         │
│  ⚠️ 警告：检测到 5 个样本，但设计文档说有 6 个                  │
│  ⚠️ 警告：比对率仅 45%，可能存在数据质量问题                    │
│  ✅ 正常：检测到 25,000 个基因，在正常范围内                    │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第 3 层：领域验证                                              │
│  ─────────────────                                             │
│  • 差异基因数量是否合理                                         │
│  • 富集结果是否符合生物学预期                                   │
│                                                                 │
│  示例：                                                         │
│  ⚠️ 提示：差异基因数 8,500 个偏高，建议检查样本质量             │
│  ✅ 提示：检测到 TP53 差异表达，与研究方向相关                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
