- **左侧导航条**：垂直居中显示

- **中间目录区**：

  - 输入框

### AI 交互布局模式

**模式一：AI 独立栏显示**
- 右侧独立栏显示完整的 AI 对话历史
- 编辑区内使用悬浮输入框进行上下文相关交互
- 适合需要大量 AI 辅助的场景

**模式二：AI 独立栏隐藏**
- 编辑区占据更大空间
- 悬浮输入框仍可使用
- 右下角显示 AI 提示气泡，点击可展开
- 适合专注编辑的场景

## AI 交互系统

### 设计理念

AI 与文档编辑**有机整合，相对独立**：

1. **AI 独立栏** - 完整的对话历史，传统 AI 交互体验
2. **悬浮输入框** - 文档任意位置激活，上下文相关交互
3. **AI 提示气泡** - 右下角弹出，主动提示用户

### 组件一：AI 独立栏（可选显示）

```
┌─────────────────────┐
│   💬 AI 助手        │
├─────────────────────┤
│                     │
│  [用户] 请解释这段  │
│        比对代码     │
│                     │
│  [AI] 这段代码使用  │
│       HISAT2 进行   │
│       序列比对...   │
│                     │
│  [用户] 如何优化    │
│        参数？       │
│                     │
│  [AI] 建议调整...   │
│                     │
├─────────────────────┤
│  [____输入框____]   │
│  [发送]             │
└─────────────────────┘
```

**功能特点：**
- 完整对话历史，可滚动查看
- 支持复制、收藏、分享对话
- 可通过导航栏按钮显示/隐藏
- 隐藏时编辑区自动扩展

### 组件二：悬浮输入框

在文档编辑区任意位置激活的输入框：

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  ## 差异表达分析                                    │
│                                                     │
│  我们使用 DESeq2 进行差异分析，                     │
│  阈值设置为 |log2FC| > 1...                        │
│                                                     │
│              ┌─────────────────────────┐            │
│              │ 🤖 [___输入框___] [发送] │ ← 悬浮框  │
│              │     快捷键: Ctrl+K      │            │
│              └─────────────────────────┘            │
│                                                     │
│  比对完成后进行表达定量...                          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**激活方式：**
- 快捷键 `Ctrl+K` / `Cmd+K`
- 选中文本后自动弹出
- 点击错误提示触发
- 点击工具栏 AI 按钮

**智能定位：**
- 默认在光标位置附近显示
- 选中文本时在选区下方显示
- 自动调整位置避免遮挡内容

### 组件三：AI 提示气泡

AI 独立栏隐藏时，右下角显示提示信息：

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  （编辑区内容）                                     │
│                                                     │
│                                                     │
│                               ┌─────────────────┐   │
│                               │ 💡 建议使用     │   │
│                               │ 参数 --threads  │   │
│                               │ 加速比对        │   │
│                               │ [忽略] [采纳]   │   │
│                               └─────────────────┘   │
└─────────────────────────────────────────────────────┘
```

**触发场景：**
- 检测到可优化的代码
- 发现潜在的参数问题
- 分析结果有异常
- 提供学习建议

**交互行为：**
- 自动弹出，3秒后淡出
- 鼠标悬停保持显示
- 点击展开详情或执行建议

### 交互模式对比

| 模式 | 场景 | 组件 |
|------|------|------|
| **深度对话** | 需要多轮交互、查看历史 | AI 独立栏 |
| **快速问答** | 针对特定内容提问 | 悬浮输入框 |
| **被动提示** | AI 主动发现机会 | 提示气泡 |
| **协作执行** | AI 帮助执行任务 | 悬浮输入框 + 结果展示 |

### AI 交互示例

**场景：代码解释**

```
用户：[选中一段代码] + 按下 Ctrl+K
      ↓
悬浮框出现，预填充："解释选中的代码"
      ↓
AI：这段代码使用 HISAT2 进行序列比对...
    · hisat2 是常用的 RNA-seq 比对工具
    · -x 指定参考基因组索引
    · -1 -2 指定双端测序文件
    需要我详细解释某个参数吗？
      ↓
用户继续在悬浮框输入：解释 -x 参数
      ↓
AI：-x 参数指定参考基因组的索引路径...
```

**场景：AI 主动提示**

```
用户执行代码后，结果有异常
      ↓
AI 提示气泡弹出：
"⚠️ 比对率仅 45%，建议检查数据质量"
      ↓
用户点击气泡 → 展开详情
      ↓
AI 给出具体诊断和建议操作
```

## 文档树结构

### Notion 风格

文档树不同于传统的目录树，核心特点：

- **每个节点都是文档** - 没有"文件夹"的概念
- **文档可嵌套** - 任何文档都可以包含子文档
- **扁平存储，逻辑树状** - 通过引用关系构建树

**生信分析项目示例：**

```
📄 RNA-seq 差异表达分析
├── 📄 实验设计
│   ├── 📄 研究背景
│   └── 📄 样本信息
├── 📄 数据预处理
│   ├── 📄 原始数据 QC
│   ├── 📄 序列比对
│   └── 📄 表达定量
├── 📄 差异分析
│   ├── 📄 标准化处理
│   ├── 📄 DEG 筛选
│   └── 📄 可视化
└── 📄 功能注释
    ├── 📄 GO 富集
    └── 📄 KEGG 通路
```

### 文档数据模型

```typescript
interface Document {
  id: string;              // 唯一标识
  title: string;           // 文档标题
  content: string;         // Markdown 内容
  parentId: string | null; // 父文档 ID
  children: string[];      // 子文档 ID 列表
  createdAt: number;
  updatedAt: number;
  executions: Execution[]; // 执行记录
}

interface Execution {
  id: string;
  timestamp: number;
  code: string;
  status: 'success' | 'failed';
  output?: string;
  error?: string;
}
```

## 结果验证机制

### 三层验证

```
┌─────────────────────────────────────────────────────────────────┐
│                      结果验证三层次                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第 1 层：执行验证                                              │
│  ─────────────────                                             │
│  • 检查命令返回码是否为 0                                       │
│  • 检查预期输出文件是否存在                                     │
│  • 检查输出文件大小是否合理                                     │
│                                                                 │
│  示例：                                                         │
│  ✅ HISAT2 比对完成，输出文件 sample.bam (2.3GB)               │
│  ❌ HISAT2 执行失败：索引文件不存在                             │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第 2 层：逻辑验证                                              │
│  ─────────────────                                             │
│  • 样本数是否匹配设计                                           │
│  • 基因数量是否在合理范围                                       │
│  • 比对率是否正常                                               │
│                                                                 │
│  示例：                                                         │
│  ⚠️ 警告：检测到 5 个样本，但设计文档说有 6 个                  │
│  ⚠️ 警告：比对率仅 45%，可能存在数据质量问题                    │
│  ✅ 正常：检测到 25,000 个基因，在正常范围内                    │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第 3 层：领域验证                                              │
│  ─────────────────                                             │
│  • 差异基因数量是否合理                                         │
│  • 富集结果是否符合生物学预期                                   │
│                                                                 │
│  示例：                                                         │
│  ⚠️ 提示：差异基因数 8,500 个偏高，建议检查样本质量             │
│  ✅ 提示：检测到 TP53 差异表达，与研究方向相关                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
