## 2. Phase 1: L1 静态基建期

> 交付目标：拥有 100% 书本知识的问答机器。
> **参考工期**：2 - 3 周 (重点在于 RAG 基座与数据清洗)

### 2.1 存储与网络底座 (`Layer 1`)
```text
任务清单：
├── 定义模型基石
│   ├── CognitiveUnit 结构与种类体系构建
│   └── 序列化与数据层搬运脚本
│
├── 向量与关系库集成
│   ├── Qdrant VectorDB 环境集群准备
│   └── 关联网络 (Graph) 初始点与边存取
```

### 2.2 LLM基础链路与API
```text
任务清单：
├── 初级适配器
│   ├── OpenAI Embedding / Chat API 集成
│   ├── 简单 Prompt 组装
│
├── L1 级基础 REST API
│   ├── GET/POST `/units` - 记忆 CRUD
│   ├── POST `/search` - 近似度寻址查询
│   └── POST `/chat` - 触发基础对话
```

## 3. Phase 2: L2 逻辑反思期

> 交付目标：能拥有当前任务焦点，懂得“举一反三”的方法论助理。
> **参考工期**：4 - 5 周 (重点在于反思引擎与缓存分页逻辑)

### 3.1 动态短期记忆与环境感知 (`Layer 0`)
```text
任务清单：
├── 极速图谱缓存
│   ├── 为 Agent 提供内存级 (Redis/RAM) 的工作区 (Working Cache)
│   └── 并行处理当前的“长上下文焦点”
│
├── AgentState 情绪控制接入
│   ├── 建立疲劳值、自信度模型
│   └── API: PUT `/state/mood` 允许外源直接干预系统状态
```

### 3.2 抽象学习与深思机制
```text
任务清单：
├── 双系统推演
│   ├── 快响应机制 (System 1) 的就近直觉短路方案
│   └── 长逻辑链 (System 2) 的深层次关系图谱激活扩散巡查
│
├── 后台反思引擎 (Reflection)
│   ├── 将短期经验升维并压缩为大策略的重写逻辑
│   ├── 建立定时巡查触发器
│   └── API: POST `/reflection/trigger` 用于开发调优
```

## 4. Phase 3: L3 自主生长期

> 交付目标：主动挂机巡检互联网、并在后台疯狂偷师主人操作习惯的猎手。

### 4.1 端侧黑盒捕获
```text
任务清单：
├── 潜意识提取插件 (Shadow Observer)
│   ├── Mac / Windows 键盘鼠标焦点全局脱敏收集端
│   ├── VSCode / IntelliJ 开发者环境操作漏斗记录器
│   └── API: POST `/shadow/ingress` —— 高并发脱敏行为回传端点
```

### 4.2 猎犬机制
```text
任务清单：
├── 主动嗅探爬虫 (Foraging Engine)
│   ├── RSS、知名社区的自动检索钩子
│   ├── 夜间算力控制器的激活触发
│   └── 新知识校验与静默图谱扩增队列
```

## 5. Phase 4: L4 多元心智期

> 交付目标：遇到危险能像《头脑特工队》一样打内战商量的万无一失委员会。

### 5.1 沙盘辩论架构
```text
任务清单：
├── 子人格分裂器 (Persona Forks)
│   ├── 根据不同 `Judgment`（激进/保守/法律）生成对应人设 Prompt
│   ├── 为每个进程隔离分配独立的推理空间
│
├── 仲裁控制中心 (Orchestrator)
│   ├── 并发状态树监控
│   ├── Summary Node (聚合节点) 提纯收敛最终策略
│   └── API: POST `/society/interrupt` —— 监控台人工终止内讧
```

---

## 6. Phase 5: L5 架构跃迁期

> 交付目标：突破单人生理极限，打破代码定死的底座规则。

### 6.1 越级超变基因
```text
任务清单：
├── 跨域融合库 (Neural Synthesis Hub)
│   ├── 解析来自任意不相关领域专家包的元数据热拔插
│   ├── 跨领域重叠交叉校验防止认知崩溃
│
├── 元架构自重写 (Meta Rewrite)
│   ├── 开放 `RetrievalConfig` 的变异写权限
│   ├── 强制挂载 `cost_awareness_limit` 安全预算上限以防暴走
```
