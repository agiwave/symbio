## 1. 概念体系总览

```

├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  第一类：认知内容（Cognitive Content）                   │   │
│  │                                                         │   │
│  │  核心问题：存储什么？                                    │   │
│  │  建模方式：CognitiveUnit 数据结构                        │   │
│  │  包含类型：知识、经验、技能、判断、策略、直觉、情感       │   │
│  │  心理学来源：陈述性记忆、程序性记忆、隐性知识             │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              │ 被操作                            │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  第二类：认知过程（Cognitive Process）                   │   │
│  │                                                         │   │
│  │  核心问题：如何运作？                                    │   │
│  │  建模方式：系统机制 / 算法 / LLM能力                     │   │
│  │  包含过程：感知→记忆→注意→思维→语言→意识                │   │
│  │  心理学来源：认知心理学、信息加工理论                     │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              │ 被承载                            │

│  │  建模方式：技术架构 / 数据结构 / 接口                    │   │
│  │  包含组件：Agent、认知架构、认知单元、知识图谱、向量数据库│   │
│  │  技术来源：软件工程、AI架构设计                          │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 三类概念的区分原则

```
┌─────────────────────────────────────────────────────────────────┐
│                    三类概念的区分原则                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  判断标准：                                                     │
│                                                                 │
│  Q: 它是"被存储的信息"吗？                                      │
│     YES → 认知内容（用CognitiveUnit存储）                       │
│                                                                 │
│  Q: 它是"处理信息的方式"吗？                                    │
│     YES → 认知过程（用系统机制/LLM实现）                        │
│                                                                 │
│  Q: 它是"技术实现组件"吗？                                      │
│     YES → 系统实现（用技术架构构建）                            │
│                                                                 │
│  示例：                                                         │
│  ├── "DCF估值原理" → 认知内容（knowledge）                      │
│  ├── "记忆存储机制" → 认知过程（memory）                        │
│  └── "向量数据库" → 系统实现（技术组件）                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

```

│  └── 借阅处理 → 思维                                           │

│                                                                 │

```

## 2. 第一类：认知内容

### 2.1 总览

```
┌─────────────────────────────────────────────────────────────────┐
│                    认知内容总览                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  定义：个人大脑中可数字化存储的信息和知识                        │
│                                                                 │
│  核心特征：                                                     │
│  ├── 是"存储什么"的答案                                        │
│  ├── 用 CognitiveUnit 数据结构建模                              │
│  └── 是被认知过程操作的对象                                     │
│                                                                 │
│  七种类型：                                                     │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                         │   │
│  │   显性内容 (Explicit)          隐性内容 (Tacit)         │   │
│  │                                                         │   │
│  │   ├─ Knowledge                 ├─ Experience            │   │
│  │   │  概念、原理、事实          │  案例、教训、最佳实践   │   │
│  │   │  (语义记忆)                │  (情景记忆)            │   │
│  │   │                           │                         │   │
│  │   └─ Skill                     ├─ Judgment              │   │
│  │      流程、方法、步骤          │  原则、规则、价值观     │   │
│  │      (程序性记忆)              │  (经验内化)            │   │
│  │                               │                         │   │
│  │                               ├─ Strategy               │   │
│  │                               │  框架、策略、思维模式   │   │
│  │                               │  (元认知)               │   │
│  │                               │                         │   │
│  │                               ├─ Intuition              │   │
│  │                               │  模式识别、快速判断     │   │
│  │                               │  (自动化认知)           │   │
│  │                               │                         │   │
│  │                               └─ Emotion                │   │
│  │                                  偏好、风格、动机       │   │
│  │                                  (情感记忆)             │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  个人核心竞争力：隐性内容（LLM无法从通用训练中获得）            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 Knowledge（知识）

```
┌─────────────────────────────────────────────────────────────────┐
│                       Knowledge（知识）                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  定义：可编码、可传递的事实、概念、原理和规则                    │
│                                                                 │
│  【心理学基础】                                                  │
│  ├── 对应：语义记忆 (Semantic Memory)                          │
│  ├── 特点：关于世界的一般性知识，不依赖于特定情境               │
│  └── 存储：在大脑中组织为概念网络                               │
│                                                                 │
│  【特征】                                                        │
│  ├── 相对客观：可验证真伪                                       │
│  ├── 可传递：可通过文档、教学传递                               │
│  ├── 结构化：有明确的概念体系和逻辑关系                          │
│  └── 通用性：可在不同情境中迁移应用                              │
│                                                                 │
│  【子类型】                                                      │
│  1. 事实性知识：具体事实（"DCF是现金流折现模型"）              │
│  2. 概念性知识：抽象概念（"估值模型的分类"）                   │
│  3. 原理性知识：因果原理（"价格围绕价值波动"）                 │
│  4. 条件性知识：应用条件（"何时用DCF估值"）                    │
│                                                                 │
│  【与LLM的关系】                                                 │
│  ├── Level 0-1：LLM已覆盖，无需存储或仅补充                    │
│  ├── Level 2：项目特定，需存储                                 │
│  └── 存储重点：个人视角的独特见解                               │
│                                                                 │
│  【CognitiveUnit结构】                                          │
│  ├── summary：核心知识摘要                                       │
│  ├── body：详细内容（可包含公式、图表）                          │
│  ├── context.triggers：激活触发词                                │
│  └── generality：通用度分级                                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 Experience（经验）

```
┌─────────────────────────────────────────────────────────────────┐
│                       Experience（经验）                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  定义：在特定情境中通过实践获得的知识和判断力                    │
│                                                                 │
│  【心理学基础】                                                  │
│  ├── 对应：情景记忆 (Episodic Memory)                          │
│  ├── 特点：与特定时间、地点、情境绑定的个人经历                 │
│  └── 存储：以事件-情境-结果的形式组织                           │
│                                                                 │
│  【特征】                                                        │
│  ├── 情境依赖：与特定场景、时间、条件绑定                      │
│  ├── 个人化：难以完全传递给他人                                │
│  ├── 可迁移性有限：需要类比推理才能应用                        │
│  └── 包含情感：常带有成功喜悦或失败教训                        │
│                                                                 │
│  【子类型】                                                      │
│  1. 成功案例：什么做法有效                                      │
│  2. 失败教训：什么做法无效/有害                                 │
│  3. 最佳实践：经过验证的有效做法                                │
│                                                                 │
│  【存储价值】                                                    │
│  ├── 经验是个人核心差异化能力                                   │
│  ├── LLM无法从通用训练中获得                                    │
│  ├── generality通常为Level 3                                   │
│  └── 需要完整存储                                               │
│                                                                 │
│  【CognitiveUnit结构】                                          │
│  ├── 情境：事件发生的背景和条件                                 │
│  ├── 行动：个人采取的做法                                       │
│  ├── 结果：行动的后果                                           │
│  ├── 教训：总结的经验要点                                       │
│  └── 可迁移性：可应用的类似情境                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.4 Skill（技能）

```
┌─────────────────────────────────────────────────────────────────┐
│                         Skill（技能）                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  定义：完成特定任务的操作能力和方法程序                          │
│                                                                 │
│  【心理学基础】                                                  │
│  ├── 对应：程序性记忆 (Procedural Memory)                      │
│  ├── 特点：知道"怎么做"，通过练习获得自动化                    │
│  └── 存储：以条件-行动规则(产生式)的形式组织                    │
│                                                                 │
│  【特征】                                                        │
│  ├── 可执行：有明确的操作步骤                                   │
│  ├── 可练习：通过重复练习提高熟练度                            │
│  ├── 程序性：知道"怎么做"                                      │
│  └── 层次性：有基础技能和高级技能之分                           │
│                                                                 │
│  【子类型】                                                      │
│  1. 认知技能：分析、推理、决策                                  │
│  2. 专业技能：估值建模、研报撰写、数据分析                      │
│                                                                 │
│  【与Knowledge的区别】                                           │
│  ├── Knowledge：知道"是什么"                                   │
│  └── Skill：知道"怎么做"                                       │
│                                                                 │
│  【CognitiveUnit结构】                                          │
│  ├── 目标：技能要达到的结果                                     │
│  ├── 前提条件：执行技能所需的条件                               │
│  ├── 步骤：具体的操作流程                                       │
│  ├── 要点：关键注意事项                                         │
│  └── 输出：技能产生的结果                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.5 Judgment（判断）

```
┌─────────────────────────────────────────────────────────────────┐
│                        Judgment（判断）                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  定义：在复杂情境中做出决策的原则、规则和价值观                  │
│                                                                 │
│  【心理学基础】                                                  │
│  ├── 来源：经验内化 + 个人价值观                               │
│  ├── 特点：包含主观偏好，是个人决策风格的核心                   │
│  └── 形成：大量实践后形成的直觉性原则                           │
│                                                                 │
│  【特征】                                                        │
│  ├── 主观性：包含个人价值观和偏好                              │
│  ├── 情境敏感：不同情境适用不同判断标准                        │
│  ├── 权衡性：常涉及多个因素的权衡取舍                          │
│  └── 经验依赖：基于大量实践形成的直觉性原则                    │
│                                                                 │
│  【子类型】                                                      │
│  1. 评估性判断：对事物价值的评估                                │
│  2. 诊断性判断：对问题原因的分析                                │
│  3. 决策性判断：对行动方向的选择                                │
│  4. 预测性判断：对未来发展的预判                                │
│                                                                 │
│  【个人核心竞争力】                                              │
│  ├── 判断力是区分专业人士和新手的关键能力                          │
│  ├── 包含个人的价值观和思维偏好                                 │
│  ├── generality通常为Level 4                                   │
│  └── 必须完整存储                                               │
│                                                                 │
│  【CognitiveUnit结构】                                          │
│  ├── 情境：判断适用的场景条件                                   │
│  ├── 标准：判断的依据和准则                                     │
│  ├── 权重：各因素的相对重要性                                   │
│  ├── 决策：建议的行动方向                                       │
│  └── 理由：判断的内在逻辑                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.6 Strategy（策略）

```
┌─────────────────────────────────────────────────────────────────┐
│                        Strategy（策略）                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  定义：解决问题或实现目标的系统性思维框架和方法论                │
│                                                                 │
│  【心理学基础】                                                  │
│  ├── 对应：元认知策略 (Metacognitive Strategy)                 │
│  ├── 特点：高阶认知，控制其他认知过程                           │
│  └── 存储：以目标-原则-步骤的形式组织                           │
│                                                                 │
│  【特征】                                                        │
│  ├── 系统性：整合多个知识和技能                                 │
│  ├── 目标导向：服务于特定目标                                   │
│  ├── 灵活性：可根据情境调整                                     │
│  └── 高阶性：属于元认知层面的思维模式                           │
│                                                                 │
│  【子类型】                                                      │
│  1. 问题解决策略：如何分析和解决问题                            │
│  2. 学习策略：如何获取和整合新知识                              │
│  3. 决策策略：如何在不确定条件下做决策                          │
│  4. 沟通策略：如何有效地表达和传递信息                          │
│                                                                 │
│  【与Skill的区别】                                               │
│  ├── Skill：具体操作方法，"怎么做"                             │
│  └── Strategy：思维框架，"怎么想"                              │
│                                                                 │
│  【CognitiveUnit结构】                                          │
│  ├── 目标：策略要实现的目标                                     │
│  ├── 原则：策略的核心指导思想                                   │
│  ├── 步骤：策略的实施阶段                                       │
│  ├── 工具：策略使用的方法和工具                                 │
│  └── 案例：策略应用的具体例子                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.7 Intuition（直觉）

```
┌─────────────────────────────────────────────────────────────────┐
│                        Intuition（直觉）                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  定义：基于大量经验积累的快速、自动化判断能力                    │
│                                                                 │
│  【心理学基础】                                                  │
│  ├── 来源：程序性记忆的自动化 (Automaticity)                   │
│  ├── 特点：模式识别，无需显式推理                               │
│  └── 形成：新手→熟练→专业→精通的技能内化过程                         │
│                                                                 │
│  【直觉形成过程】                                                │
│  新手阶段 → 显性知识 → 有意识应用                               │
│      ↓ 大量实践                                                  │
│  熟练阶段 → 程序化 → 半自动执行                                 │
│      ↓ 继续积累                                                  │
│  专业阶段 → 直觉化 → 自动模式识别                               │
│                                                                 │
│  【特征】                                                        │

### 7.4 检索引擎：认知单元的激活与选择

```
┌─────────────────────────────────────────────────────────────────┐
│                    检索引擎设计                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  功能：从认知单元库中检索与当前任务相关的内容                   │
│                                                                 │
│  检索流程：                                                     │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                         │   │
│  │  Step 1: 向量检索（语义相似度）                         │   │
│  │  ├── 输入：用户查询/任务描述                            │   │
│  │  ├── 处理：向量化 → 相似度搜索                          │   │

│  │  ├── 输出：扩展的认知单元集合                           │   │
│  │  └── 算法：BFS/DFS + 激活强度衰减                       │   │
│  │                                                         │   │
│  │  Step 3: 相关度排序                                     │   │
│  │  ├── 因素：语义相似度 + 激活强度 + 重要性 + 时效性      │   │
│  │  ├── 公式：Score = α·Sim + β·Act + γ·Imp + δ·Time      │   │
│  │  └── 输出：排序后的认知单元列表                         │   │
│  │                                                         │   │
│  │  Step 4: 容量控制                                       │   │
│  │  ├── 原则：控制注入数量，避免上下文过载                 │   │
│  │  ├── 限制：总token数 < LLM上下文窗口的30%              │   │
│  │  ├── 策略：按类型比例选择（各类型均衡）                 │   │
│  │  └── 输出：最终注入的认知单元列表                       │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  检索策略矩阵：                                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  任务类型      │ 检索重点类型        │ 检索深度        │  │
│  │  ──────────────────────────────────────────────────────  │  │
│  │  知识问答      │ knowledge           │ 浅层（1-2跳）   │  │
│  │  决策支持      │ judgment + exp      │ 中层（2-3跳）   │  │

│  └──────────────────────────────────────────────────────────┘  │

└─────────────────────────────────────────────────────────────────┘
