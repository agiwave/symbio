## 关键设计原则提示

1. **`04-核心概念词典` 是所有概念的唯一权威来源**，任何其他文档中的概念描述均应以它为准
2. **`05` 定义"是什么能力"，`03` 定义"怎么实现"**，两者按需互相引用但不重复
3. **`01` 是设计意图文档（Why + What），`02` 是实现规格文档（How）**，分层不混用
