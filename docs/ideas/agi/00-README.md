## 关键设计原则提示

1. **`04-核心概念词典` 是所有概念的唯一权威来源**，任何其他文档中的概念描述均应以它为准
2. **`05` 定义"是什么能力"，`03` 定义"怎么实现"**，两者按需互相引用但不重复
3. **`01` 是设计意图文档（Why + What），`02` 是实现规格文档（How）**，分层不混用
4. **`07` 和 `08` 是专家核心特征的完整定义**，工具能力（外部增强）与模型能力（内部增强）互补，共同贯穿 L1-L5 各阶段
5. **`09-应用场景全景` 明确系统的能力边界**，"能做什么"和"不能做什么"同样重要，帮助用户合理预期
6. **系统支持独立模式和 Agent 模式**：可先独立使用（存储/检索/展示），再结合 LLM（问答/决策/生成），两条路径共用同一套数据结构，可平滑演进
7. **核心概念有心理学基础**，七种认知类型源自记忆系统理论，但 Intuition/Emotion 的类型化存在理论争议（详见 04 文档 0.3 节），需要实践验证

## 🚀 快速参考

### 核心概念速查
- **L1-L5**：能力演进阶梯（详见05文档）
- **七种认知类型**：Knowledge, Experience, Skill, Judgment, Strategy, Intuition, Emotion
- **双系统思维**：System 1（直觉）和 System 2（理性）
- **工作记忆**：短期活跃记忆，容量有限
- **长期记忆**：永久存储，通过检索激活

### 开发阶段速查
- **L1**：基础存储检索（2周可交付）
- **L2**：关联推理+双系统（+4周）
- **L3**：主动学习+影子监听（+8周）
- **L4**：多心智辩论+工具编排（+12周）
- **L5**：超参重写+跨域融合（+16周）

### 常见问题
1. **从哪里开始？** → 从01文档开始，然后05文档
2. **概念不清晰？** → 查阅04文档（权威来源）
3. **如何实现？** → 查看02文档（技术方案）
4. **开发计划？** → 查看03文档（路线图）
5. **能做什么？** → 查看09文档（应用场景）
