## 关键设计原则提示

1. **`04-核心概念词典` 是所有概念的唯一权威来源**，任何其他文档中的概念描述均应以它为准
2. **`05` 定义"是什么能力"，`03` 定义"怎么实现"**，两者按需互相引用但不重复
3. **`01` 是设计意图文档（Why + What），`02` 是实现规格文档（How）**，分层不混用
4. **`07` 和 `08` 是专家核心特征的完整定义**，工具能力（外部增强）与模型能力（内部增强）互补，共同贯穿 L1-L5 各阶段
5. **`09-应用场景全景` 明确系统的能力边界**，"能做什么"和"不能做什么"同样重要，帮助用户合理预期
6. **系统支持独立模式和 Agent 模式**：可先独立使用（存储/检索/展示），再结合 LLM（问答/决策/生成），两条路径共用同一套数据结构，可平滑演进
