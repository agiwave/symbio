# Symbio 文档维护指南

> 本指南规范Symbio认知架构项目文档的创建、更新和维护流程，确保文档质量一致性。

**版本**：1.0  
**生效日期**：2024年1月  
**适用范围**：所有项目文档

## 📋 文档体系概览

### 文档分类
1. **核心设计文档** (必读)
   - 01-认知架构模型.md
   - 04-核心概念词典.md
   - 05-能力演进体系.md

2. **技术实现文档** (开发者)
   - 02-技术实现方案.md
   - 03-实施路线图.md
   - 07-工具能力体系.md
   - 08-模型能力体系.md

3. **应用与评估文档** (业务)
   - 06-行业评估报告.md
   - 09-应用场景全景.md
   - 10-历史发展分析.md

4. **支持文档** (工具)
   - 00-README.md (导航)
   - 术语索引.md (参考)
   - 文档模板.md (模板)

### 文档关系原则
1. **权威性**：04文档是所有概念的权威来源
2. **引用性**：其他文档必须引用04文档中的概念定义
3. **分工性**：各文档有明确分工，不重复描述
4. **一致性**：术语、格式、风格必须统一

## ✅ 质量标准

### 格式标准
1. **标题层级**
   - `#` 文档标题
   - `##` 章节标题
   - `###` 小节标题
   - `####` 子小节 (尽量避免)

2. **代码块**
   ```rust
   // Rust代码
   ```
   ```yaml
   # YAML配置
   ```
   ```json
   // JSON数据
   ```
   ```text
   // 纯文本
   ```

3. **表格**
   ```markdown
   | 列1 | 列2 | 列3 |
   |-----|-----|-----|
   | 内容 | 内容 | 内容 |
   ```

4. **列表**
   - 有序列表：`1. `, `2. `
   - 无序列表：`- `, `* `
   - 任务列表：`- [ ]`, `- [x]`

### 内容标准
1. **术语一致性**
   - 使用04文档中的定义
   - 首次出现时简要说明
   - 重要术语加粗强调

2. **引用规范**
   - 内部文档：`[文档名](./文件名.md)`
   - 外部资源：`[描述](URL)`
   - 章节引用：`[章节名](#锚点)`

3. **示例要求**
   - 示例必须完整可运行
   - 提供必要的上下文
   - 说明预期结果

## 🚨 常见问题处理

### 问题1：术语不一致
**处理流程**：
1. 检查04文档中的定义
2. 更新不一致的文档
3. 通知相关作者

### 问题2：链接失效
**处理流程**：
1. 检查链接目标是否存在
2. 更新或移除失效链接
3. 记录在变更日志中

### 问题3：内容过时
**处理流程**：
1. 标记为需要更新
2. 安排更新计划
3. 更新后验证准确性

### 问题4：格式错误
**处理流程**：
1. 使用检查工具识别
2. 按照标准修复
3. 预防性培训
