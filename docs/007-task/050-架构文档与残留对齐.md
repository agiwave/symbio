# 架构文档与残留对齐

> 对应架构分析：**P6（文档类）**。
> 架构批第 1 笔。纯文档，不碰行为，可插在 `D-381` 之前。

## 内容

三处文档与代码不一致，直接影响后面所有架构讨论的可读性：

1. **018 是 v1 视图**：§2 的模块图与 §3 的「六个模块」表写的是
   `interface` / `actors` / `projections` / `store` / `adapters` / `governance`，
   与今天 `crates/` 的实际分层（kernel / sdk / plugin-api / host / 插件 / provider / 装配）
   不是同一套语言。重写成当前 crate 集的视图，保留「依赖单向」与「谁守哪条不变量」两节
   仍成立的部分，删掉目录级的过时描述。
2. **002 漏两层**：§目录分工 只列 kernel / sdk / plugin-* / provider-* / symbio。
   `symbio-host`（运行时层）与 `symbio-plugin-api`（扩展层唯一宿主依赖）必须各自成条，
   不能只作为插件段的括号说明存在。
3. **`symbio_core` 残留**：crate 已整体并入 `symbio-sdk`（D-279），但活跃区仍有
   73 处 / 52 个 `.rs`（全是注释）与 118 处 / 27 个 `.md`。逐条改指实际 crate
   （`symbio_sdk::…` / `symbio_kernel::…`），不留无主旧名。
