## 内容

DE-036 §2 把 embedding 定成「一条普通事件 `memory.encoded{payload: vec}`」，索引是 `Store` 的
实现细节；今天载荷里**没有 `vec`**，`providers/embedding` 只喂 `codebase_search`。
于是「语义检索」在记忆面只有词面重叠分（`recall_score::rank`），SC-006 的
「提起来能找到」靠的是字面命中。

D-110 把「恒空预留键不进事实形状」立成了决策，本任务兑现它的前置：
**向量要么写、要么明确不写**，不允许载荷里留一个永远为空的键。
