# A1：时机去全局化的 ADR

## 内容

**缺口不点名能力**（`D-269` 的两条准入）：加一条策略要改 2 处、加一个**新时机**要改 3 处
外加 1 个调用点，且全部落在 `loop`；`prio` 是一张 0→72 的全局序，行自己并不知道「我属于
哪个阶段」。这不是缺注册口：`owes` / `until` / `unless` 已经读事实，剩下由代码位置承载的
只有「它在全局序里坐哪儿」。

要裁的是形状，不是实现：**时机能不能成为行自己的一个值**，使环只在同一阶段内做不动点，
跨阶段竞争全走事实？三条边界不能碰：`D-093`（行自带完整判据、跨行竞争有全序）、
`D-222`（只有一个环、环内只有一笔债在跑）、`EX-008`（端口不说容器词）。

| 选项 | 形状 | 代价 | 判据 |
|---|---|---|---|
| A1 | `Decl` 自带 `phase` + `anchor`；环按阶段分组，组内不动点，组间靠事实交接 | 行表 16 行逐条补两格；`ring::drive` 从「全表最小」改成「阶段内最小」；跨阶段前件必须落成事实，漏写会退化成静默不触发 | 新增一条时机的夹具包只改自己目录；控制面不再新增 `prio` 行；现有 e2e 行为逐字不变 |
| A2 | 保留全局全序，只把 `prio` 数值从控制面移进能力包的 `Decl` | 改动小；仍是全局序，新时机仍要挑一个数字并可能与既有行竞争；「时机」没有消失，只是换了个作者 | 新增时机仍要改控制面表 ⇒ 只能算过渡，不算目标态 |
| A3 | 不开放，维持现状 | 零成本；每条新时机继续改 `loop` 3 处 + 1 调用点，`EX-002` 的 diff = 0 对新时机不成立 | 与父任务「新落地 diff = 0」冲突，必须写明例外 |

## 处理过程

1. 先读 `DE-021` §4.1 的现序与 `DE-014` `D-093` 的裁决，列出现有 16 行各自「读什么、在等谁」。
2. 按「行自带 phase/anchor」写一版等价映射：每一行的 phase、组内 anchor、跨阶段前件落成哪条事实。
3. 三套选项逐条写代价与反向用例；判据沿用 `EX-001` / `EX-002` 的 diff 口径，不新开脚本。
4. 裁决落进宿主设计文档（`### D-NNN`），并把结论回填本任务；实现另立 `T-016`，不夹带在裁决里。
