# C2：首条能力准入落地

## 内容

把「先落骨架、等第二条再补件」从一句承诺变成**可判字段**：每条首条能力的账里必须写
期限、触发条件与承接任务；没有这三样的开格在账上判红。

## 处理过程

1. 先定字段形状：写进 `DE-025` §5.2 缺口账的「结论」列，复用现有四列，不新建总账。
2. 让既有判据认它：`capability-ledger-audit` 已在读 §2.3 的处置与交付段；「首条 + 骨架」
   这一档加一条「计划三样齐全」的核对即可，不新开脚本。
3. 拿一条读数型能力（族里没有同伴的）按新流程走一遍：开格 → 骨架 → 计划 → 端到端用例。
4. 复核：计划过期未搬的，在账上回到「待裁决」并挂 `T-019` 的决策号，不静默续期。
