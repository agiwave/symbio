## 内容

DE-040 的裁决是「只认机制、不落参数」：`min_generality` 过滤的是通用性分级，而
**没有任何地方给一条记忆标 L0–4**。参数先落会得到一枚恒真旋钮。

本任务补的是那个前置：分级器的写方。分级算法本身划在架构之外（DE-040 §7），
但「分级结果以什么字段落进哪一格事实」是机制面，必须先定。

## 判据

| # | 判据 | 承担者 |
|---|---|---|
| 1 | `generality` 字段的取值域与缺省（认不出 ⇒ 不过滤，不把笔误读成越权） | `memory_events.test.rs` |
| 2 | 读侧过滤平凡值 0 = 不过滤，逐字等价 | `recall.test.rs` |
| 3 | 可逆性：阈值调回 0，被排除内容必须重新可检索 | `recall.test.rs` 反向 |
| 4 | 没有分级写方时不得落参数 | DE-040 §3.1 裁决仍在 |
