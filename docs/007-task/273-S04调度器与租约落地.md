## 内容

DE-034 的行表今天只落地了「借来的 `held` + 单写者 FIFO + 候选集投影」，调度器 / 租约 TTL /
`cap` 三件事被 D-064 收窄掉了。收窄是当时的正确动作，但它同时意味着
**SC-004 的「并行推进 + 抢同一份活有仲裁」在用户面不存在**。

本任务按 D-064 自己写的重开条件办：**先立放宽决策，再让写方与消费方同批落地**——
不许先加一格事件看看效果，也不许把 `cap` 做成一枚没有调用方的旋钮。
