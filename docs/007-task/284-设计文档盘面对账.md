## 内容

这一批全是「账记错了」，不是能力缺口，但它让缺口表**无法被信任**：

- 主体地址在 D-069 后是 `<ns>/<name>`，设计文档仍有 18 处 `agent:main` / `agent:worker` /
  `agent:market`（含 `capability-assign` 块）；
- core 三格写死 16 / 56 / 18，实为 15 / 55 / 18；
- 三个「巨型函数」已被按阶段拆分（`turn_runner.rs` 2004 → 895 + 7 个阶段文件，
  `tool_executor.rs` 1508 → 607 + `dispatch/`），§4.3 仍按旧行数描述；
- DE-034 `impl: planned` 而正文承认 store / readyset / held 已在生产；
- DE-042 §3 增量表仍列 §3.1 已裁决「不建」的 ActorSpec 行。

**修法不是补数字**：正文只写「谁判、在哪一格」，数字让它自己算（引生成物或脚本输出）。
