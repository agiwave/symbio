# 封闭语法面收窄——删生产零调用的选债口

## 内容

### 现场

- `crates/symbio-kernel/src/decl/ring.rs:247-257` 的 `pub fn drive` 是 `owed` 的一层包装
  （`filter(!blocked).min()`）。全仓**生产调用点为 0**：环的 `plan()` 直接调 `owed`
  （`crates/symbio-plugin-loop/src/ring/engine.rs:355`），仅 `ring.test.rs` 的 6 处断言在调它。
- `:236-246` 的注释仍写「生产入口 `turn_exec::drive` 直接调用它」，并按行点问指向
  `crates/symbio-plugin-loop/src/loop_rows.rs::owes`。两个文件经 Glob 确认**均已不存在**。
- `DE-052` 的证据锚点冻结表已把 `ring.rs::drive_frame` 标为「决策时点的历史文件，仅作溯源」，
  并写明「选债现住 `crates/symbio-plugin-loop/src/ring/engine.rs`」。

### 判定（按终态，不按省事）

这是**只靠测试续命的生产死码**，与 `D-443`「门面压缩只收生产，测试不续命」同一形态。
留着它省一次删除，代价是封闭语法层多一个**看起来是选债入口**的 `pub fn`，后来者会把它当成
第二个可扩的选债口——`DE-001` 的「一环」被语法面悄悄放宽。删除属**收窄**封闭语法面，
按 `CS-002` / `D-278`「收窄不需要批准」直接做，不需要裁决，也不许顺手补调用点把它救活。

`owed` 保留（生产在用）、`PortDecl` 与 `port_of` 保留（装配期读声明、非选债）。

### 动作

1. 删 `ring.rs` 的 `pub fn drive` 及其上方指向已删文件的注释；把 `Decl` / `Debt` 区段里
   仍需的解释改成指向现行落点，不写「曾经…现已…」。
2. 删 `ring.test.rs` 中只测这个函数的断言；`owed` 的测试一条不动。
3. 单测 `cargo test -p symbio-kernel` 绿；`arch-shape-audit` 三格不涨；全量门禁绿。

exit: 内核 `decl` 模块不再有生产零调用的 `pub fn`；注释不再指向不存在的文件；
`owed` 仍是环的唯一生产求解入口；`CS-001` 三格与门面三臂读数不上升。

不做什么：不改 `owed` 的字节语义、不动 `PortDecl` 字段、不新增任何替代函数或 trait。
