2026-10-24 的设计实现总收口批。父任务只定**顺序与判据**，子任务各收一段。

**排序依据**（不是阶号，是依赖）：

1. **先修判据面**——G-01…G-06 是元问题：证据锚点坏了，缺口表就只能靠人重读代码。
2. **再做有消费方前置的能力**——G-07（调度器）/ G-08（召回参数）/ G-10（语义维）/
   G-12（市场与守门主体）都要先有消费方，参数不许先落地（死旋钮比没有更坏）。
3. **安全与恢复面单独一批**——G-13（权限四字段）与 G-14（重试进债键）都必须先裁口径，
   不许顺手改代码。
