# B2：写口效果化落地

## 内容

只在 `T-017` 的裁决成立后动手。目标形状：

```text
能力：交 EffectDraft（形状 + 内容 + 幂等键）
宿主：校验形状 → 唯一写口落格 → 盖章（归属 / 溯源 / 时刻）→ 幂等拒绝重复
```

三条不许破：未声明效果的能力让系统逐字无差（平凡值）；同一幂等键只落一次；卸载能力后
系统完整运行、无静默边（`EX-004`）。

## 处理过程

1. 先为选定面写形状与幂等的单元判据（反向：重复键、误序、未声明效果三种输入必须各判各）。
2. 补件单列提交：`plugin-api` 的声明形状 + 宿主写口的校验与盖章；挂 `T-017` 的决策号。
3. 至少两条能力按新效果落地：一条落阶段格、一条落转写卡片；两个包各自只改自己目录。
4. e2e：能力出现 → 效果可见；重复投递 → 只落一次；停用 → 效果面消失、会话照常。
5. 全量门禁与提交；补件与迁移/落地分离（`EX-007`），不夹带。
