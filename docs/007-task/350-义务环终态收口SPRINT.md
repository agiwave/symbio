# 义务环终态收口 SPRINT

## 内容

### 判定总纲（本 SPRINT 所有取舍的唯一标尺）

1. **架构面必须落地，不得妥协；只有模块内部实现可以妥协**（`DE-002 §4`）。冻结锚点、
   机制表顶层键、三条不变量、封闭集合、以及「一个能力一个插件」的全面拆分，都属架构面。
   「改动少 / 好实现 / 测试不用改」**不构成**放宽理由；判断一件事要不要做只问它属哪个迁移步。
2. **收窄不需要批准，变宽需要论证**（`CS-002` / `D-278` / `DE-023`）。凡能让封闭语法面、
   门面三臂、扩展局部性覆盖面更紧的改动优先做；放宽若只落在模块内部（常量 / 基线 /
   判据读法），按该判据自身的 allow 通道记账即可，**只有放宽改到模块之间的依赖或协议面**
   才进裁决通道（`SP-003`「架构改动的边界」）——**「模块实现困难」永远不是改架构的理由**。
3. **扩展局部性只认加严**：`EX-002` 的受保护树并集与生成物例外，判据面只许扩覆盖面，
   不许为某一批能力开新豁免；名单只有 `PROTECTED_TREES` 一个 owner。
4. **`impl` 档位按代码事实对账，不按愿望收口**：不把 `partial` 机械改成 `done`；
   每篇只能在其正文列出的残余项逐条有落地锚之后改档。现行文档不写变更史。
5. **一个事实只有一个 owner**：结构事实归 `RE-006`（生成物，由门禁重生成，不手改）；
   「为什么这样设计」归宿主设计文档的 `### D-NNN`；模块机制归该模块 README。
6. **绿灯才算绿**：`scripts/gate.mjs` 全绿是每批提交的唯一出口。发现的门禁问题在提交前
   修复，不把红灯带入库，也不顺手夹带无关修复。批次按「一次只改一件事」划分，
   **可独立回退不构成拆分依据**。

### 入口事实

只读评估（`2026-11-12`，`v2` / `69934e7e`）给出四组实测：内核形状 `3/3 · 7/7 · 0/0`、
门面三臂 `0 / 132 / 108 / 13`、环纯度 `0 / 0 / 4 / 0 / 0`、引擎账本 `0 / 1 / 0`。
机制封闭性已由门禁兑现；欠的是**终态收口**与**口径同步**，不是再加一层机制。
