## 内容

落地 [DE-025](../003-design/025-能力包与扩展面.md "DE-025-能力包与扩展面") §2.1 与 D-207：

- `symbio-plugin-api` 新增 `ToolBehavior`（`before` / `after`）与 `FactDraft`，经 `inventory` 收集；
- 依次执行 `before × N → execute → after × N`，`before` 任一拒绝即 fail-closed；
- `after` 只返回草稿，由 `loop` 的唯一写入口按 owner 序落格；
- 三个现有效果回迁：`todo_write` 的任务声明、`agent_run` 的委托承诺、`vdfs_*` 的工作目录变更；
- 删掉 `CapabilityMeta` 对应的行为位消费点与 `note_tasks` / `note_delegation` 的名字分派。

验收看的是**换一个工具名不再需要动 core/loop**：改 `vdfs_write` 的名字只影响 vdfs 自己的声明。
