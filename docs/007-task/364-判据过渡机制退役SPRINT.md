# 判据过渡机制退役 SPRINT——让临时判据自己消失

## 内容

### 判定总纲

1. **过渡机制自带退役条件，退役条件是判据不是愿望**（[DE-052-决策正文证据锚点冻结表](../003-design/052-决策正文证据锚点冻结表.md) 的
   退役条件、[DE-054-判据欠账与到期豁免](../003-design/054-判据欠账与到期豁免.md) 的台阶表）。到期不撤的过渡机制会从「临时豁免」
   变成「永久第二套口径」。
2. **销账只能靠净减，不能靠改计数口径**（`EX-007` 的 补件:迁移 比例）。为消账搬一段
   没准备好的代码，正是 `D-404` / `DE-054` 禁止的「凑数迁移」。
3. **档位按代码事实对账**：`partial` 是合法中间态，但要每处残余都能指认归属；
   `done` 要指得出落地锚。
4. 一个事实只有一个 owner：结构事实归 [RE-006-当前事实表](../004-ref/006-当前事实表.md)（生成物），
   「为什么」归设计文档的 `### D-NNN`，进程归本条与子任务。

### 不做什么

- 不批量把 `partial` 改成 `done`（让档位失去意义，且违反「现行文档不写变更史」）。
- 不改 `EX-007` 的计数口径、不删欠账明细行、不改台阶表。
- 不为「让判据绿」而给冻结表加行（它只减不增，退役条件写死在正文）。
- 不把「绿灯」当成终态达成的证据。
