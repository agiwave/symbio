# A2：时机去全局化落地

## 内容

只在 `T-015` 的裁决成立后动手。目标不是「再写一张表」，而是把**时机从位置搬进值**：

```text
行 = { owes, until, unless, by, phase, anchor, tier, expand }
环 = for phase in 有序阶段: 在本阶段的行里做不动点; 阶段交接只经事实
```

三个必须同时成立的读数：① 现有 16 行的执行顺序逐条等价；② 新时机不碰控制面；
③ `EX-008` 仍绿（端口不出现轮 / 幕 / 容器词）。

## 处理过程

1. 先落等价性清单：按现有 `prio` 序逐行记录「前件 / 出口 / 与谁竞争」，作为改造后的对照表。
2. 改 `Decl` 与环：阶段序、组内 `anchor`、空阶段、阶段交接的事实形状；每改一处跑对应 e2e。
3. 把现有 16 行迁到新形状；有行找不到阶段归属的，先停下回到 `T-015` 补裁决，不就地加分支。
4. 用夹具能力包验证新时机：新增一条 `phase` 只在夹具包内声明，四个控制面目录 diff = 0。
5. 全量门禁与提交；`Migration:` 与 `Core-Change:` 按 `EX-007` 的既有形状声明，本任务不是迁移批。
