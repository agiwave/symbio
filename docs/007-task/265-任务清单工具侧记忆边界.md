## 内容

`local/todo_write` 的 `merge = true` 只在同一进程内按 id 合并，跨进程基准为空。
持久真相是 `task.*` 事实：`task_events::write` 每轮从事实快照 `rebuild` 观察状态，
工具只负责把本轮声明交给写方。

**为什么不给工具加文件缓存 / 读 Store**：能力上下文只递值（D-084），工具拿不到
`Store`；为一份确认回显新开跨插件键，把任务图读侧接进工具，收益与面积不成比例。
要做「跨进程续写整张清单」，得先给工具一个**值形态的任务快照键**，与「上下文只递值」
同批裁决——在那之前不造第二份可持久化的账。
