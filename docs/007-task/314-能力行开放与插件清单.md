## 内容

现在新增一个能力族要改 `CapabilityRowKind` / `CapabilityRowPayload` 的枚举臂，
家庭数量被内核代码写死。能力是**词汇**，不是语法：插件应该能自己声明
「我有一族能力行，它的字段是什么」，内核只校验形状与引用。

收口形状：

1. 能力家族名由插件声明，不再用内核枚举区分。
2. 能力行的 payload 形状由声明描述，装载期校验。
3. 宿主按「插件是否接入」决定能力行是否可见——未接入则读不到。
4. 现有六族作为首批声明迁出，内核只剩行容器与校验。
