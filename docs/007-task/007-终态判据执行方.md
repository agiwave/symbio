## 内容

### 每一条要补什么

| 判据 | 今天的执行方 | 缺口 |
|---|---|---|
| `TC-1` | 无 | 判"循环体出现次数 + 选债口份数 + 五道守卫实现份数"；反向用例：加一段影子推进、在派发器外直问求解器、让动作拿得到第二份 `&mut` |
| `TC-2` 机制层无域名 | `PTS-002`（端口名）、`CS-008`（事件名） | 补**行名 / 执行体名**；反向用例：在 kernel 里按行名分支 |
| `TC-3` 声明面封闭 | 装载期七道检查 | 已成立，只需把反向用例补齐（可变注册口、`seal` 放行缺表） |
| `TC-4` 事实面唯一写方 | `PTS-005` + J 组 | 补"收束格唯一写方"（今天 `turn_runner/prepare.rs` 就地写 `final` 而不在任何 `ActorDecl.writes` 里——事实面两写方、声明面一个，这是现成的反例） |
| `TC-5` 横向扩展零改机制 | `PTS-003` / `PTS-004` | 补"不改 host / 视图 / 驱动循环"的静态判据 |
| `TC-6` 判据集闭集 | `gate-codes-audit`（只管命名空间） | 新增元判据：控制面判据条数与能力数无关 |

### 判据自身的纪律（不是可选项）

1. **反向用例与该判据同批提交**：没有反向用例的判据，无法区分"真的在算"与"恰好没写错"。
2. **判据不得读取结论**：断言"某文件里有 1 处循环"时，不许从一份手写清单里读那个 1。
3. **判据的输入是源码与运行日志**，不是另一条判据的输出——链条一长，失效就静默。

### 不做什么

- **不为新判据新开命名空间**（除非确实与既有空间不同类）：能与 `PTS` / `OB` / `CS` 共处就共处，
  空间数量本身就是成本。
- **不把"退场判据的读数"删掉**：退场=降为读数，`RE-008` 的地址不变，历史日志仍指得到。
