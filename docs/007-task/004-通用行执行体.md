# S3：通用行执行体 plugin_row（I-1 轮级写口）

## 内容

能力四元组里事实、视图、行都已可插件，只有执行体不行：`ActorEntry` / `Action` 是
`loop` 的 `pub(crate)`，且 `Action` 收 `&mut Ctx`（整轮可变状态）。S3 补上**一个**
通用执行体（D-241），形状是：

```
债实例 + 本行声明的事实切片  →  Vec<FactDraft> | Verdict  →  宿主唯一写口落格
```

三件事：按声明把输入经容器路由发出去、把纯值结果拿回来、交写口。它**不认识任何能力名**；
顺序由既有 `(prio, name, key)` 决定，失败由既有租约兜底。

## 处理过程

1. 在 `symbio-plugin-api` 定义行的输入输出纯值形状，执行体只收纯值，不收 `Ctx`。
2. 在宿主装配处注册**一条** `ActorEntry`；`Decl.by` 由 `ActorDecl` 绑定，解析不到在 `seal` 期红。
3. 用一个真实能力走通：它写一条事实、读回视图，`loop` 侧零改动。
4. 跑 `EX-002` / `EX-005` 与端到端用例，绿灯后提交。
