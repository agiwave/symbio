# 端口单族按名唯一：注册层不再按端口分族

## 内容

[T-026] 裁决的落地批：把 `port.model` / `port.tool` 两个单槽族收敛为**一个
`multi("port")` 族**（D-299），注册层的族声明不再认识端口名——加端口不加族；端口级
唯一由读数（行名前缀分组）与装载期检查裁，不靠表侧 `demote`。行名保留
`<port:{port}>:{provider_id}`（provider_id 后缀是表键唯一性的来源，去掉会让同端口
第二提供者被同名静默顶掉——判重不可判，这正是初稿两案被否的机制根据）。

## 处理过程

1. **D-299 落 DE-045**：裁决 / 为什么不是初稿两案 / 代价 / 判据 / 推翻条件，
   含「行名去 provider_id ⇒ IndexMap 同名覆盖静默顶掉」「按名槽位档在同名覆盖
   语义下空转（机械上 ≡ multi）」两条机制论证。
2. **`crates/symbio-plugin-api/src/port.rs` 四处**：
   - `port_family`：match 两分支 → `PORT_FAMILY` 常量 + `ports::KNOWN.contains`
     闭集判定（闭集外仍 `None`，漏声明不是默认值）；
   - `port_row`：`active` `true` → `false`——port 行不参与表侧降位（`DefaultToolVisitor`
     的 put 只对带生效位的行降同族旧行；tool/prompt/option/configurable 行同款
     `active=false` 构造）；
   - `capability_port_of`：`list(family)` 后按 `port_row_name(port, "")` 前缀
     （`<port:{port}>:`）过滤再计行数——`0` 缺席 / `1` 就绪 / `>1` 判重三档读数不变，
     单族内其他端口的行互不可见；
   - `capability_port_check` 错误文案：去掉「保留先注册 / 被顶掉」措辞，改为
     「两行俱在」——单族不降位，判重时谁都没被顶掉。
3. **`port.test.rs`**：`port_row_builds_the_declared_shape` 的 active 断言翻转
   （`!row.active()`）；新增 `all_ports_share_one_family`（同族结构用例）；
   `port_rows_never_reach_consumption_families` 的行数前提改为单次 `list(PORT_FAMILY)`
   （单族下按端口两次 list 会重复计数）；`two_ports_do_not_demote_each_other` /
   `duplicate_provider_is_loud` 注释与断言措辞跟进（前缀互不可见 / 两行俱在）。
4. **消费方核查零跟进**：model 插件只经 `port_row()` 间接构造（无 active 直接断言）；
   loop / composite / session 的读方全部经 `capability_port_of` / `port_row`，仓内
   无按端口族字面量（`port.model` / `port.tool` 作为族名）的外部依赖——注释里的
   `port.model` 都是端口名指称，不是族词。
5. **测试**：`cargo test -p symbio-plugin-api`（63 过）→ `-p symbio-plugin-model
   -p symbio-plugin-composite`（118 过）→ `-p symbio-plugin-loop`（467 过）。
