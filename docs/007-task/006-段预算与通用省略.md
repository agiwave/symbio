# S5：上下文段的成本/优先级与通用省略（I-2 / I-5）

## 内容

多能力同时贡献段会撑爆窗口。今天只有「隐藏未选分支」一条硬编码规则，它不能推广到
第二个能力——那正是「加一个能力改一次组装」的形状。D-243 给出两条通用化：

- **段有成本与优先级**：宿主收齐后按确定规则裁剪，超界有读数；能力不得自己调窗口
  （预算没有唯一裁决）。
- **省略是一条事实**：「某区间被摘要取代」写进事实，组装按事实跳过区间；不为压缩特判。

## 处理过程

1. `ContextSection` 增加成本与优先级，收集顺序仍按 owner 字典序。
2. 裁剪规则写成确定函数并配读数（裁掉了谁、超了多少），不按插件名判断。
3. 省略事实落格 + 组装按事实跳过；把既有隐藏分支的规则翻译成同一条事实，验证输出逐字不变。
4. 压缩形态夹具能力：摘要落 `Message` 事实，省略事实跳区间。
5. 绿灯后提交，并把 DE-026 §2 的 I-2 / I-5 读数改为可用。
