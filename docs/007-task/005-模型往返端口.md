# S4：模型往返端口（I-4）

## 内容

反思、压缩、技能编译都需要 LLM。不开口，它们只能住 `loop`——这是三个样本能力共同的
第二个缺件。D-242 把它定义成**端口**：派出之后控制面不持有对方状态（D-222 §一），
与 `model` / `tool` 两个既有端口同形。

能力交的是纯值：提示由能力构造，应答由能力的解析函数解释；宿主负责调用、预算、租约，
并把请求与应答各落一条事实。字段与失败语义必须让回放（L0 + L1，读日志、不重执行）
看到完整的一次往返。

## 处理过程

1. 在 `symbio-plugin-api` 定端口形状：请求只含纯值，解析函数只收应答纯值。
2. 宿主侧接预算与租约，沿用既有失败语义（不许吞），请求 / 应答落格。
3. 用反思形态的夹具能力跑通「读转写切片 → 一次往返 → 一条洞察事实」。
4. 反向用例：插件直连 provider、或宿主为某能力特制原语，必须判红。
5. 绿灯后提交，并把 DE-026 §2 的 I-4 读数改为可用。
