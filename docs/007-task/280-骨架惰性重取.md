## 内容

DE-019 §6 的形态是：骨架折叠后，子节点可以被前端**释放**，再用一个 VDFS 动作按需重取。
今天的 `VDFS_OPS` 13 项里没有它；`vdfs/action` 只是测试钩子。长会话的折叠因此只有
「本地藏起来」，没有「真的不加载」。

## 判据

| # | 判据 | 承担者 |
|---|---|---|
| 1 | 动作入参 / 出参与 §6 一致，非法 depth / since_seq 有错误码 | VDFS 协议用例 |
| 2 | 返回的是**窄帧**，复用现有 delta / content 形状 | 同一用例 |
| 3 | 前端释放后重取，节点 id / parent_id / seq 与全量加载一致 | 前端单测 + e2e |
| 4 | 折叠态仍看得见「多少条 / 什么类型 / 还在跑几个」（`stats`） | 组件用例 |
| 5 | 反向：重取接口返回空而 stats 非零 ⇒ 用例必须红 | 同一用例 |
