## 内容

DE-020 §1「差距盘点（只列仍成立的）」里，信任面的四项全是空的：
看不见 Agent 干了什么、看不见上下文水位（已补）、看不见花了多少、看不见分支。
本任务按 P2 的顺序做，**先做有后端事实的**：`<根>/session/<id>/workdir` 已存在、
`session/stats` 有成本列、`parent_id` 树已建——缺的都是「前端把它显示出来」。

## 判据

| # | 判据 | 承担者 |
|---|---|---|
| 1 | 变更面板：本会话 workdir 的增删改可见，diff 复用既有编辑器 | 组件用例 + e2e |
| 2 | 授权分级：三档选项落成授权事实，不是仅界面状态 | 服务层用例 |
| 3 | 用量：会话头显示累计 token / 成本，读的是 `session/stats` 同一份切片 | 组件用例 |
| 4 | 分支：同 parent 多候选可 `‹ ›` 切换且不重挂载会话 | 组件用例 + e2e |
| 5 | 四项都不新增专属资源页（GO-002 T4） | 评审 + 路由快照 |

## 处理过程

- 2026-10-24：登记。P2-4 的前置是 `model` 是否有价格字段——没有就先后端补，
  不许前端按名字猜价格。

- 2026-10-27（批 0 · 前件勘查）：四项**不是同一档工作量**，逐项对着代码核了一遍，
  结论落在 [DE-020 §11 的前件表](../003-design/020-前端UI-UX.md "DE-020-前端UI-UX")：

  | 项 | 前件 | 谁先动 |
  |---|---|---|
  | P2-2 变更面板 | 文件改动只有实时面（事件总线，进程退出即消失），没有可回读、可归因的记录 | 后端先补 |
  | P2-3 授权分级 | 「本会话放行」= 抬会话阈值，零新事实；「永久放行」没有任何落点（跨会话授权清单不存在） | 两档可做，第三档需先裁 |
  | P2-4 用量成本 | token 在手（`LlmTurn.usage`）但没入格；`model` 没有价格字段 | 后端先补 |
  | P2-5 分支切换 | `RetrySubtree` 是**删除式**（删掉失败轮按新轮重来），日志上不产生第二支 | 后端先补 + 一条裁决 |

  顺带纠正 DE-020 §1 的一处事实错误：原表写「重试会产生分支」，而 `wake.rs` 的
  `WakeOutcome::NewTurn` 是「删掉失败轮的消息，按普通新轮重来」——分支今天**没有数据
  来源**，所以 P2-5 不是「补个 `‹ ›`」，是先裁「重试 = 替换还是分支」。

  分批（前端判据一律挂一条后端判据在前）：

  | 批 | 内容 | 判据落点 |
  |---|---|---|
  | 1 | P2-3 前两档：`每次` / `本会话放行`（抬会话 `risk_level`） | 服务层用例 + 授权事实 |
  | 2 | P2-4 后端：`response` 载荷带 `usage` + 一张 token 投影 + `session/stats` 一列 | Rust 用例 + stats 读数 |
  | 3 | P2-4 前端：会话头显示累计 token（读数走 `present/reading` 方言） | 组件用例 |
  | 4 | P2-2 后端：可回读的变更记录（谁写的、哪条路径） | Rust 用例 |
  | 5 | P2-2 前端：可折叠「变更」面板，diff 复用 `CodeEditor.vue` | 组件用例 + e2e |
  | 6 | P2-5：先裁「重试留下什么」，再谈切换器 | 裁决 + 用例 |

- 2026-10-27（批 2 · P2-4 的后端半边）：token 从「在手但没入格」变成一条可读的账。
  四处落点：① `turn_runner/facts.rs::output_fields` 把 `LlmTurn.usage` 写进
  `response{port=model}` 的 `usage` 键——**键在不在就是「测到了」的唯一记号**（缺席时
  不写 `usage: null`，只报一侧时不补 0）；② 新投影 `symbio_core/projection/token.rs`
  的 `token_ledger`：按**内容的 `principal`** 累计（不是写方的 `actor`），`calls` 数的是
  实测条数；③ `session/stats` 新增 `tokens` 列（与四列同切片、同 as-of）；④
  `stats_reading.rs::usage_section` 给读数面板加一段「用量」（输入 / 输出 / 合计，
  多主体才逐条摊开；一次都没测到就整段不出现，不写「0 token」这种编出来的数）。
  **前端零改动**——读数面板本来就按后端下发的 `panel` 排版。用例：
  `the_response_payload_carries_the_measured_usage`（写侧四种情形）与
  `the_usage_column_counts_only_measured_responses`（读侧 + 面板 + 反向）。
  **未承接**：钱（要 `model` 的价格字段）与会话头的常驻展示（今天读数在抽屉里）。
