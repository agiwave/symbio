# 能力自配置迁移批

## 内容

SPRINT 父任务。终态：**每个能力的配置由该能力插件自己持有并声明，接入走通用机制，
`symbio-plugin-session` 只保留会话基底、不认识任何具体能力名**。判据取
[DE-002-架构总览](../003-design/002-架构总览.md) 的「新能力只改自己目录，控制面 diff = 0」与
[DE-025-能力包与扩展面](../003-design/025-能力包与扩展面.md) 的「配置与身份随能力包走」。

本批不新增能力，只把 session 里代管的存量开关与阈值交回 owner；中间态不得出现
「两套配置同时生效」或「读方还能读到活配置」。子任务按 [DE-026-能力拆分与影响类](../003-design/026-能力拆分与影响类.md)
的两类提交纪律分开：架构补件独立、通用、挂决策号；迁移提交只做删除与绑定切换。

## 处理过程

- 子任务见父任务分解树；收口按「结论落进设计文档 → 删任务文件」执行。
- 每一步的出口判据写在子任务里，全量门禁是整批的唯一收口信号。
