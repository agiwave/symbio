# 行业智能体能力前沿参照

> **这张表回答什么**：行业前沿智能体产品/框架当前竞争的能力轴、代表坐标与公认分水岭，
> 供场景账本（SC）与方案（DE-014）做差距对照。
> **时效声明**：这是 2026-10-17 的调研快照，会过期；引用前核对来源。
> 标注约定：〔事实〕= 有公开来源；〔推断〕= 业界共识但无权威口径。

## 1. 能力轴 × 代表坐标

| 轴 | 代表坐标 | 性质 |
|---|---|---|
| 长时程自主 | METR「50% 可靠任务时长」：GPT-5 约 2h17m → Claude Opus 4.5 约 4.9h → GPT-5.6 Sol 约 11.3h；翻倍周期约 129 天；>16h 超出测量套件可靠范围 | 〔事实〕 |
| 计算机/浏览器操作 | OSWorld 越过人类基线 72.36%，Claude Opus 4.6 实测 72.7%，前沿转向 OSWorld 2.0（200+ 步长任务） | 〔事实〕 |
| 工具协议 | MCP 规范 2026-07-28 版；A2A v1.0 生产就绪、150+ 组织接入 | 〔事实〕 |

## 2. 公认分水岭

SWE-bench Verified 顶级约 97%、GAIA 约 94%（均饱和）〔事实〕。业界分界线已从
「能否通过基准」移到**「无人监督的数小时级长任务可靠性 + 自我验证闭环」**，
METR 时长是公认代理指标〔推断〕。

## 3. 桌面（本地）形态的位置

- 已被本地形态追平〔推断〕：编码智能体、MCP 本地工具、Skills 文件、自托管记忆。
- 仍依赖云端〔事实+推断〕：大规模并行沙箱农场、深度研究并行浏览舰队、
 computer-use 云 VM、托管编排、在线评测。
- 事故警示〔事实〕：本地无默认沙箱已出真实事故——代理无视停止指令批量删邮件
 （OpenClaw 类）。桌面形态的最大缺口是「每任务一次性隔离环境 + 审批门」，
 不是模型能力。

## 5. 五轴 → 行业自主等级（L0–L5）对照

> **这张表只做翻译，不改任何机制。** 五轴的定义与读数口径的唯一 owner 是
> [DE-008 §3.1.1](../003-design/008-能力注册表与能力坐标系.md "DE-008-能力注册表与能力坐标系")；本表回答的是
> 「一个只看行业分级的人，能把本仓的读数放到哪一级」。分级本身是**业界约定**，
> 没有权威口径——所以整表标〔推断〕，引用时不要当事实。

| 等级 | 通行含义 | 时域跨度 | 主动性 | 自主程度 | 自我模型精度 | 抽象层级 |
|:-:|---|---|---|---|---|
| L0 | 工具 | 单次调用 | 纯被动响应 | 每步人工确认 | 无 | 不迁移 |
| L1 | 助手 | 单轮 / 分钟级 | 只回答被问的 | 人给指令、人执行 | 无 | 同域内换表述 |
| L2 | 协作者 | 多轮 / 十分钟级 | 会追问澄清 | 自动执行、关键步人审 | 有"我做不到"的粗判 | 同域跨任务迁移 |
| L3 | 有条件自主 | 单任务 / 小时级 | 会提出下一步 | 无人干预完成闭环，异常上报 | 说到做到率可测 | 近邻域迁移 |
| L4 | 高度自主 | 多任务 / 数小时级 | 自发发起并被采纳 | 长时程无人在环，自我返工 | 校准误差可测并对齐行为 | 跨域迁移 |
| L5 | 完全自主 | 天级、跨会话连续 | 自设目标 | 无人监督的长期运行 | 自我模型与外部评测一致 | 抽象协议设计、迁移规则本身 |

**怎么用本表**（三条，别越界）：

1. **从左往右不作弊**：一个系统在某一行上「多数格对得上」就算在这一级；**没有任何一列
 能单独把系统顶上两级**——那正是「伪高阶」的定义（[DE-008 §6.2](../003-design/008-能力注册表与能力坐标系.md "DE-008-能力注册表与能力坐标系")）。
2. **本仓目前的位置**：L2–L3 之间的某处，五条轴不齐（`抽象层级`仍只能人工判、
 `自我模型精度`有口径未出数，见 [GO-000 §2](../001-goal/000-价值主张.md "GO-000-价值主张")）。
 **不要在对外材料里说成 L4**：那张表里 L4 的两格（长时程无人监督、跨域迁移）
 本仓都还没有读数。
3. **这张表不进判据**：L 级是沟通用的坐标，不是验收标准。判据仍是各轴自己的读数
 （DE-008 §3.1.1），把 L 级写进 exit 条件是给架构加一条拍出来的门槛。
