# Symbiont - 智能共生体

> 在做中学：生信分析的互动学习平台

---

## 项目定位

**Symbiont 是生信分析的学习平台，让你在做中学，而非看教程学。**

传统学习方式的问题：

- 看教程 → 似懂非懂 → 自己做时卡住
- 问 ChatGPT → 得到答案 → 不知道对不对
- 上培训班 → 学完忘光 → 实战时不会

**Symbiont 的方式**：

- 边做边学 → 在真实数据上操作
- 即时反馈 → 执行结果立即可见
- 过程记录 → 每一步都有据可查

## 与其他方案的对比

| 场景 | 看教程 | 问 ChatGPT | 用 Symbiont |
|------|--------|------------|-------------|
| 学习方式 | 先学后用 | 问答式 | 边做边学 |
| 遇到问题 | 搜帖子、问人 | 得到答案 | 立即执行验证 |
| 结果验证 | 不知道对不对 | 不知道对不对 | 自动检验 |
| 学习效果 | 容易忘 | 用完就忘 | 做过就记住 |
| 能力积累 | 无 | 无 | 流程可复用 |

**核心差异**：Symbiont 不是给你答案，而是陪你在做中学。
