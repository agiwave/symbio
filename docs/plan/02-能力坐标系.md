# 02 · 能力坐标系

> **回答一个问题：能力能长到哪去，以及怎么判断"这算不算高阶"。**
> 清单是开放集，永远列不完；坐标系是封闭的，可以吸收清单的开放性。
> 这正是"架构必须收敛"的理由：**用坐标系的封闭性，去吸收能力清单的开放性。**

---

## 1. 为什么不用能力清单

| 清单的问题 | 坐标系的解法 |
|---|---|
| 永远不知道有没有漏 | 五维正交完备，任何能力必须落入且只落入一维 |
| 无法判断"高阶了多少" | 五轴给出纵向刻度 |
| 新能力来了不知道放哪 | 准入判定函数（§4） |
| 容易把"宽度"当"高度" | 伪高阶识别（§5） |

---

## 2. 横向：五维（分类的完备性）

任何能力都落入且只落入这五维之一。**判据是四个追问，无遗漏也不重叠**：

> 我**知道**什么？我**能做**什么？我如何**说**？我做得**对不对**？我**想不想**做？

| 维度 | 回答 | 内涵 | 条数 |
|---|---|---|:-:|
| **知** Episteme | 我知道什么 | 事实、记忆、时间、因果、世界模型、检索 | 10 |
| **行** Action | 我能做什么 | 工具、执行、副作用、具身、承诺 | 13 |
| **言** Utterance | 我如何表达 | 对话、人格、时延、节奏、主动性、多模态 | 8 |
| **省** Reflection | 我做得如何 | 规划、自我模型、校准、评估、审计、信任 | 16 |
| **欲** Conation | 我**想要**什么 | 动机、目标生成、好奇、价值偏好 | 7 |

### 2.1 为什么必须有「欲」

前四维都是**功能性**的（"能做什么"）。缺了「欲」，系统永远只是**高级工具**——有能力，没有能动性。

- 「省」回答"我做得**对不对**"
- 「欲」回答"我**想不想**做、**为什么**要做"

心理学对应：认知 + 情感 + **意志**。缺意志就是缺「欲」。
**缺了这一维，系统再强也不会自己想做事**——它永远在等指令。

### 2.2 时延属于「言」的横切属性

分层（反射/快速/深度/自主）回答的是"**我多快能回应**"，这是**表达问题**，不是结构问题。
所以它不是第五维，也不占用架构位置——它是 `actor.budget_ms` 的取值（[01 §10](./01-核心架构.md)）。

> 这也是"双脑"说法的正确归属：快/慢是参数，不是两个脑。

### 2.3 「欲」的最小可执行形态（不是分类，是设计）

> 「欲」最容易停在**分类学**上：把"动机/目标生成/好奇/价值偏好"归成一维，然后说"缺了它不高阶"。
> 但这是**命名**，不是**设计**。真正的问题是架构问题：**"想要"在系统里以什么形式存在？**
>
> 若答"用一个 Motivation 模块 / Drive 原语 / Goal 基类"——立即违反 J1（本架构承诺只有 1 个原语）。
> 所以「欲」**必须落成数据**，且必须回答三个可执行的子问题（`verify/conation_minimal.rs` 实测）：

| 子问题 | 形态 | 强制方式 |
|---|---|---|
| **E1 欲是什么？** | 一条事件 `conation.expressed`（走 I1 单通道、I2 带溯源） | 事件网格登记一行 |
| **E2 欲如何不直接变成行？** | 欲 → `CandidateIntent`（待评估）→ **闸门** → `ApprovedTask` | **ZST 能力令牌**（`GateWarrant`，私有构造 → 不可伪造） |
| **E3 欲如何被关停？** | `ConationPolicy.enabled`，**平凡值 = false** | J2：关闭后系统退化为纯响应式且仍完整运行 |

**E2 是「欲」的全部难点**。"想要"直接产生动作，等于绕过授权 / 预算 / 审计三道治理。
因此欲与行之间**必须有一道类型闸门**——不是约定、不是 code review、不是 CI 断言，
而是**不持有令牌就写不出那行代码**（编译失败）。实测三条反向用例：

```
(a) 伪造 approved: true        → error[E0451] field `approved` is private
(b) 伪造 GateWarrant           → error[E0451] field `_private` is private
(c) 不带令牌调用 approve       → error[E0061] takes 3 arguments but 2 were supplied
```

> **为什么令牌要 ZST**：强制力来自**类型**（谁能写出这行代码），不来自运行时字段。
> `size_of::<GateWarrant>() == 0`——零运行时开销，但编译期不可伪造。

**准入判定复核**：4 项「欲」能力（目标自生成 / 内在动机 / 好奇与探索 / 价值偏好）
全部落在**已有机制键的新取值**上（`event.entity=conation`、`projection=conation` 等），
**新增机制键 = 0**。这正是 §4 准入判定第 3 问（J1）的通过条件。

> **「欲」这一维解决的是"欲如何被治理"，不是"欲从哪来"。**
> 后者是价值对齐问题，架构不回答。架构只保证三件事：
> **想要的都留痕（E1）、都必须过闸（E2）、都可关停（E3）。**

## 3. 纵向：五轴（高阶的刻度）

| 轴 | 低阶 | 高阶 |
|---|---|---|
| **主动性** | 只在被要求时行动 | 主动发现问题、发起目标 |
| **时域跨度** | 单轮、当下 | 可规划数周、跨会话坚守目标 |
| **抽象层级** | 具体指令 | 理解意图、处理模糊、归纳规则 |
| **自我模型精度** | 不知道自己不知道 | 精确校准、知道边界 |
| **自主程度** | 每步请示 | 可长时间独立工作，只在关键点请示 |

**"高阶"不能用能力清单衡量，必须用这五轴度量。** 一个能力若不能说明它提升了哪一轴，它就没有让系统变高。

### 3.1 天梯 T1–T8 = 五轴的递进

| 级 | 名称 | 提升的轴 | 核心能力 | 工具层级 |
|---|---|---|---|---|
| T1 | 能对话 | 抽象层级 | 多轮对话 | L1 |
| T2 | 能干活 | 自主程度 | 工具调用 + 分层响应 | L1–L2 |
| T3 | 能记住 | 时域跨度 | 五类记忆 + 混合检索 | L2 |
| T4 | 能自省 | 自我模型精度 | 校准、承诺、信任账本 | L2 |
| T5 | 能递归 | 抽象 + 自主 | 子智能体、对等协作 | L3 |
| T6 | 能感知时间 | 时域跨度 | 时序推理、预测、节奏 | L3 |
| T7 | 能具身 | 主动性 | 反射通路、硬实时闭环 | L4 |
| T8 | 能学习 | 全轴 | 巩固、技能编译、目标自生成 | L4 |

**每级的验收三问**：① 低级场景全部仍工作；② 无新增机制（只有新参数取值）；③ 关闭本级配置可退回上一级。

## 4. 新增能力的准入判定

```
admit(capability):
    1. 它属于五维中的哪一维？          答不出 → 它是已有维度的组合，不是新能力
    2. 它提升五轴中的哪一轴？          答不出 → 它是宽度/工程，不是高度（§5）
    3. 它能否表达为 §8 参数表的新取值？ 不能  → 走 ADR 流程（[03 §3](./03-演进与验证.md)）
    4. 它的平凡值是什么？              没有  → 驳回（J2）
```

第 3 问是 J1 的直接应用，第 4 问是 J2 的直接应用。**两问都过 = 加一行数据，不是改架构。**

## 5. 伪高阶识别

> 以下都是**宽度或工程，不是高度**。它们让系统变大，不让它变高。

| 说法 | 为什么是伪高阶 |
|---|---|
| 工具数量多 | 是「行」的宽度 |
| 上下文更长 | 是容量，且 Cowan 2001 证明核心工作记忆只有 4±1 组块，堆长度不如建结构化组块 |
| 反应更快 | 是工程（除非进入了反射层预算，那才是架构） |
| 支持更多模型 | 是配置 |
| 能跑很久 | 是耐力；**跑很久但每步请示 = 低阶** |
| 会写代码 | 是技能 |

`verify/capability_frame.rs` 把这六个判据做成了可执行函数，并配反向用例（真实能力不得被误判）。

## 6. 覆盖矩阵（实测）

`verify/capability_frame.rs` 对 **54 项能力**的分类结果：

```
               主动性   时域跨度   抽象层级  自我模型精度   自主程度
  知             1        5        4         0          0
  行             1        1        6         2          3
  言             2        3        3         0          0
  省             0        4        3         5          4
  欲             3        0        0         1          3
```

**空格子 7 / 25。** 这些不是缺口，是**坐标系预留的生长位**——它们告诉你下一步可以往哪长：

| 空格 | 可能的生长方向 |
|---|---|
| 知 × 自我模型精度 | "我知道我哪些记忆不可靠"（记忆的元认知） |
| 知 × 自主程度 | 自主决定是否值得记住 |
| 言 × 自我模型精度 | "我说的话有多可能被误解" |
| 言 × 自主程度 | 自主决定什么时候闭嘴 |
| 欲 × 时域跨度 | 跨会话的长期动机 |
| 欲 × 抽象层级 | 从价值到原则的抽象 |
| 省 × 主动性 | 主动发起自省而不只是被动评估 |

> **这是坐标系相对清单的最大价值**：清单只告诉你"有什么"，坐标系还告诉你"缺什么、缺在哪"。

## 7. 社会性：递归覆盖不了的那一类

递归是**树**（主从），对等协作是**图**。以下能力树结构表达不了，必须显式支持（[01 §12.2](./01-核心架构.md)）：

| 能力 | 提升的轴 |
|---|---|
| 对等协商 | 抽象层级 |
| 跨体承诺 | 时域跨度 |
| 声誉与互信 | 时域跨度 |
| 传递性信任 | 抽象层级 |
| 共同目标与分工 | 自主程度 |
| 冲突与仲裁 | 自主程度 |
| 可撤销的承诺 | 时域跨度 |

> **没有承诺机制，就没有真正的协作——只有并发。**

---

## 8. 边界：什么是判断，不是证明

| 主张 | 性质 |
|---|---|
| 五维正交且完备 | **判断**（依据是四个追问无遗漏，但无法证明不存在第六维） |
| 五轴足以度量"高阶" | **判断** |
| T8 是"当前能想到的最远" | **判断**，不是"存在的最远" |
| 54 项能力全部归位 | **已验证**（程序，含反向用例） |
| 空格子 = 生长位而非缺口 | **判断**（它也可能是我没想到的能力） |

**正因能力清单是开放集，架构才必须收敛。** 这是本方案把能力放进坐标系、把扩展放进参数表的全部理由。
