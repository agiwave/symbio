## 规范

限定名 `04 §1.3 出口表`。**owner = 守卫源码** [`slo-exit-audit`](../../../scripts/slo-exit-audit.mjs)——
它把出口表当规则源，逐行核对「用户可见出口」一栏的每个指认**确实对应 `session/stats` 的一列**
（从 `stats.rs` 的两个 `Serialize` 结构体字段现提，不硬编码）。

两条口径：

1. **指认必须落到真列**：表里每个非 `—` 的指认（支持 `列.子列`）在 `plugins/session/stats.rs`
   的读数列集合里必须有同名——指认漂移（列被改名 / 出口还没建就写上）即红（SX-001）。
2. **`—` 不是豁免是待建**：`—` = 这一项还没有用户可见读数；脚本每次门禁都把 `—` 的行数打进日志，
   让「还有多少出口是用户看不见的」是一个**每次门禁都看得见的数**（待建读数口清单）。

## 判据

`scripts/slo-exit-audit.mjs`（`SX-001/002/003`，出口表锚 `阶`、列表 `用户可见出口`）；
