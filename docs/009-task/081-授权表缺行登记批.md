## 内容

三处 §3.1 落地状态核实（T-127 / T-130 / T-132）指向同一个机制空洞：**授权叙事写在正文，
表里没有对应的行**，而未登记 `agent:*` 走 `matrix_for` 派生分支 = 拿主智能体整套能力（含
`reply.*`）：

1. **S07 抢占判定者**：正文断言「判定者不得发言」，生产里 `agent:reflex` 行不存在，
   `held/controlled` 写格不过 `closure_granted` 闸——判据今天用自造矩阵，只证明「我拒我」
   （T-132 §3.1 已点名此形态并给出修复先例：补窄行 + 生产表判据）。
2. **S10 人物主体**：`person:* ▸ shared` grants 行整行缺失，`VisScope::Shared` 只在测试态
   出现——个人认知注入的可见域承诺今天无表支撑。
3. **改道裁决**：`Preemption` 枚举（`actors/control.rs:7-21`）无改道分支；动 core 枚举是
   形状变宽，须按 ADR-055 流程先立决策，本任务只负责把裁决记下来。
