## 验收口径

1. 每道检查一条**反向用例**（违反 ⇒ 装载红 / 报告）：①依赖图环；③行 Pattern 引用未声明字段；④相交行对报告输出样例；⑤执行体越权写；⑥`by=Some` 且 `writes ∩ (until∪unless)` 为空。
2. 装载失败 ⇒ 拒绝启动复用 [T-239-装载失败拒绝启动与孤名收口](239-装载失败拒绝启动与孤名收口.md) 的 fail-fast 路径，不建第二套。
3. 七道检查在代码注释与 PL-016 §3.4 编号一一对应（指认表进 evidence）。
4. 门禁全绿；CS-001 三格只降不升。
