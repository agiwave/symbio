## 内容

本仓的健壮性面已逐处登记（`panic-audit` 的 PN-001…003），但**覆盖率**这条相邻的
量化面一直没有判据：`cargo-llvm-cov` 逐 crate 阈值成本高于本仓当前的守卫投入，
因此被显式延后。

延后是有理由的，但**理由必须有 owner**：13 篇归档前把它写在「明确不做」里，
那篇随归档退出活跃文档之后，这条延后就只剩 git log 记得——于是本条目把它接过来。

处置只有两种（与 C7 的登记同一条约定：空白比"看起来已决定"更危险）：

1. **做**：`cargo-llvm-cov` 逐 crate 阈值进 `RATCHETS` 清单（floor，只许涨）；
2. **不做**：在一条 ADR 里写下「为什么逐 crate 阈值对这一仓不划算」的判断，
   并在本条目 `evidence` 指认那条 ADR——**理由不许只存在于本条目**。
