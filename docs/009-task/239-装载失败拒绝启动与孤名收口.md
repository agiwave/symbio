## 验收口径

1. 用例：表含任一 `Gap`（孤儿名 / 无出口 / 未声明字段）⇒ 装载返回 Err、开幕带错退出（`TurnExit::Failed`）；每种 Gap 一条反向用例。
2. CLI 复验：stderr 中「声明的事实暂无行消费」出现次数 = 0（旧实测每轮必现，本任务的反例基线）。
3. `turn.dispatch` 的归宿有名字：接入了哪一行、或退出控制面声明集（写方与投影读方保留），写进 evidence。
4. 门禁全绿；`port-surface-audit` PTS-003 指纹不违规（若触 `drive` 字节，同批更新基线并挂 ADR）。
