## 内容

`06-facts-write` 把生成链从 `facts` 阶段拆出去的那天，三个 gate 调用点没跟着改——它们仍写
`--only=facts`，而这个 id 从此只剩 `gen-facts --check` 一项。2026-10-23 实测到的形态：

1. pre-commit 跑完 **1/1 全绿**，而它的头注释写着「全部是生成器 + 登记校验」；
2. 于是 `docs/009-task/README.md`、`docs/010-adr/README.md`、`docs/README.md` 三处的汇总区块
   以**未展开的 `[[编号]]` 记号**进了提交，落后两个提交，直到下一次全量门禁才被
   `gen-doc-refs` 改写回来——即本任务要消灭的「漂移不归属造成它的那次提交」；
3. CI 的 docs & facts job 同样只跑 `--only=docs,facts,baseline --ci`，而 `facts` 阶段里
   **没有任何一条**引用地址复核——`gen-doc-refs --check` 早就存在（且实测能判出这次的红：
   RF-002 三条），只是三个调用点都没点到它。

与 [T-089-ci触发分支守卫失配](089-ci触发分支守卫失配.md)（CI 触发分支名单与守卫失配）、[T-092-fmt缺推送点闸门](092-fmt缺推送点闸门.md)
（fmt 无推送点闸门）是同族第四次：**漏点一个阶段 id 不报错、不变慢、日志一片绿**，
`gate.mjs` 只对「不存在的 id」报错。

## CI 侧点得动生成链的前提：差异判定做在链尾，不是做在每一格

看着最省事的修法是「三处都加 `facts-write`，`--ci` 下差异即红」，实测**恒红**：链上
`registry-audit --write` 先把汇总页写成记号，`gen-doc-refs` 再展开（顺序不能换，理由见
`06-facts-write` 头注释），而 `autoWork` 是**逐步**判差异的——它看到中间态就报红。
CI 要的是末态判据，不是生成器。

⇒ 这条不是「CI 点不动生成链」的理由，而是**差异判定该做在哪一格**的理由：链合成一格
（`autoChain`）之后，判的是「链跑完的末态与跑之前差多少」，中间态不再参与判定，
CI / pre-push 就点得动了。口径 4 因此选 ②。

## 验收口径

1. 阶段 id 对账有执行方：`_shared.test.mjs` 一条守卫，规则是「点了 `facts` 复核的 gate
   调用必须同时点到生成链 `facts-write`」——**不分本地与 CI**（原判据只管本地模式，因为
   CI 侧点不动生成链；口径 4 落地后那条前提没了，规则就取全模式），阶段 id 按逗号拆开
   **精确匹配**（不用 `\bfacts\b`——`facts-write` 里的 `facts` 后面跟 `-`，那样数会把没点复核的调用数进来）。
   反向判据实测：pre-commit 退回 `--only=facts` ⇒ 该用例红。
2. `facts` 阶段带只读末态复核 `gen-doc-refs --check`（实测 0.27s），并由守卫断言钉住不被当冗余删掉。
   反向判据实测：把 `args: [docRefs, '--check']` 改成 `args: [docRefs]` ⇒ 该用例红。
3. 三处调用的**文字描述**与实际命令一致：`pre-commit` / `pre-push` 头注释与
   `CONTRIBUTING.md` 的钩子表不再写 `--only=facts`；耗时按实测写，不留「<1s」这类过期口径。
4. 残余缺口收口：登记汇总页的**内容**（计数 / 状态分布 / 分解边）新鲜度有一条只读执行方。
   形态二选一，选哪个都要写理由：① `registry-audit --check`（渲染到内存再与文件比对，不写盘）；
   ② `autoChain`（把整条链当一个原子工作跑，只在**末态**与 HEAD 比差异，本地改写并暂存、
   `--ci` 判红并还原工作区）。口径 1 的守卫随之扩到「CI 侧点了 `facts` 就必须点到末态判据」。
5. 门禁全绿；一次真实提交复验（提交里带上生成器改写的汇总页，且 pre-commit 无需 `--no-verify`）。

## 不是本任务范围

- 不给 pre-commit 加 `fmt`（`cargo fmt --all` 会重排所有脏文件 = 替人暂存别人的改动，与
  `autoWork` 的暂存纪律冲突，理由见 T-092）。
- 不动 `autoWork` 的逐步判差异语义：单步生成器的产物**就是**末态，逐格判它是对的；
  口径 4 的形态 ② 新增一条链版原语（`autoChain`），不改那条。

## 处理过程

- 2026-10-23 登记：T-243 收口后清工作区，发现三个 README 的汇总区块在 HEAD 里是未展开记号，
  而 `git status` 在跑完整条链后变脏——顺 `gate.mjs --list` 与 `--only=facts` 实跑（通过 1/1）
  定位到「阶段 id 少点一个」。口径 1–3 随本批落地（含两条反向判据实测）；口径 4 待做。
- 2026-10-23 口径 4 落地，**形态取 ②（`autoChain`）**。选它的理由（① 的代价是实测出来的，
  不是猜的）：`registry-audit --check` 要比的是「渲染结果 vs 文件」，而渲染结果带
  `[[编号]]` 记号、文件里是 `gen-doc-refs` 展开后的地址——**直接比恒差**。要做成 ① 就得把
  `gen-doc-refs` 的展开逻辑从它的 `runGenDocRefs` 里抽出来复用（那段现在是内联在遍历循环里的，
  含 `TOKEN_RE` / `LINK_RE` / `codeRanges` 三段），等于把第二个真相搬进检查路径；
  而 ② 用的就是生成器本身，判的是「链跑完 == 树」，一条真相。附带收得多：末态判据覆盖
  整条链的产物（`006-当前事实表.md` / `GATE_CODES.md` / `007-清单归属总账.md` /
  `routes.gen.ts` / 各汇总页 / `verify/facts/mod.rs`），不只汇总页。
  - **实现**：`_shared.mjs` 新增 `autoChain(ctx, {label, steps})`——跑之前记脏路径与内容哈希
    （`autoWork` 同一套），四步跑完**一次**比差异；本地生成并暂存，`--ci` 报红**并还原工作区**。
    还原分三路：跑之前已脏的按**内容快照**写回（`git restore` 恢复到索引会抹掉人的未提交改动，
    这是唯一不能图省事的一路）、跑之前干净的 `git restore --worktree`、跑之前不存在的（生成器
    新建）删掉——`git ls-files` 分这两路，因为 `restore` 不认未跟踪路径。
    本地模式**不还原**：那侧的约定是「生成并暂存」，链坏在中间时把现状留给人看比替他决定
    该留哪一版更安全。`06-facts-write.mjs` 的四格 `autoWork` 合成一格 `autoChain`，
    步骤名单 `export const STEPS` 导出去给 `gate.test.mjs` 判顺序（判的是跑的那份，不是 label）。
  - **三个调用点**：pre-commit `--only=facts-write,facts`（不变）、pre-push
    `--only=fmt,facts-write,facts --ci`、ci.yml 的 docs & facts job
    `--only=facts-write,docs,facts,baseline --ci`（顺带把「生成先于静态审计」这条次序在
    CI 侧也摆正了——原先 CI 只跑复核，审计看到的是上一版投影）。
  - **实测**：注入一条 front-matter 漂移（T-245 的 `prio: later → now`）⇒
    `--only=facts-write --ci` **红**且消息点名 `docs/009-task/README.md`，跑完 `git status`
    里它不在（还原到位）；同一棵树不带 `--ci` ⇒ 绿 + note「自动生成 1 个文件（已暂存）」。
    反向判据三条各自实测：`06-facts-write` 的 `autoChain(c, {` 退回 `autoWork(c, {` ⇒
    「生成链是一个 autoChain 工作」红；pre-commit 退回 `--only=facts` ⇒ 「点了 facts 就必须点
    facts-write」红；`STEPS` 里改掉一步 ⇒ `gate.test.mjs` 的关键路径用例红。
    `node --test scripts/gate.d/_shared.test.mjs` 60 通过 / 0 失败（新增 5 条链用例）、
    `node --test scripts/gate.test.mjs` 21 通过。耗时实测：pre-commit 1.7s、pre-push 那一串 2.6s。
  - **同族清到的**：`registry-audit.mjs` / `registry-lib.mjs` / `gen-doc-refs.mjs` /
