## 处理过程

### 判据：三个「轮 / Turn」是三个东西，只有一个是过时的

全仓 `grep '一轮\|Turn'` 命中 250+ 文件，逐条比对后确认**绝大多数不是过时措辞**——它们是三个
彼此独立、且都**合法存续**的概念，被同一个词面盖住了：

1. **线格式 `MessageType::Turn`（已退役 ⇒ 该清）**：ADR-070 用 `NodeKind::Skeleton + style_tag:"run"`
   取代的那个**协议变体**。`NodeKind` 闭集五值（body/notice/skeleton/interaction/typing）里**不再有
   `Turn`/`Compression`/`ToolCall`**。凡是把 wire 说成 `msg_type=Turn` 之类的注释都是**假事实**，
   必须改。
2. **呈现层 `turn`（ADR-070 §决策 3 明确保留 ⇒ 不动）**：前端 `NODE_KIND_TURN='turn'` 是**折后呈现键**
   （`chat_node.ts:194-223` 注明「不是 wire 词」），`TurnGroupNode.vue`、`isTurnFacet`、
   `registerMessageRenderer('turn')` 都是注册表按呈现键分派的正当命名。
3. **执行引擎的「一轮」与事实网格的「收束格」（存续 ⇒ 不动）**：`TurnRunner`/`LlmTurn`/`TurnState`/
   `TurnOutput`、`chat_loop/turn.rs` 局部变量 `turn`、ADR-052 的 `chat.assistant.final`「一轮至多一条收束格」
   ——这是 agent loop 的**模型产出回合**，从未被改名（T-147 只改 wire 类型），删它等于改执行语义。
   同理 Rust `ChatNode` 字段仍叫 `msg_type`（`#[serde(rename="type")]`）、`role` 作为存量只读格保留
   （T-147d-iii），故 `message.msg_type` / `role===CHAT_ROLE_TOOL` 都是**活代码**，不是残留。

`docs/archive/*` 是带日期的历史快照（AGENTS.md：archive 即历史），**不回改**；PL-013 / ADR-070 /
T-134 / T-137 / T-147 里出现旧名，是在**叙述这次改名本身**，是其职责。

### 实际改动（只动 1 类：假 wire 事实）

- `useChatConnection.ts::ResumePayload.targetId`：三条 `msg_type=Turn/Compression/ToolCall` 改为真实
  wire 形态（`skeleton`+`style_tag=run` / `notice` / `skeleton`+`style_tag=tool`）。
- `resume.rs::process_retry_subtree` 两处 `msg_type=Turn`：改为 `is_run()`（wire `skeleton`+`run`）。
- `pipeline.rs` 逐帧白名单条目 1「Turn 组合节点（msg_type=Turn）」：改为「运行骨架根帧（`is_run()`）」，
  与 `stream.rs` 实发的 `Skeleton` 帧一致。
- `chat_node.rs::RetryCompaction`：`msg_type=Compression` 改为 `msg_type=Notice 且 is_compression()`；
  同文件 `RetrySubtree` 的悬空引用 `ADR-070 §决策 5` → `§决策 1`。
- `messageTypes.ts::messageRetryTargetOf`：把「后端要求 target_id 指向 Failed **Turn**」更正为
  「指向**运行骨架**（`is_run()`）」，并修正压缩节点的 wire 类型表述（`type=notice`）。

### exit 三条具名目标的核实结果

- **ADR-052**：其「一轮 / 收束格」属上述第 3 类（事实网格回合），**不作废**；补一段**术语澄清**，
  把它与 ADR-070 退役的 wire `Turn` 划清，并说明「一个 user.message 配一对 Turn.Opened/Closed」这类
  **线格式配对不变量**随 ADR-070 作废——这是 ADR-070 §关联承诺的那条标注。
- **ADR-055**（core 形状棘轮）：`grep MessageRole|Turn|role` **零命中**——不涉及，无需改动。
- **`docs/005-rev/*`**：该目录**不存在**（现行架构文档在 `docs/005-arch/`）；`005-arch` 是活文档，
  其中 `010-session-input-addressing.md` 的「这一轮 / 收敛在途 Turn」指会话节点上**正在跑的运行**
  （第 3 类语义），非 wire 断言，保留。
