## 内容

父设计：[PL-015](../004-plan/015-可扩充性与插件切分.md "PL-015-可扩充性与插件切分") §4.2（静默失效的扩充点）· [ADR-096](../010-adr/096.md "ADR-096")（令牌退役先例）· [ADR-094](../010-adr/094.md "ADR-094")（闭集即行表）

**判据只用一条**（与 [T-170](170-横向扩展摩擦批.md "T-170-横向扩展摩擦批") 同一把尺）：这处机制
**不生效时谁会红**？答「没人会红」的才进批。

| 处 | 症状 | 核验 |
|---|---|---|
| `ReplyAppend` + `reply_capability(first)` | 生产八个收束调用点全是首条（`turn_runner.rs` `closure_granted`），追加臂只被单测喂到 | 为不可达状态造的机制 |
| `GateWarrant` / `issue_warrant()` | PL-001 §4.2 承诺「经授权 / 预算 / 审计三道检查后才发牌」，生产是同点内联无条件签发 | 编译期强制的**错觉** |
| `CapabilityMeta.keywords` | 每个工具都填、全仓无读方 | 19 个工具的持续维护税 |
| `LatencyTier::may_call_model` / `may_generate` | ClassifyOnly 退役（ADR-096）后仅测试引用；verify 程序（`verify/latency_gate.rs` / `budget.rs`）有自己的 std-only 副本，不依赖生产面 | 孤儿谓词 |

**裁决**（2026-10-20）：四处**全部清偿**。`GateWarrant` 走**真接线**方向——
PL-012 §0 把 E2 列为目标，按工作区纪律「它属哪个迁移步」，缺口是补上而不是砍掉；
若施工中发现三道检查在现有类型面上无处安放，退回本批重裁，不改成「降级」就地混过。
