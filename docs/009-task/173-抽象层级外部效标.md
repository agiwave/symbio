# 抽象层级的外部效标——把「同义换述 × recall@k 之差」做成可执行读数

## 内容

**缺口**：五轴里四条都挂上了生产读数口（时域跨度 = span 投影、主动性 = `adoption_rate`、
自主程度 = autonomy 投影、自我模型精度 = calibration 列），只有 `抽象层级` 停在
「本轴目前只能人工判」。它偏巧是天梯 T2–T6 的主轴——「高阶了多少」这句话，在没有读数时
只能靠叙事，而那正是 [PL-002](../004-plan/002-能力坐标系.md "PL-002-能力坐标系") §3.1.1
纪律一（「读数没出来不得改可测量口吻」）想防的事。

**候选口径已经写在计划里**（§3.1.1，原文）：把 `verify/recall_eval.rs` 的 33 条用例各改写
一种说法（同义换述）后重跑 recall@k，两次命中率之差即「这条规则在多大程度上依赖字面」。
**离线可测、尚未实现。** 本条就是实现它。

**三步**（每步都要能红）：

1. **换述集**：33 条用例各写 ≥2 条同义换述——同一请求、不同措辞。两条纪律写进 fixtures 的
   头注释：① 写换述的人**不许看任何一条记忆的正文**（否则等于把答案抄进查询）；
   ② 换述尽量避开原查询的二元组——`recall_score` 的算法就是二元组重叠，换述若共享
   二元组，「依赖字面」这件事根本测不出来，测出来的只是「换了同义词仍然算得中」。
2. **读数**：`main` 多打印一行「换述召回率 / 差值」。差值 = 原述 recall@k − 换述 recall@k，
   是**依赖度**（越大越依赖字面）。它同时给 pass^k 加第三个维度：现有 V1–V3 是池形状变体，
   换述是**输入外观**变体——同一问题的合法外观，本来就包括「同一件事换个说法」。
3. **落口**：把 §3.1.1 的「抽象层级」格从「本轴目前只能人工判」改成「离线读数 + 残余人工判」，
   **并写明读数不覆盖什么**（见下「两处不可省的自欺防线」）。

**两处不可省的自欺防线**（否则这条读数会变成一个好看的 A）：

- **换述集是人写的，所以它只是效标的**下界**：换述越接近原述，差值越小越好看。故换述集
  一次写完即冻结（进 `fixtures/`），改它必须说明为什么——与 `recall_eval` 的 `cases()`
  同一条纪律（用例是数据，改数据要留理由）。
- **它测的是排序器对措辞的敏感度，不是「模型/系统的抽象能力」**：读数低只说明「这套排序
  不靠字面」，不说明「系统会归纳」。这句话必须写进 PL-002 那一格，否则读者会把一个
  排序器的性质读成整条轴的高度。

**与相邻任务的分工**：[T-171](171-keys域环拆解.md "T-171-keys域环拆解") 动的是 core 依赖图，本条只动
`verify/` 与 PL-002 的一格，两者无依赖。复核表里的 P6（A2A 互操作）/ P7（五轴 → L0–L5 映射表）/
P8（验证器生产耦合率）**不在本条里**——它们是不同的活，塞进来会让本条无法独立回退。
