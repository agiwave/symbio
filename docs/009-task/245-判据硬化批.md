## 内容

父任务：[T-236-义务环符合性收口批](236-义务环符合性收口批.md)。

2026-10-22 对账发现四处「判据存在、执行方偏软」：重放等值只测合成表；
PTS-002 不查取值；reason 必填在历史夹具上放宽；no_progress 守卫按构造不可达。
本批把它们逐一变成会红的检查。②④ 的基线更新须同批挂 ADR（PTS-003 口径）。

## 验收口径

1. 四条各指认可执行方：①生产表重放等值用例名；②PTS 扩判的脚本 diff 与回归；③`allow_missing` 收窄的不变量小节号 + 历史归档段豁免的明确边界；④`no_progress` **可达**用例名（[T-241-ActorDecl执行体注册表](241-ActorDecl执行体注册表.md) 后守卫能触发——ADR-118 订正 3 落地）。
2. verify 程序数 / assert 数 ≥ 门禁基线；门禁全绿。
3. CLI 复验两幕全过（守卫用例之外的真实证据）。
