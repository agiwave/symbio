## 内容

父设计：02 报告建议 3 / 4 · 本仓纪律「core 形状只许收窄」（[ADR-055](../010-adr/055.md "ADR-055")）

**两项都在问同一个问题：地址与载荷这两类跨端事实，能不能从「人工清单」变成「生成物」。**

| 项 | 现状 | 目标 |
|---|---|---|
| 路由清单 | 人工维护一份文档，守卫守的是「人工清单」 | 由插件自述聚合生成，守卫守「清单与代码一致」 |
| 载荷形状 | 地址不漂移已 CI 化，载荷形状无守卫 | 高频路由有前后端同源 schema |

**为什么第一项必须先论证再动手**：给 `Plugin` trait 加 `manifest()` 成员是**trait 变宽**——
按本仓纪律「收窄不需要批准，变宽需要论证」，且 CS-001 把 core 的三格形状冻结成只许降。
所以本批的第一个产出可能是**一份 ADR 论证「不做」**——那也是合格的出口：
「成本对不上」是有理由的结论，比默默不动强。

**第二项允许渐进**：资源面已有 `schemas/vdfs.ts` 先例，载荷 schema 可以逐路由加，
不动机制。选「高频控制面路由」先做，是因为它们的载荷形状最稳定、收益最直接。

**一项不做的事**：不为了「统一」把动态分发的路由塞进生成物——动态分发有明文登记位，
把它生成化等于把「运行时才知道」的东西假装成「构建时就知道」。

## 处理过程

- 2026-10-20 立批。来源：02 报告建议 3 / 4。
- 2026-10-20 为什么是 later：两项都是「把人工维护换成生成」的优化，当前没有具体故障驱动；
  且第一项要过架构论证，第二项要逐路由推进，都不适合与 now / next 的机制收敛抢改动面。
- 2026-10-20 与 [T-198](198-插件身份单源化批.md "T-198-插件身份单源化批") 的关系：T-198 让
  「前缀 = 目录名」无例外（删白名单），本批问「清单能不能自动生成」。T-198 先行——
  没有例外之后，生成才有唯一规则可依。
- 2026-10-21 段一（论证产出是一份「不做」的 ADR）。共同判据只有一问：**这个跨栈事实有没有
  第二个 owner**。路由没有——`route()` 的 `match` 臂加臂上一句职责注释就是唯一真相，
  `scripts/route-facts.mjs` 是它唯一的提取方，三个下游（事实表 §2.3、`routes.gen.ts`、
  插件入口审计）都从这一份抽取里派生。再加一个 `manifest()` 等于凭空造出第二处声明，
  守卫从此比对的是「代码 vs 代码的复述」而不是「代码 vs 代码的投影」，
  还要为此吃下 trait 变宽（CS-001 第二格）与 21 个实现方各一份清单。
  判「不做」的同时写清**撤销条件**：出现运行期必须持有全量路由表的产品消费者，或仓内出现
  第二种装配方。裁决见 [ADR-112](../010-adr/112.md "ADR-112") 决策 1。
- 2026-10-21 段二（载荷同源 = 后端命名类型 + 前端逐字段镜像 + D 组登记）。
  载荷这一侧**有**第二个 owner（后端产、前端消费，两份形状各自手写就会漂），
  但补法不是运行时 schema 注册表或生成 TS——那要么再造一处自述，要么把「前端手写契约」
  变成「前端构建产物」。走的是既有 D 组判据：先把载荷变成**读得出来的东西**
  （`json!` 现拼的响应没有结构体，守卫连比都没法比），再让前端逐字段镜像并登记。
  先做 home 四条是因为它们的形状最稳、且前端恰好已经持有三份抄本（一个 `schemas/home_reload.ts`
  加 `services/home.ts` 里三个「本模块私有契约」）——抄本就地换成镜像，改动面最小。
- 2026-10-21 段二把守卫的两处缺口一并补上，它们是这条路线的前提而不是附带品：
  ① D 组的抽取器按结构体名在**整份文件**里取第一个匹配，而一份按路由分模块的契约文件里
  四个模块各有一个 `Response`——不限定就会拿 `home_reload::Response` 去比
  `home_get_homedir` 的接口，该红的红不了、不该红的反而红；登记项因此支持
  `module` / `namespace` 限定，且限定解析不出来时**报错**（静默退回全文件搜索等于把限定丢掉）。
  ② E 组只判后端 `Corresponding Frontend`，前端 `Corresponding Backend` 无人看守——
  只守一侧等于让另一份指针免检，而读前端代码的人恰恰靠它找后端，故扩成双向。
- 2026-10-21 收口。exit 逐条核对：① 插件清单自述的自动聚合**走了论证并明确判「不做」**，
  理由与撤销条件登记在 [ADR-112](../010-adr/112.md "ADR-112") 决策 1（人工路由清单因此
  **不退役**——`docs/006-ref/003-ROUTES.md` 继续 own 契约列，键「可以缺、不能多」那条判据不变）；
  ② 载荷契约类型化已为高频控制面路由（home 四条臂）落地同源，守卫扩展到「载荷形状不漂移」，
  逐路由渐进、不动机制（[ADR-112](../010-adr/112.md "ADR-112") 决策 2）；
  ③ 两项裁决都已登记；④ 全量门禁 126/126 与 e2e 78/78 全绿。
  本批不做、按 [ADR-112](../010-adr/112.md "ADR-112") 代价节留档的一条：其余控制面路由的载荷
  命名类型逐个补——判据是「前端逐字段镜像了它才登记」，`session/stats` 这类按需取字段的
  响应没有镜像关系就没有漂移可判，硬塞进 D 组制造的是噪音。
