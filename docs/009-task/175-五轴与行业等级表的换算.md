# 五轴与行业等级表的换算——先找出处，再决定要不要造表

## 内容

**缺口的真实形状**：本仓的能力刻度是**自洽**的——五轴四级（§3.1）、天梯 T1–T8（§3.2 由名册
逐级算出）、五轴的外部效标（§3.1.1）。这三者互相对得上，且都有机器判据
（`capability_frame.rs` 判刻度顶格与阶梯咬合，`axis_orthogonality.rs` 判五轴可分）。

对外沟通时缺的是另一件事：**别人用的刻度与本仓的刻度怎么换**。行业里流传着各种
「L0–L5」「等级 1–5」的说法，它们各有出处、也各有各的定义。本仓若直接借用其中一个词，
会得到两种后果之一：

- **借对了**：读者能对上号，省一段解释。
- **借错了**（大概率）：那张表的分级依据与本仓五轴不是同一组维度，于是「本仓在 L3」
  这句话在人家的表里不成立——而读者无法分辨，因为两边都写着「L3」。

所以第一步是**找出处**，不是造表。

**若找到出处**，换算表要满足一条硬要求：每一级的判定必须能**回落到读数**
（`span` / `autonomy` / `conation` / `calibration` / 措辞依赖度，见 §3.1.1），
不能只写「能自主完成任务」这种形容词——形容词在两个刻度上都能说得通，等于没换。

**若找不到出处**，正确的产出是**不造表**，并写下代价：自造一张 L0–L5 会让
「高阶了多少」看起来有出处，而实际上那份出处就是本仓自己；[PL-002 §3.1.1](../004-plan/002-能力坐标系.md "PL-002-能力坐标系")
纪律二（设定的数字必须标「设定值」）对等级表同样成立。
