## 内容

本次面审计（2026-10-13，由用户提问触发）对照 `docs/006-ref/006-当前事实表.md` §1/§2 与
`e2e/cases/` 实际内容，确认 [RE-005](../006-ref/005-e2e覆盖矩阵.md "RE-005-e2e覆盖矩阵") 的缺席面：LLM 可见 12 工具里 `web_search` / `web_fetch` /
`http_request` / `codebase_search` / `content_search` 五个**零用例**；`telegram`（6 路由）、
`hook`、`home` 整插件面零用例；ADR-004 的四套协议适配器 e2e 只走 OpenAI 形 SSE 一条形状；
ADR-011 的三实现（SingleFile / Dir / Memory）切换从未被测。既有 50 条在册用例本身经核无虚构
（t11 / t44 两条漏入格已并入格子）。

矩阵此前自称「10 条能力域 × 3 列全部入格」——该陈述对**行集内部**成立，但行集不是从出厂面
导出的，所以「已实现且经 e2e 验证」的全量性不能由这张表背书。本任务把六个缺席面推进到
各自有归宿（用例入格，或明确不做 + 理由）。
