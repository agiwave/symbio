## 1. 场景：要什么能力

大量主体长期共存，形成**组织形态**：声誉市场、契约网络、角色分化、准入门槛、
集体决策、以及对失效主体的淘汰。

相对 S12 高了什么：S12 是"一个系统会自己做事"，S13 是"**一群系统形成了结构**"。
这是当前能设想的最远一阶（T8）——注意这是**判断**，不是"存在的最远"（[PL-003 §7.2](../004-plan/003-演进与验证.md "PL-003-演进与验证")）。

## 2. 为什么它能落在 v2 上（J1）

| 看起来新的东西 | 实际是 |
|---|---|
| 声誉市场 | `projection = reputation`（S08 已点亮） |
| 契约网络 | `commitment` 实体的一批事件 |
| 角色分化 | 不同 `capabilities` 组合的 ActorSpec 行 |
| 准入门槛 | grants 表的一行 |
| 集体决策 | 多个主体对同一 `verdict` 的竞争 + 仲裁者 |
| 淘汰 | 声誉投影低于阈值 → 不再被授予 `assign.work` |

**全部是已有键的新取值。新增机制键 = 0。**

这一阶的意义在于它验证了一件事：**从 S01 到 S13，机制键总数停在 10**。
增长的只有数据行数——事件格子、ActorSpec 行、grants 行、投影参数。

## 3. 增量清单（只加数据）

| 类型 | 内容 |
|---|---|
| 事件格子 | 复用 `commitment/*`、`verdict/*`——**不加新格子** |
| ActorSpec 行 | 市场/仲裁/守门等角色，各一行（模式仍只有三种） |
| grants 行 | 每角色一行；**读写成对** |
| 投影参数 | `reputation`、`calibration`（置信度）、`budget`（成本）组合使用 |
| `vis_scope` | `public`（集体可见）与 `thread_private`（个体私有）并存 |

**本阶点亮的机制键**（阶梯总表的「新增机制键」由这张块算出；`scripts/gen-verify-facts.mjs` 从这里取输入）：

```capability-assign
event.entity = commitment
event.verb = asserted
principal = agent:market
vis_scope = public
projection = reputation
```

> 整阶现状：**数据层已实例化**（角色行 + 淘汰回路 + 裁决消费点），`verify/scenario_ladder.rs` 的机械审计（新增机制键 0）照旧通过。
> 三项诚实缺口记在任务层：① **申诉触发器缺席**——淘汰后唯一能涨声誉的路径（成功委派）恰是被收回的能力，自动恢复不可能；恢复事件的机制半边（`restore` 同格事件 + last-wins 折叠）已由单测证，生产触发器未接（**已裁决**：缺席按边界登记，重开条件与判据见 [ADR-108](../010-adr/108.md "ADR-108")，本阶不预先立项）；② 市场 / 守门只有数据行，无跑轮主体；③ 召回路径的跨主体预过滤另立 [T-117](../009-task/117-召回跨主体读侧预过滤批.md "T-117-召回跨主体读侧预过滤批")（T-094 暴露，不归本阶）。

## 4. 平凡值与回退（J2）

| 参数 | 完整值 | **平凡值** | 平凡值下 |
|---|---|---|---|
| `vis_scope` | `public` | **`thread_private`** | 仍完整运行——无公共领域，退化成 S08 的点对点协作 |
| `projection` | `reputation` | `snapshot` | 仍完整运行——无声誉计算，契约仍成立但不可比较 |

**整条阶梯可以逐阶退回 S01**：这是 J2 的真正含义——每一阶都不是"装上去就拆不下来"，
而是"关掉参数就回到上一阶"。

## 5. 静默失效与强制（J3）

| 约束 | 违反时信号 | 强制方式 |
|---|---|---|
| 声誉计算可被操纵 | **无** | 声誉只由事件派生（投影），不由主体自报——I2 的推论 |
| 淘汰必须可申诉 | **无** | 淘汰是 grants 变更事件，可审计、可回退 |
| 跨主体成本可归属 | **无** | `budget` 投影按 `principal` 分组 |

## 6. 验收断言

1. 声誉值完全由事件序列派生——两次计算逐字节相同（确定性）。
2. 主体自报的声誉事件不得进入声誉投影（只认派生）。
3. 淘汰 = 一条 grants 变更事件，可被审计、可被撤销。
4. **反向用例**：给某主体注入一条自报声誉事件 → 断言 2 必须仍然成立（自报被忽略）。
