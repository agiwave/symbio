## 内容

父设计：[PL-016 · 义务环](../004-plan/016-义务环.md "PL-016-义务环")

**这一步只做文档，不改代码。** 但它不是"写个文档"——它要做三件有后果的事：

| 事 | 后果 |
|---|---|
| PL-016 立为 owner | 义务环的形状从此只有一处可改（改 PL-016，不在实现里绕） |
| PL-014 加指路 | 已有裁决不重开，只指方向；**PL-014 的六步路径与熔断线继续有效** |
| ADR-114 显式标注"不是更好" | 防止后人把"形状更纯"读成"已被证明更优" |

**为什么指路必须加在 PL-014 §2.1 和 §3 两处**：§2.1 是终点坐标（本方案就是它），
§3 是 `Step` 五值（本方案退役它）。只加一处，读者会以为另一半没变。

**明确不做**：不改 PL-014 的六步路径、不动它的 17 场景清单、不删 `Step` 词汇
（退役是 T-223 的施工结果，不是文档动作）。
