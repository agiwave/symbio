## 内容

父任务：[T-236-义务环符合性收口批](236-义务环符合性收口批.md)；前件条款由 [T-237-方案自洽与命名统一](237-方案自洽与命名统一.md) 写入 PL-016 §2.1。

求解器本身是纯的（`now` 为入参），但五个生产调用点全部现取墙钟当 `now` 注入——
「回放可重建」在这些路径上是假的。补法沿用 PL-014 F3 唤醒源：
启动 / 心跳 / 插话等触发先落一条**唤醒事实**，其 ts 就是本次 drive 的 `now`；
`owed` 只见事件 ts。这是把既有语义接线，不新增机制键。

## 验收口径

1. grep 判据：五个生产调用点（`turn_exec.rs:794-798`、`chat_loop.rs:463,590`、`drive.rs:120`、`inputs.rs:163,327`）不再出现 `clock_now_ms()`；全仓 `clock_now_ms` 调用点清单进 evidence，且 ⊆ {唤醒事实落格处, 与判决无关的展示/计时层}。
2. 用例：同一日志 + 同一唤醒 ts ⇒ `owed`（生产表 `loop_rows::table()`）两次求值逐字相同。
3. CLI 复验两幕全过，且租约求值由唤醒 ts 驱动（用例或日志证据）。
4. 门禁与 e2e 全绿。
