## 决策

**背景**：登记机制（[PL-011](../plan/PL-011-登记与汇总机制.md "PL-011-登记与汇总机制")）把条目放在**仓根** `registry/`，
而本仓其余文字全在 `docs/` 下。读者的查找动线因此是两处，而更要紧的是：
一条判据**适用不适用**，取决于那个目录**住在哪里**——
`doc-link-audit` 的散文体检（D-002 / D-003 / D-004 / D-006 / D-008）扫的是 `docs/` 根，
`registry/` 不在里面，所以条目从来没被这些判据判过。
这个边界是**位置隐式给的**，不是任何一处声明的：目录一动，适用范围就跟着变，
而变了也没人会被告知。

**决策**：

1. **`registry/` → `docs/`**（`git mv`，改名历史保留）。
   条目仍是 `.md` 单文档 + 受限 front-matter，kind 目录与生成投影的形状不变。
2. **装载根改到 `docs`，并把「谁判条目」这条边界显式写进代码**：
   `registry-audit` / `registry-board` 的装载目录、`doc-symbol-audit` 的整目录豁免、
   `core-shape-audit` 的 CS-002「ADR 执照必须打得开」的路径、`dead-code-audit` 读
   批号闭集（SP-015）的规则源路径，全部按新位置写。
   `doc-link-audit` 的扫描根**去掉** `registry`（它已在 `docs` 里，留着会扫两遍）。
3. **散文体检整体豁免 `docs/`，链接体检不豁免**。
   `doc-link-audit` 新增 `BODY_EXEMPT_DIRS = ['docs/']`，只管 D-002 / D-003 /
   D-004 / D-006 / D-008；**D-001（链接可达）与 D-007（站内锚点）对条目照常判**。
   这条是把上面那个隐式边界**显式化**：条目搬进 `docs/` 不改变它受哪些判据管。
4. **引用同步由脚本做，不靠手抄**：链接按「解析旧目标 → 应用迁移 → 重算相对路径」
   改写（304 篇 md 里 675 处），反引号里的路径文本另走一遍**边界判定**
   （前面不是路径字符才算路径开头，从而放过 `../`、`tauri/src/registry`、
   `~/.cargo/registry` 这些同名异物）。

**理由**：

1. **查找动线合一**：「本仓的文字」只有一个入口 `docs/`，与工作区指令
   （AGENTS.md 的「一个事实只有一个 owner」）指向同一张地图。
2. **边界本来就该显式**。靠目录位置隐式决定的适用范围，是漂移的温床：
   这次迁移真正的产出不是新目录，而是 `BODY_EXEMPT_DIRS` 那一段**写下来的判据归属**。
3. **条目不是散文**。`## 处理过程` 的职责就是记「初版怎么想、后来为什么改」，
   按 D-004 判它写历史等于判台账漏记；闭环条目引用当时存在、后来删掉的路径是事实，
   按 D-006 判它即永久误报。条目自己由 RG 判据管（`exit:` 里的路径由 RG-012 验存在）。

**被否决的方案**：

- **条目搬进 `docs/` 后让 D-002/003/004/006/008 照常判、逐条写豁免注释**：否决。
  141 条里绝大多数 `## 处理过程` 都要豁免，豁免面一开口就喂到失效——
  这正是 `doc-link-audit` 文件头记下的教训。
- **把 `docs/` 整个排除出 `doc-link-audit`（连 D-001 一起免）**：否决。
  条目链接的可达性是 ADR 迁入 registry（T-008）时建立的能力，免掉等于放弃它；
  而且迁移恰恰最容易漏的就是条目内链。
- **保留 `registry/` 在仓根 + 只在 14 里补一句说明**：否决。位置不动，隐式边界继续隐式。
- **在仓根留 `registry/` → `docs/` 的链接 / junction 兼容旧路径**：否决。
  Windows 上符号链接要额外权限且 git 处理不稳，还凭空多出第二处入口（一个事实两个 owner）。
- **顺手把 registry 改名（如 `docs/ledger`）**：否决。名字不是问题所在，
  代价却是几十处脚本字符串与全部条目引用——与本条要买的东西无关。

**后果与不变量**：

- **不变量：条目受哪些判据管，与它住在哪个目录无关**。要改这条边界，动的是
  `doc-link-audit` 的 `BODY_EXEMPT_DIRS` + 它的两条回归测试（豁免必须双向钉：
  条目里的历史叙述不判，条目里的失效链接照判）。
- **RG-012 的作用范围随迁移变大了**：`refsIn` 只认 `docs/` / `scripts/` / `e2e/` 开头的
  反引号路径，条目进了 `docs/` 之后，`exit:` 里写的 registry 路径**开始被验存在性**
  ——本次实测当场抓到 T-008 的 `ADR-*.md` glob 写法。这是收益，不是副作用。
- 同名异物未受影响：`tauri/src/registry`（前端消息类型映射）、`~/.cargo/registry`、
  `scripts/registry-*.mjs`（脚本名，不是路径）。
- **`docs/archive/` 不回改**：归档里的旧路径是当时的事实，改写等于篡改历史
  （与 D-001 / D-002 对 archive 的整体豁免同一口径）。
- 新脚本读条目一律用 `docs`；文档里指路一律写 `docs/<kind>/…`。
