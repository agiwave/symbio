## 决策

**决策**：Tauri 后端仅暴露 3 个 command——`route_v2` / `route_v2_send` / `route_v2_close`。

**理由**：极简适配层（业务逻辑全在核心库）；前端无业务规则；宿主可替换。

**后果**：前端无法直接调用插件、必须经路由；有 IPC 序列化开销。命令面现状核对见 [CURRENT.md](../CURRENT.md) §5。
